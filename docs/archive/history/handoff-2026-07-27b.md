## 5. Traps this session paid for

- **A window HIDES the G3-only steps.** `lint` and `dupes` stopped running for
  twelve commits and the debt landed in one lump. That is what WI-336 exists to
  fix — and the fix is not landed.
- **SIX vacuous guards in one session**, same shape every time: an assertion
  positioned where it cannot observe what it names. A probe in `tmp_path` never
  loads the root conftest; an exit-code compare is blind when the baseline
  already fails; a guard that compares against the constant it guards proves
  nothing; a test that RE-IMPLEMENTS the rule it checks asserts against its own
  copy; asserting a name is in an exclusion SET does not prove the filter reads
  the set. Every one passed until mutated. **Mutate before believing a guard —
  and prefer calling the real function over restating its logic.**
- **Never `Start-Process` a workload you are measuring** — it detaches, and a
  tool timeout then orphans the tree (26 processes hung ~15 min here). Run it
  inline and sample from a second process.
- **Verify process attribution before killing** — I misattributed the IDE's
  node servers to Playwright.
- **Never `git stash` mid-session.** It reverted an uncommitted 140-row flip.
  Use `git show <rev>:<path>` to read history.
- **Line endings will lie to you.** They produced both the census defect *and* a
  false byte-budget delta (a CRLF working tree measured against an LF baseline;
  true figures: **+771** for the edit, **+571** pre-existing overage — the
  review's substitute "+3,178" has the same defect inverted). **WI-337 closed
  the root cause:** 67 tracked files were CRLF on disk against an LF index, which
  `git status` cannot show you because the clean filter normalizes on the way in.
  The check is `git ls-files --eol | grep 'w/crlf'` — only `*.ps1`/`*.cmd`/`*.bat`
  should appear. Both byte figures above re-measure **exactly** on the restored
  tree, which is how they were confirmed.
