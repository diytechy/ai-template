# WI-268 — `--dual-plan` flag path honors `autonomous` (pause-free); widen SR-108 to both PAGE entries

**Status: building.** Filed 2026-07-22 from the `dualplan-routing-fix` branch
investigation (owner question: "the last run paused for human input despite
`gate-policy: autonomous`"). Rides just past the repo-review-2026-07-21 close.

## The gap

`docs/gate-policy: autonomous` is honored by the **dispatcher** dual-plan PAGE
path (`agent_dispatch.py` `dual_plan_disposition`, SR-108 / LLR-096 / TC-098): a
position-unstable round is journaled, quarantined, and the run routes on to
disjoint work, reaching the pause-free attention end state
(`_terminal_decision` → run-state `RUNNING` + `EXIT_STALL`).

The **single-shot `agent_loop --dual-plan <WI>` early path** (`agent_loop.py`
`main`, WI-199) did **not** honor it. It printed
`gate-policy autonomous -> design-check-session` and then returned
`EXIT_NEEDS_HUMAN` **unconditionally**, writing the NEEDS-HUMAN run-state only
under `attended`. So a dual-plan round reached **through the flag** hard-gated a
human even under `autonomous`, while the identical round reached **through the
dispatcher** did not — an asymmetry, and the source of the "paused despite
autonomous" surprise whenever a round is driven by the flag (or by an
orchestrator that shells into it).

Root cause on the spine: SR-108's requirement was scoped to "**The dispatcher**
shall … map PAGE through gate policy," so **no active requirement covered the
flag path's PAGE → gate-policy mapping**. The flag path (SR-106/SR-107 territory)
had a gate-policy branch with no requirement of record and no test.

## The fix

1. **Code** — `agent_loop.py` `main`, the `--dual-plan` PAGE branch: branch on
   `plan_round.page_action(gate_policy)`. `stop-needs-human` (attended) keeps the
   NEEDS-HUMAN run-state + stop banner + `EXIT_NEEDS_HUMAN`. Any other action
   (`autonomous` / `single-ratify`) writes run-state `RUNNING` + an attention
   banner and returns `EXIT_STALL` — the same end state the dispatcher's
   dual-paged route-on reaches for an attention-only frontier. No design-check
   session is spawned (neither entry does today; `page_action`'s
   non-`stop-needs-human` strings are intent labels, and the realized behavior
   matches the dispatcher's else arm).

2. **Spine** — **widen** SR-108 (do not mint): its Requirement + AC generalize so
   **both** dual-plan PAGE dispositions — the dispatcher's serialized docs-only
   disposition **and** the `--dual-plan` single-shot round — map PAGE through
   gate-policy: hard-gate a human only under `attended`, otherwise reach the
   pause-free attention (`EXIT_STALL`) end state. LLR-096 `Module`/`CodeSymbol`
   widen to add `agent_loop.py` / `main` (the LLR-095 precedent — one LLR
   spanning sibling call-sites). TC-098 `Expected` + `Evidence` extend with the
   flag-path attended/autonomous split.

## Non-goals

- A real "design-check session" tiebreaker for autonomous dual-plan disagreement.
  Neither entry runs one today; `page_action("autonomous")` returns the label but
  no code consumes it. Implementing it is a separate, larger change touching both
  call-sites and PROCESS_OPTIONS "Failure semantics" — see Residual.
