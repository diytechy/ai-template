# WI-329 — Extract the spine-row text concern out of `trace.py`

**Status: done** (filed 2026-07-27 by WI-328, which caused the growth).

## Why this exists

`trace.py` took a **+196 reviewed bump (2,812 → 3,008)** when WI-328 added the
requirement-form tier. The module-size ratchet's standing instruction is
*"decompose (WI-280), do not bump"*, so that bump is a **deferral, recorded as
one** — not a decision that the size is fine.

It is the second bump this module took in one WI (the first, +5, was the LLR
`Rationale` schema note). Two bumps against an explicit decompose-first rule is
the point at which the debt gets filed rather than re-argued.

## The extractable unit, and why it is cohesive

Four functions and their compiled patterns answer exactly one question — *is this
spine row readable and decidable on its own?*

| Function | Tier |
|---|---|
| `provenance_findings` | gating — the row carries its own history |
| `form_findings` | gating — the row is not one testable obligation |
| `paraphrase_advisories` | advisory — the child re-words its parent |
| `ac_advisories` | advisory — a comparative with no named predicate |

They are **pure text predicates**: rows in, findings out, no I/O, no git, no
filesystem. That is the pure-core / I-O-shell split
[`PROCESS.md`](../../../project-trajectory/PROCESS.md) §3 already asks for, and it is
the half of `trace.py` that is cheapest to test in isolation.

## Why a sibling module is the right shape here

The precedent is `agent_common.py` + `plan_runner.py`, split out of
`agent_loop.py` — a coordinator's own core lifted into siblings.

This is **not** the shared-`_kitcommon.py` shape that was ruled out for breaking
scripts' independent copy-ability: that proposal put logic used by *many* scripts
into one shared import. This is **one module's own core, imported by that one
module**, which changes the copy set from one file to two and nothing else.

## Deliberately deferred, not forgotten

The extraction moves the **scaffold surface** — `bootstrap.py`'s `MAPPING`,
`README.md`'s kit-contents list, `test_bootstrap.py`'s file lists, and an
`ADOPTING.md` §6 re-sync note. WI-328 landed *inside an open attestation window*,
where widening blast radius is precisely the drive-by this repo has recorded
against itself more than once. So the debt is filed with its reason instead of
being paid at the worst moment to pay it.
