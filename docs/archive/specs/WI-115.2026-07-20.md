## The observed failure class (2026-07-12, same day, same root cause)

The mechanized rules (R-A…R-E) kept the WI bookkeeping honest, but three
stalenesses of a class they don't cover survived until a human asked:

1. `docs/run-state` read `NEEDS-HUMAN` (from an earlier pause) over an
   actionable queue — `agent-resume` would boot and immediately park
   (`agent_loop.py` exits on end-states at loop start).
2. status.md's Needs-\<human> header said "the run is paused on these" —
   true under `attended`, contradicted the declared `single-ratify`.
3. status.md's WI-085/087 step said "STOP and page the owner" — the
   attended-era flow.

Root cause: the WI-107 **policy flip didn't sweep the working surfaces** for
prose predicated on the old policy value. Structure is mechanized; semantics
against declared policy is not.

## Deliverables

1. **Mechanize the run-state ↔ queue coherence (the exact observed trap).**
   `check_trajectory.py` gains a warn-first finding: `docs/run-state` reads an
   end-state (`NEEDS-HUMAN` / `BLOCKED`) while the registry holds `queued`
   WIs whose predecessors are all satisfied (actionable work, nothing blocking
   recorded) → "is the pause still real? (a stale end-state parks
   agent-resume at boot)". `DONE` + an empty actionable queue stays legal.
   Warn plain / `--strict` error at G2+ (the R-B…R-E precedent). Vacuous when
   `docs/run-state` is absent (a repo not using the unattended layer pays
   nothing).
2. **The policy-flip sweep as protocol.** One line each in the
   `session-protocol` and `gate-advance` skills (+ fan-out re-sync): a change
   to a declared policy file (`gate-policy`, `push-policy`, `review-policy`,
   `guardrails-policy`) is a **status-staleness event** — in the same sitting,
   grep `docs/status.md` + `docs/run-state` for language predicated on the old
   value (pause/stop/approval phrasing) and re-point it at the policy file
   rather than paraphrasing it (paraphrase is what rots).
3. **Reviewer-charter clause.** The REVIEW-B (process/trace) charter gains:
   flag status.md prose that contradicts a declared policy file's current
   value as a finding.

## Non-goals (honest Prose-class residue)

No NLP/semantic lint of status prose — the enforcement audit's discipline:
mechanize the narrow invariant (deliverable 1), state the judgment rule once
and route it to the reviewer (2–3); don't pretend a grep understands meaning.
