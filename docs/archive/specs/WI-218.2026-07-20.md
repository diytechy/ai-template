## Why

`agent_loop.py` is 6,336 lines. The `main()`-function decomposition (WI-080,
2026-07-16) fixed the god *function* but the god *file* remains, and it keeps
absorbing whole subsystems (dispatcher WI-182–186, dual-plan runner
WI-199/209, session I/O WI-216/217). The last four real defects (WI-215's
tuple bug, review-17c H1/M4) were all seam mismatches *between* subsystems
sharing one namespace. Three reviews deferred this to "a decomposition
campaign" that was never filed as a WI — this row makes the deferral real.

## Scope — what this IS and IS NOT

**IS:** a physical file split, **verbatim-move only**, behavior-preserving
under the existing ~130-test e2e/golden net (the WI-080/081 discipline:
unpack/verbatim/bind — code moves unchanged; only imports, module docstrings,
and explicit parameters are new). Total line count is expected to *grow*
slightly (seams cost docstrings and imports).

**IS NOT:** compaction, dedupe, simplification, logic or behavior changes,
comment-density edits, or renames of moved symbols. Any improvement spotted
en route is filed, not folded in (the conservative-edit rule — a move mixed
with a rewrite is unreviewable).

**Compatibility surface:** `agent_loop` re-imports every moved name that tests
or downstream code reference (`al.build_argv`, `al.run_session`,
`al._codex_lastmsg_*`, `al._dp_routes`, `al._dp_session`, exit codes, …) so
the module's public attribute surface is unchanged. The two
`monkeypatch.setattr(al, "run_session", …)` sites in
`tests/test_dual_plan_routing.py` re-target the module where `_dp_session`
now resolves it.

**Known behavior-relevant relocation hazards (each gets an explicit guard):**

1. `spawn_worker` re-launches the engine via `Path(__file__)` — in
   `agent_dispatch.py` this must become the `agent_loop.py` sibling path.
2. The coordinator lock's held-descriptor global (`_LOCK_FD`) must live in
   exactly one module (`agent_common`) so the dispatcher and a worker share
   one lock namespace, as today.
3. Each new module that imports siblings carries the same sanctioned
   sibling-import `sys.path` guard `agent_loop` already uses.
4. `preflight` resolves `check_privacy.py` relative to `__file__` — all
   modules live in the same directory, so the relative resolution holds.
