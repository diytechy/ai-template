# WI-270 — Reconcile the Python-floor **requirement spine** to 3.11 (catch up to WI-262)

**Status: queued.** Filed 2026-07-22 (owner-directed follow-up from the
repo-review-2026-07-21 close). A **requirements-change / re-attestation** WI:
spine text only, no code.

## Why

WI-262 bumped the kit's actual floor **3.8 → 3.11** — the scripts, the CI matrix
(`.github/workflows/test.yml` already runs
`["3.11", "3.x"]` with macOS on 3.11), the pinned dev toolchain, and
`project-trajectory/ADOPTING.md` §"Python floor" — but
**deliberately froze the requirement CSVs**. So the requirement **spine** and a
few doc lines still claim **3.8+**, drifting from the shipped reality. This WI
brings the spine into line. The hard part (choosing the matrix, editing CI) was
already done in WI-262; this is a text reconciliation + re-attestation.

## Scope — every `3.8` surface to move to `3.11`

- **SN-011** (`docs/requirements/stakeholder-needs.md`) —
  "clean Python **3.8+**" → **3.11+**.
- **SR-034** (`docs/requirements/system-requirements.csv`)
  — Requirement "clean Python **3.8+**" → **3.11+**. (Its AC — an AST stdlib-only
  scan — is version-independent and unchanged.)
- **SR-035** (same file) — Requirement "**3.8+** across Linux, Windows and macOS"
  → **3.11+**. **Rewrite the AC narrative:** the current text explains why
  *macOS+3.8 is excluded* (macos-latest is arm64; "3.8 predates Apple Silicon;
  arm64 macOS binaries start at 3.9.1"). That rationale is **obsolete** under a
  3.11 floor — 3.11 *has* arm64 macOS builds, so availability is no longer the
  reason. `test.yml` instead **excludes the macOS+3.11 cell** and runs macOS on
  **current Python (3.x) only** as a redundant-coverage call (M-27). The AC must
  describe the matrix `test.yml` actually runs (`ubuntu/windows/macos × {3.11,
  3.x}` with **macOS+3.11 excluded**), not the retired 3.8 story.
- **TC-035** (`docs/test/test-cases.csv`) — Parameters
  "Python **3.8**/latest" → **3.11**/latest (Evidence stays `test.yml`, already
  green on 3.11).
- **architecture.md** (`docs/architecture.md:15`) overview — "Python **3.8+**"
  → 3.11+.
- **status.md** (`docs/status.md` Scope) — "stdlib-only on Python **3.8+**"
  → 3.11+ (hand-authored line).
- **docs/specs/WI-064.md** — the "Stdlib-only, Python 3.8+" working-note line
  (historical spec; update the floor mention or leave with a dated note — pick at
  build time; not load-bearing).
