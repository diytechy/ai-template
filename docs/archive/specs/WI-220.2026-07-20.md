## Why (field evidence, gilbert log 2026-07-18)

gilbert's overnight dual-plan batch surfaced three defects, each verified
latent at our HEAD (`8b32453`; the regions were untouched by review-18 and
last changed in WI-218 slice D):

1. **#5 — the launch reconcile silently overwrites a diverged dev branch.**
   gilbert `9258b43`: a relaunched dispatcher found `main` carrying two
   commits the integration ref lacked, published over them, and
   `reset --hard` discarded them (reflog-only recovery). Our
   `agent_dispatch.py:1540-1559`:
   the diverged case (`neither is ancestor`) emits `integration-diverged` and
   then **falls through into the publish branch** — the adjacent comment
   claims the divergent case is "logged and left for a human", but no control
   flow enforces it, and `publish_integration` (line 1053) CASes the dev ref
   against the *freshly read* head, so the CAS succeeds and the sync resets a
   clean checkout onto the target. Violates the kit's own
   surface-never-overwrite posture (spec §9/§11).
2. **#6 — registry-editing disposition/integration commits are rejected by a
   freshness-gated pre-commit hook, then the error path discards the work.**
   gilbert `3456316`: a dual-plan SELECT edits `work-items.csv` in the
   staging worktree, staling the generated OKF bundle + dashboard; the
   repo's hook rejects the disposition commit and the error path hard-resets
   — **an ~11-session round discarded**. Page-only dispositions commit fine
   (registry untouched), which is why only SELECTs died: *the auto-SELECT
   path had never succeeded in any freshness-hooked repo.*
   `integrate_train` (787) and `blocked_disposition` (906) edit the registry
   the same way (`Status=done`/`blocked`) and share the exposure — gilbert
   only patched `dual_plan_disposition` (972) because that is what bit them.
3. **#7 — disposition error paths destroy round evidence.** Every error
   branch in those functions runs `git reset --hard old_head` on the staging
   worktree, discarding `docs/plans/DP-*` artifacts (the round's only
   output). Flagged unpatched even in gilbert; with #6 fixed the trigger is
   rare, but an error must never silently delete evidence.

## Scope

**(a) Diverged-dev guard (#5).** In `dispatch_run`'s launch reconcile: the
diverged case routes to a NEEDS-HUMAN page (banner naming both heads + the
reconcile options; generated run-state `NEEDS-HUMAN` with an `ask:` line) and
**skips publication** — never falls through. Defense in depth:
`publish_integration` itself refuses (state `deferred`, reason named) when
the target is not a descendant of the current dev head
(`git merge-base --is-ancestor dev_head target`), so no future caller can
reintroduce the overwrite. Fault/behavior tests: a diverged fixture must (i)
keep both dev-only commits reachable from the dev ref, (ii) exit
NEEDS-HUMAN, (iii) leave the intent/journal evidence naming both heads.

**(b) Disposition freshness regen (#6).** One helper (in `agent_dispatch`):
regenerate the *present* generated artifacts inside the staging worktree
before the commit, in dependency order — OKF bundle, then trajectory
dashboard (`generate_status`/`regenerate_index` are already called where
they apply; arch-map is untouched — dispositions are docs-only). Called from
**all three** registry-editing commit paths: `integrate_train`,
`blocked_disposition`, `dual_plan_disposition`. Kit-grade generalization of
gilbert's patch (their `3456316` resolves `wt/scripts/<gen>` — the
downstream layout only):

- Generators resolve as `Path(__file__).parent` **siblings** of
  `agent_dispatch.py`, so the same code serves the downstream `scripts/`
  layout and this meta-repo's `project-trajectory/scripts/`.
- Gate on **artifact presence in the worktree** (`docs/okf/` dir for
  `gen_okf.py`; `PROJECT_STATE.html` for `gen_trajectory.py`), not script
  presence — a non-adopter must not have a bundle/dashboard conjured into a
  disposition commit.
- A regen failure resets and reports loudly (`"disposition regen failed
  (<gen>): <tail>"`) — never a cryptic hook rejection — and goes through the
  #7 salvage below.

**(c) Evidence salvage (#7).** Before any error-path `reset --hard` in
`dual_plan_disposition` (and the shared shape in the other two where a
round/train wrote docs-only evidence), copy the staging worktree's uncommitted
round evidence (`docs/plans/DP-*` for the dual path) to
`out/dispatch/salvage/<train>/` in the primary root (out/ is the journal
home — unversioned, never authority, spec §11) and append the salvage path
to the returned error detail. Best-effort: a salvage failure must not mask
the original error.

**Non-goals:** no reconcile-policy redesign (the diverged page IS the
policy — a human merges or moves the ref); no hook-detection heuristics
(regen unconditionally-when-present is cheap and idempotent); gilbert's
`2d52ef6` (native codex path) stays superseded by WI-216/217.
