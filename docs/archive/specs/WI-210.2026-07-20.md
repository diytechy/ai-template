# WI-210 — M3: legacy-path retirement (one engine, one selection path)

> **ARCHIVED 2026-07-20 — WI-251 spec-lifecycle sweep.** Spec-of-record for **no registry citer (working notes for the effort it accompanies)** (all `done`; deliverables in `docs/requirements/work-items.csv`, session records in `docs/log.md`). Absorb-verified before archiving: every durable decision has a live spine/architecture/process home (dispositions in the log, 2026-07-20 entry).

**Status: DEFERRED (filed 2026-07-17, owner-directed). Hard predecessors:
WI-208 + WI-209. Un-defer trigger (the bake period):** the dispatcher has been
the live default for **≥ 3 real multi-WI runs on this repo** (dispatch →
review → integrate → publish, evidenced in the log/journal) with no
correctness incident that the serial path would have avoided — then this WI
re-enters `queued` on an owner un-defer.

## Problem

With WI-208 flipping the default and WI-209 closing the dual-plan hole, the
**legacy serial resume driver** and the `--track` lane plumbing become the
third and fourth strata of a one-engine design
([parallel-wi-dispatch.md](parallel-wi-dispatch.2026-07-20.md) §1.2; `--track` is
explicitly "retained temporarily as compatibility plumbing"). Keeping them
costs real safety: every future guard must be wired per-path (the dual-plan
quiet-park hole was exactly this), and the two control philosophies split the
judgment duties ambiguously.

## Scope

1. **Retire the serial resume driver as a default-reachable mode:** absent
   `--jobs`/`AGENT_JOBS` resolves to the dispatcher (`--jobs 1` = serial
   dispatcher, the §1.2 escape — NOT the legacy loop). The legacy loop's
   remaining unique duties are re-homed first (item 3). Decide at build —
   with the owner — whether the legacy code path is (a) deleted outright or
   (b) kept one release behind an explicit `--legacy-resume` flag with a
   deprecation note; the spec default is **(a) delete** (dead code is the
   liability the working agreement names), with (b) only if downstream-resync
   evidence demands a window.
2. **Retire `--track`** (the pre-dispatcher parallel-lane plumbing) and its
   lane files; `test_agent_loop_tracks.py` retires with it; SR-029/SR-030
   (the per-track lock rows) are re-scoped or retired **through the normal
   spine amendment path** (Draft→ratify in a reviewed commit — this is the
   heart of why the WI is spine-touching and strong).
3. **Re-home the judgment duties** the legacy driver owned, explicitly and in
   one place (PROCESS_OPTIONS "Unattended operation"): intake/triage of new
   scope → the human + the gate-stage sessions; drained-queue handling → the
   dispatcher's end-state banner (already generated); NEEDS-HUMAN
   surfacing → run-state (already dispatcher-generated); the
   "resume-from-status.md" prompt text → retired with the path.
4. **Downstream migration guidance:** ADOPTING.md §6 gains the one-paragraph
   recipe (an upgraded repo re-syncs the kit, runs its own §14 audits, flips,
   then drops any local reliance on the legacy prompt); `downstream-resync`
   skill updated to match.
5. **Sweep the per-path guard inventory:** every check that exists only on
   one path today (grep for worker-only / driver-only guards) either becomes
   single-path or is recorded as deliberately dispatcher-only — the
   "guards wired per-path" failure mode dies with the second path.

## Interfaces

Retirement work: **no cross-module seam** is added (the PROCESS.md §8
escape); the surviving seams (IF-053/054, IF-058…061, the coordinator's
declared rows) are unchanged, and any seam that exists *only* to serve the
retired paths is retired through the interface registry's normal lifecycle in
the same commit.

## Done-when

- [ ] Absent-`--jobs` boots the dispatcher; no code path reaches the legacy
      resume loop (or, if (b) was ruled, only via the explicit deprecated
      flag); `--track` is gone.
- [ ] SR-029/SR-030 re-scoped or retired through a reviewed spine amendment;
      `trace.py --strict` green at the derived gate.
- [ ] The judgment-duty re-homing is stated once in PROCESS_OPTIONS;
      ADOPTING §6 + the `downstream-resync` skill carry the recipe.
- [ ] The per-path guard sweep is recorded (single-pathed or deliberately
      dispatcher-only, each with a reason).
- [ ] Full suite + `check.py` at the derived gate green; the retired tests
      removed in the same commit that removes their subject.

## Non-goals

- No behavior change to the dispatcher itself.
- Not before the bake period — this row stays `deferred` until the un-defer
  trigger above is met and the owner rules.
