# WI-287 — the integrator runs the spec close-ritual at done-flip

**WI:** WI-287 · **Status:** queued · **Delivers:** the integrator close
transaction (harness layer; the `docs/specs/README.md` lifecycle + the R-F rule
in `check_trajectory`) — no new spine SR

## Problem

When `agent_dispatch.integrate_train` flips a WI to `done`, it sets `Status` +
`Deliverable` but leaves the **`SpecRef` cell set** and the **spec file live** in
`docs/specs/`. The `docs/specs/README.md` lifecycle (enforced by
`check_trajectory`'s R-F rule) requires a terminal WI to **clear its SpecRef** and
**archive its spec** to `docs/archive/specs/<stem>.<date>.md`. So every WI the
autonomous loop closes strands two R-F findings:

- `WI-N: status=done but SpecRef '<path>' is still set`
- `docs/specs/WI-N.md: live spec cited by no open WI`

Observed live (run `20260723T0202`): WI-275 and WI-279 both closed by the
integrator carried the debt; it had to be cleaned by hand (`df24b7b`). R-F is
WARN at the commit bar but ERROR under `--strict` (G2+), so the debt silently
accumulates until a gate check reddens on it.

## Approach (implemented 2026-07-23, hand-applied per owner directive)

In `integrate_train`'s done-flip transaction, before the disposition commit:

- **Capture** each closing WI's current `SpecRef` (`_wi_specrefs`, read before
  the rewrite).
- **Clear** the `SpecRef` cell in the same `_rewrite_wi_rows` update
  (`"SpecRef": ""`).
- **Archive** the file half (`_archive_closed_specs`): a `docs/specs/<file>.md`
  SpecRef is `git mv`d to `docs/archive/specs/<stem>.<date>.md` inside the staging
  worktree (staged by the existing `git add -A`). A SpecRef that is empty, a
  non-`docs/specs/` anchor (e.g. WI-279's `docs/repo-review-*.md#...`), or an
  already-absent file is **skipped** — the ritual only archives a real live spec.
- The integration log entry records `Spec(s) archived: <dest>` when any moved.
- Date via `time.strftime("%Y-%m-%d")` (the dispatcher already stamps the log
  this way — no clock-purity constraint here, unlike a workflow script).

**Known follow-on (recorded, not silently ignored):** archiving a spec can leave
an inbound link stale (a `log.md` entry that linked `docs/specs/WI-N.md`) — the
WI-275 cleanup hit exactly this and check_docs caught it. The integrator's own
combined bar does not run check_docs today (and, per WI-285, has not run at all),
so this WI does **not** claim to fix inbound links; it fixes the SpecRef+archive
half. A future WI-285 (integrator bar) + a link-rewrite pass is the complete
guard; noted here so the boundary is explicit.

## Interfaces

No cross-module seam — intra-module (`agent_dispatch.integrate_train` + the two
new helpers, and tests). It enacts the `docs/specs/README.md` lifecycle the
`check_trajectory` R-F rule validates; that rule is unchanged.

      cleared with no move.
- [x] Commit bar green; row `done`, spec archived (self-exercising the ritual once
