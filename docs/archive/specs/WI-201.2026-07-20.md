> **ARCHIVED 2026-07-20 — WI-251 spec-lifecycle sweep.** Spec-of-record for **WI-201** (all `done`; deliverables in `docs/requirements/work-items.csv`, session records in `docs/log.md`). **Status: queued (filed 2026-07-17 at the WI-199 close, per the WI-190 spec's

## Problem

The dual-plan round set (WI-194…WI-199) shipped traced to **provisional SR
homes**: LLR-070/071/073/074/076 + their TCs ride **SR-061**
(parallel-by-default dispatcher — coordinator machinery, but not a dual-plan
requirement), each row carrying an in-place "provisional home pending the
structuring WI" note; the four new seams **IF-058…IF-061** are `Status=
Proposed` with the same caveat. The feature has no requirement of record, so
its acceptance criteria live only in module docstrings and the
PROCESS_OPTIONS layer.

## Scope (the WI-176 → WI-177 pattern)

1. Structure the requirement: an SR for the dual-plan decomposition round
   (SN-Refs from the existing unattended-operation needs; clauses = the
   layer's seven steps + the caps + the degraded modes), entering at G1 and
   ratifying through the normal gates.
2. Re-home the provisional LLR/TC rows onto the new SR (id edits only — the
   rows' Detail text already describes the behavior accurately) and drop the
   "provisional home" caveats.
3. Ratify IF-058…IF-061 out of `Proposed` (they are implemented, consumed
   seams since WI-199).
4. Rule the **frontier auto-dispatch residual**: what `SafetyClass` a
   `PlanMode=dual` row declares so the `--jobs` dispatcher schedules the
   round itself (single-WI traincar per SR-058's fail-closed posture), and
   whether the round runner's repo-cwd sessions need the manual protocol's
   empty-cwd isolation as an option.

## Interfaces

Acts on the declared seams **IF-058**, **IF-059**, **IF-060**, **IF-061**
(ratification of the existing Proposed rows — no new seam; registry-row edits
plus SR/LLR/TC re-homing are intra-registry work).

## Done-when

- [ ] The dual-plan SR exists and is Verified; every WI-194…WI-199 LLR/TC row
      cites it; no "provisional home" caveat remains in the registries.
- [ ] IF-058…IF-061 are no longer `Proposed`.
- [ ] The auto-dispatch ruling is recorded (SafetyClass value + isolation
      call), implemented or explicitly deferred with its reason.
- [ ] `trace.py --strict` + `check.py` at the derived gate stay green through
      the re-homing.

## Non-goals

- No behavior change to the round set (this is spine structuring).
- No new engine or layer text beyond what the ruling in scope item 4 demands.
