## Problem

Owner finding (2026-07-20, post-WI-249/250): the wired diagrams in
`PROJECT_STATE.html` still have **edges that cross each other and edges that
pass through unrelated node boxes**. WI-249 fixed arrowheads and fanned
multi-edge ports, but wires are still straight/bowed segments with no
obstacle awareness — a wire between distant rows can cut through an
intermediate node's box (falsely reading as connected to it), and crossings
land under labels/ports where sources become unattributable.

Acceptance is now owned by rubric anchor **T8** in
[dashboard-usability.md](../../rubrics/dashboard-usability.md) (added at this
filing): a reader can follow any edge source→target; no edge passes through
an unrelated box; unavoidable crossings happen in open space. A critique may
cite this WI as the filed disposition, but **T8 blocks APPROVE until the
render passes** — so this WI is what stands between the dashboard and a clean
critique.

## Approach

For the builder to refine; the plausible shape, smallest-first:

1. **Obstacle-aware wire paths** in `gen_trajectory.py`'s shared wire
   emitters (`dag_svg`, `sw_graph`, `know_graph`, `_drill_layer_svg`,
   `_port_fan`): route a wire that would intersect a node rect around it
   (orthogonal or bowed detour with a clearance margin), reusing the WI-249
   port-fan/trim idioms. Deterministic geometry only (no randomness — the
   `--check` byte-stability rule).
2. **Crossing reduction** where cheap: order same-port fan-outs by target row
   (already done), and consider per-layer horizontal lane assignment for
   long-range wires rather than full crossing-minimization (this is a static
   generated SVG, not a layout engine — proportionality per SN-012).
3. Re-shoot the full width/theme matrix; the next `*-CRITIQUE.md` judges T8.

Constraint: any change here touches the render surface, so the WI-243
fail-closed staleness gate requires a fresh critique before the next green G3
— build + critique in the same effort.

## Interfaces

No cross-module seam — acts only within `gen_trajectory` (and its co-located
`shoot.mjs` matrix for evidence).
