# `docs/test/` — the test-case registry

The TC tier of the spine. [`test-cases.toml`](test-cases.toml) holds one table
per test case, keyed by its `TC-###` id, and is the file every gate joins on
when it asks what verifies a requirement — the id, its `verifies` targets and
its `evidence` are the cells the traceability rules read.

Beside it, `report.md` (untracked, gitignored; written by every run, so a fresh checkout has none until `trace.py` runs — which is why this sentence names it rather than links it) is generated by `trace.py` — the tier
counts, the coverage matrix and the orphan/integrity findings — so it is read,
never edited.
