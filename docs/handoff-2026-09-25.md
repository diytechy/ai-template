## Known traps

- **An `--approves` names a whole registry.** The snapshot refuses drifted
  approved text a Status flip does not cover, but naming a registry with
  `--approves` authorises every drifted row in it. Name one only when a verdict
  has read each of its drifted rows; row-level refusal (WI-635) removes the
  trap.
- **Do not run intake's mint or a claim with uncommitted edits** in the
  primary checkout (WI-612). This grind filed its work items by hand, raised the
  watermark with `trace.py --bump-ids` and regenerated with `trunk_step.py
  --regen`.
- **Drafted rows skip the text rules.** Lint a new batch as if Approved before
  review; the grind's scratch linter did this for every iteration.
- **Hooks are opt-in** and unset here (D30).
