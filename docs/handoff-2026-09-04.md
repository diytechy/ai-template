## 3. What to expect, and what to do (additions to the 09-03 §4 playbook)

- **A CHANGES-REQUESTED rework that changes only `docs/reviews/`** leaves the
  tree identity unchanged; the next APPROVE is refused as a
  reroll-until-green. The lane then needs a rework that moves the non-record
  tree (a `## Dispositions` draft is the adjudicator's proper answer) and a
  new round.
- **A finished lane cannot draw another round through the loop** (the
  coordinator integrates finished branches before resuming workers). Recovery
  is the WI-578/WI-590 precedent: a supervisor-drawn independent Opus
  reviewer with `prompts/reviewer.template.md`, the round file committed on the
  lane, a legacy rollup `docs/reviews/WI-<n>-REVIEW-A.md` citing it as the
  newest commit, then `integrate.py --root . integrate` from the trunk root.
  Never `git merge` the trunk into a lane by hand (it moves the merge-base
  past the round files and the evidence scan goes blind).
- **Refresh conflict on generated files**: merge the trunk on the lane, take
  the trunk side of `PROJECT_STATE.html` / `docs/stage` / `docs/status.md`,
  regenerate (`derive_stage`, `gen_trajectory --status`, `gen_trajectory`,
  `gen_open_items`, `trace.py --approve modified --out docs/ratify/CURRENT.md`
  — never `gen_verdict_rollup` on a lane, it now refuses), commit, re-note the
  rollup so it is newest, integrate from the trunk root.
- **UNLOAD INCOMPLETE on an ignored real `.venv/`**: `readlink` first, then
  `git worktree remove --force <lane> && git branch -d <branch>`, relaunch.
- **An untracked `docs/reviews/rollup/*.md` in a lane** reads as dirty to the
  dispatcher; delete it.
- **`integrate.py ... integrate` from the trunk root can exceed the 10-minute
  tool timeout** under the DevStg-Tests bar; run it in the background. A kill
  mid-refresh leaves regenerated files staged on the lane: `git reset --hard
  HEAD` there and re-run.
- **A fresh loop launch under `docs/work/pause` exits EXIT_PAUSED** before
  resuming any parked lane; to resume one under a pause, delete the pause,
  launch, re-create the pause in the next commit.
- **Relaunched loop stdout is block-buffered**; monitor git state (trunk HEAD,
  lane HEAD, newest `docs/iteration/*.log`) rather than the log.
