## How the build runs

- **One builder session per item, in its own worktree**, cut at the trunk's
  tip: `git worktree add -b build/wi-NNN <scratchpad>/wt-NNN <HEAD>`. Do NOT use
  the Agent tool's `isolation: "worktree"`: it cut the worktrees from the
  default branch's July commit (3abeb636), 2,948 commits behind. Point each
  builder at its worktree path explicitly, hand it the builder brief, and
  pre-assign its interface ids (the IF watermark is 189, so the next free id is
  IF-190; the WI watermark is 648). Run at most three or four builders on this
  machine.
- **Review** each builder's commit with codex Sol at medium effort, read-only,
  from the worktree: `codex exec -m gpt-5.6-sol -c model_reasoning_effort="medium"
  -s read-only --skip-git-repo-check -o <out> - < <prompt>`. Put a real
  disagreement to a Fable (medium) agent. Send the fixes back to the same
  builder as one follow-up commit.
- **Integrate** with `git merge --squash build/wi-NNN`. Expect additive
  conflicts in `RESYNC_PACK.md`, `tests/conftest.py` `SLOW_MODULES`,
  `tests/test_module_size_ratchet.py`, `docs/requirements/interfaces.toml` and
  `docs/id-watermark` (take the higher mark). Close the spec: `## Deliverable`
  before `## Context`, `specref = ""`, then `spec_move.py` to
  `docs/archive/work/complete/`. Add a section to the build log fragment, run
  `trunk_step.py --regen`, then the bar. Commit as `WI-NNN: …` with the `WI:`
  trailer.
- **The bar** per commit: `check_docs --stale`, `check_trajectory --strict`,
  `trace.py --strict-integrity`, `trace.py --approve modified --check`,
  `gen_open_items --check`, and `scripts/check_smoke_budget.py --mode enforce`
  (it runs the smoke tier itself). Also run the slow modules the change touches:
  the smoke tier skips them, which is how a stale pin went unseen for a day.

## Known traps

- **The full unfiltered suite has not run since the approval act.** A run at
  2be2894f was stopped unfinished when this session wrapped up. Run it once
  (`python -m pytest -q -n 4`, in a worktree so merges cannot disturb it) before
  anything is called phase-complete.
- **An approved row's attesting text is never edited in place by a build.**
  When a change makes one false, draft the amendment in the same change, file
  an adjudication, and re-anchor the MEANING rows with `intake.py snapshot
  --reattests <ROW-ID>[,...]` (WI-612 and WI-648 are the worked example).
- **A re-anchor names its rows.** Since WI-635 the snapshot refuses any drifted
  approved row an act neither flips nor names with `--reattests`, and
  `--approves` only records a ref.
- **A session limit can stop every builder at once.** Their worktrees keep the
  work; resume each builder with a message rather than starting a new one.
- **Hooks are opt-in** and unset here (D30).
