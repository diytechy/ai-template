## Deliverable

DONE 2026-07-28. _rebase_moved_spec_links(wt, moves) is the mirror WI-288 left unbuilt: at archival each moved spec's OWN relative link targets are resolved against the OLD directory and re-relativised against the NEW one. The inbound loop structurally cannot reach these - it rewrites a link whose TARGET resolves to a moved source, and here the targets did not move, the document did - which is why the two are separate functions rather than one. Left alone, for the same reason in each case: a bare #fragment, a scheme-ish or protocol-relative URL, and a root-relative /path all resolve independently of the holding directory, so moving the file cannot break them. The #fragment and the link TEXT survive; line endings are preserved. Wired INSIDE _archive_closed_specs beside the inbound half, so the ritual stays indivisible - its docstring now says a caller cannot do two thirds of it, and a test pins that the inbound redirect was not lost while adding the outbound rebase. The new half created a same-file duplication and check_dupes went RED, which is the F5 rule working (it buys cross-SCRIPT copy-ability, never a same-file copy), so TWO primitives were extracted rather than sanctioned: _rewrite_md_links (the traversal, the leave-it-alone None contract, and the newline="" I/O discipline, shared by both rewriters, since only the per-link DECISION differs between them) and _resolvable_link (the is-this-a-repo-relative-path test, with skip_absolute for the one asymmetry - a /path cannot be broken by moving the HOLDER but can be by moving the TARGET, so only the rebase half excuses it). Guards (6, tests/test_agent_dispatch_decisions.py): a fixture carrying a link at each depth (same dir, ./, ../, ../../, sideways) plus an anchor, an absolute path and an http URL, archived through the REAL _archive_closed_specs and then checked with the REAL check_docs - and the MUTATION TWIN moves the same fixture without the rebase and asserts check_docs FAILS, so the guard demonstrably reproduces the defect it fixes. Plus: the #fragment survives, the link text is untouched, a same-directory move is a no-op, CRLF is preserved with no lone LF introduced, and both halves of the ritual still run. Found while writing them: check_docs does not resolve root-relative links at all, so that shape is asserted on the decision function instead of end-to-end. Module size 3923 -> 4028, reviewed bump.
