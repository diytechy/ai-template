## Deliverable

check.py gained one module-level helper, `_step_gate(explicit)` (beside `resolve_gate`), returning `explicit or "all"`; main() computes it once and both step-plan branches — `--run-step` and `--run-steps` — build their plan at it instead of the hardcoded `"all"`. It is deliberately NOT `resolve_gate`: that reads docs/gate, which would arm `--strict` inside the pre-commit floor the `trajectory` step's comment forbids. So an explicitly passed `--gate` really gates (`--gate G3 --run-steps trajectory` now prints and runs `check_trajectory.py --strict`), while the hook's defaulted call — argparse `default=None`, no `--gate` on the command line — stays warn-first, exactly as before. Name lookup is untouched: the plan is searched unfiltered either way, so a gate-scoped step like `format` is still findable at any gate. One line added to the `--run-step` CLI docs; the trajectory step's comment now names `_step_gate` rather than asserting the flag resolves at `"all"` unconditionally.

Both halves are pinned, as the row demanded. `tests/test_check_harness.py::test_step_gate_honours_an_explicit_gate` is the unit half (the sentinel's four cases, plus the command `check.steps()` builds: `--strict` present at G2/G3, absent at `all`, and `format` still resolvable at `all`). `tests/test_pre_commit_hook.py::test_run_steps_gate_promotes_the_warn_first_floor` is the behavioural half, on the same dangling-SpecRef (R-E) fixture the existing R-A floor test uses: with no `--gate` it exits 0 even though the scaffold's own docs/gate says G3, with `--gate G3` it exits nonzero naming R-E, and a repaired row goes green at G3 so it is not a blanket strict failure. Both left unmarked, off the smoke tier. The existing `test_hook_trajectory_step_is_the_ra_floor` is untouched and green.

The row's open question — "decide what `--list` should print" — is answered for the explicit case: `--gate G3 --list` and `--gate G3 --run-steps` now agree. A residual divergence remains BY DESIGN and was left: with no `--gate`, `--list` reports the gate from docs/gate while `--run-steps` runs the warn-first floor. That is the hook contract, not a defect, and widening it would re-arm the very thing the trajectory comment forbids.
