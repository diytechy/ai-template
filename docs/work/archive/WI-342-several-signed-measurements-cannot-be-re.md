## Deliverable

DONE 2026-07-28. Ruled: BOTH halves, in order, as one standing rule stated once in process-options.md "Signed measurements" (applies when a measured number is about to be written into a doc, log or registry row). (1) A measurement whose input its own fix will destroy must commit its evidence FIRST - the command, the manifest, before/after hashes, raw output - in the repo, not in a session transcript. (2) A number already taken on state that is gone is written as a historical, non-reproducible observation in the same sentence that states it. The reasoning worth keeping: such a number is not wrong, it is UNFALSIFIABLE, which to a reviewer is indistinguishable from one that was never true - that is how a false claim survives. Applied to all four sites 128-REVIEW-A named: the 28-LF/9-CRLF mixture (docs/dupes-allow) and the 67-file restoration (the archived WI-337 spec) are marked HISTORICAL with the independently checkable residue named beside them - the committed 164-entry census, and 128-REVIEW-A's own proof that no line-ending-only blob change landed; the classifier's "four passes" claim is gone, superseded by WI-340's re-triage which states its method rather than its effort; and the 24.3 s smoke figure now carries the command that re-derives it plus a fresh reading taken today (470 tests / 29.1 s), which is half (1) actually applied rather than described. Enforcement is honest: nothing can distinguish a live measurement from a recollection, so this is a Reviewer-tier rule and it is recorded as such in docs/enforcement-audit.md, with the evidence that the tier works - two adversarial reviews refuted or marked UNVERIFIABLE eight signed figures between them.
