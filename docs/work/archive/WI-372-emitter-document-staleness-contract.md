## Deliverable

DONE 2026-07-30, documentation only, exactly as the owner's narrowing ruling
scopes it (log.md Decisions, same day). `_every_emitter_document`'s docstring
now carries the truth-time contract the WI-367 builder had to work out by hand.

**What it states.** `shipped` is the COMMITTED `PROJECT_STATE.html` — markup an
OLDER renderer wrote, because generated artifacts belong to the trunk lane
(concurrency-restructure §5.2) and `check.py` skips the freshness gates off it,
so off trunk the document legitimately lags the code under test. Asserting over
it is therefore a COMPATIBILITY PIN ("the invariant holds for the markup already
in a reader's hands"), never a claim about the current emitter; it is also simply
absent in a checkout with no committed dashboard, so a caller reading it must
still be meaningful fresh-only. Every other label is FRESH — built into
`tmp_path` and rendered by this run's `gen_trajectory.py`.

**The trap, named where a caller meets it.** A change that TIGHTENS an invariant
reds through the stale shipped copy rather than through the emitter it changed:
the failure names an older renderer's markup while the code under test is clean.
So the contract sends a caller wanting the CURRENT emitter's answer to filter at
the call site and supply a fixture for whatever shape the shipped copy used to
contribute, citing `test_svg_viewbox_contains_every_routed_wire` as the worked
example (`lb != "shipped"` plus `WRAPAROUND_WIS`). The fourteen call sites that
keep `shipped` are named as the pins they are — the U1-U4 / A1-A3 / T6
uniformity-and-accessibility sweeps and T8's through-box sweep, enumerated
mechanically over the file rather than from memory — with the triage rule that
was the finding's whole point: **read the failing LABEL first**, `shipped` means
regenerate the dashboard on trunk, any other label means the emitter really
regressed. `test_a2_the_repos_own_shipped_dashboard_holds_the_invariant` is
cross-referenced as the same pin made without the helper.

**What deliberately did not ship.** No enforcement layer: the shared
fresh-emitting fixture of the original medium-tier filing stays out of scope
(rejected as enforcement-layer growth; its evidence remains in
[WI-367-REVIEW-A](../../reviews/WI-367-REVIEW-A.md) if it ever re-opens), the
per-caller exclusion pattern is unchanged, and there is no new test — a docstring
contract is the whole deliverable. Zero behaviour change: one docstring, no code
touched, no fixture added.
