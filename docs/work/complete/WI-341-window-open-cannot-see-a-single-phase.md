## Deliverable

DONE 2026-07-28 by MEASURING the counterfactual instead of inferring it, which turned an owner-shaped question into a mechanical one. The row offered two routes, both of which change what derive_gate publishes: a stored high-water mark, or an explicit window marker. Both were rejected - a high-water read from the artifact's own previous content makes a generated file depend on its own history and never falls back when a repo genuinely regresses; a declared marker re-introduces the hand-set gate the derived model exists to abolish. The evidence was already in the snapshot and nobody had asked for it: a Draft erases its PHASE's level, but it does not touch the sibling rows, which are still standing there. So derive_gate now publishes `ex-draft=` on the `# basis:` line - the SAME gate arithmetic run over the non-draft subset - and window_open reads it directly: a draft window needs ex-draft to clear G2 AND to sit above what the drafts produced. Pure function of the artifacts, no history, no self-reference, no owner decision required. The false negative is closed (mature single-phase repo + one Draft: computed=G0, per-phase=1=G0, ex-draft=G3 -> window) and the MAJOR-3 false positive stays closed at the source rather than by a floor heuristic (early multi-phase repo: removing the drafts recovers nothing, ex-draft=G1). Implemented by lifting the shared arithmetic into _raw_level(rows...) so compute() can ask it the counterfactual question - one function, called twice, rather than a second copy of the rules. The per-phase heuristic is KEPT as the fallback for a gate file written before the field existed, so an un-regenerated downstream repo keeps its old behaviour; regenerating docs/gate is the one migration step and `--check` reports it. Guards: three in test_derive_gate.py drive the real spine (a G3 single-phase repo reopened by a Draft, an early spine where ex-draft recovers nothing, and a clean repo where ex-draft == computed), five in test_advisory_during_window.py cover the consumer including both precedence directions with ex-draft and per-phase DISAGREEING, and one asserts the meta-repo's real docs/gate carries the field - without which every fixture assertion could pass while the producer published nothing. The mutation proof is in the suite: strip only `ex-draft=G3` from the winning fixture and the answer reverts to the documented defect. docs/status.md now states what the rule measures instead of describing a heuristic and its limit.
