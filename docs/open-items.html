Every prompt the delivered loop launches or an attended launcher renders as a review or critique brief shall be a shipped, reviewable file with strictly filled slots — listed by digest in a freshness-gated generated catalogue, each loop session recording which template it used and the fingerprint of what it rendered to.

Rationale

Requirement

When a commit is made from a process the unattended loop started, or is merged in a lane the loop owns from the point the loop took that lane over, the delivered commit floor shall refuse it unless it carries a valid provenance trailer naming the loop and its session.

Refusing the unmarked commit at the floor makes the mark total, which is what lets a later check treat its absence as meaningful. The floor where a commit is made is local and a determined bypass defeats it, which is why the merge re-checks a loop lane and the history check stands behind both.
