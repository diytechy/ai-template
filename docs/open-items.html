SR-233Review threat modelre-accept owed

Requirement

The delivered review process shall limit findings to defects reachable in a normal working environment.

Rationale

A DERIVED requirement, and labelled so. SN-006 requires an unattended run to report failures clearly and to continue until it must surface to an operator; it does not say which hostile host conditions a review must treat as an actionable defect. The unattended-operations lens listens for an unbounded retry: treating a reproduction that depends on a compromised or contrived host as actionable can extend review indefinitely and can demand code that compensates for a host whose integrity the process cannot establish. A stated boundary was chosen over relying on each reviewer to infer it, because an inferred boundary varies by session and cannot stop repeated rework. Fed back to the need: SN-006's acceptance could identify the normal working environment in which a review finding is actionable; until it does, this row is derived and says so.
