cognitive() walks one function's body by recursive descent carrying a nesting level (not ast.walk, which loses depth), adding 1 + nesting for each If/For/AsyncFor/While/ExceptHandler/IfExp/Match, 1 flat for a real else, a nesting increment with no base increment for a nested FunctionDef/AsyncFunctionDef/Lambda, one per RUN of like operators inside a BoolOp, and 1 for a recursive call. An elif chain is FLATTENED before descent: the parser nests it inside orelse, so a naive recursion both double-counts and over-nests every ladder. census() walks the declared source paths (excluding __pycache__), keying each function on (relative path, qualified name) so a module move is spelled rather than double-counted, and returns every source-function row plus a per-module public-symbol count that is emitted and never compared. main() selects only rows strictly over the threshold for baseline comparison, reads docs/complexity-baseline as tab-separated rows, compares by exact equality in both directions, prints the three sanctioned remedies on a finding, and honours no per-site suppression token from the scanned source; --report always exits 0, --restamp rewrites the baseline and compares nothing, --mode warn (the default) reports a divergence but still exits 0, and --mode enforce returns nonzero on a divergence in either direction. Standard library only. The shipped downstream template remains REPORT-ONLY: it wires no [step:complexity], so its enforce capability is exercised by this module'… [225 more chars — read the registry row]
Rationale
The counting rules are pinned in this module's own docstring rather than delegated, because a census whose rules live in a third-party tool has a baseline that is a property of that tool's version: an upgrade that began counting a new construct would invalidate every entry at once, with no code having changed. Keying on (path, qualified name) rather than on the bare name is what lets a function move between modules as one re-keyed row instead of appearing twice. The absence of a per-site suppression token is stated here rather than left to the implementation because it is the clause most likely to be added later as a convenience: scattered opt-outs self-replicate as new code copies them, and a central file is the only form of this escape hatch that stays auditable in one read. Method
In-process unit cases over the counting function, pinning the metric a naive implementation gets wrong. The two traps: an elif ladder of n arms scores n rather than the inflated nested figure (and, in reverse, a written-out else:-if genuinely nests and scores strictly more), and a BoolOp scores per RUN of like operators — a and b and c is one, a and b or c is two. A nested def takes a nesting increment with no base increment and produces no census row of its own, while Appendix A's decorator shape is exempt; a flat else is one increment with no nesting. An oracle battery transliterates the Sonar white paper's own worked examples (Appendix C overriddenSymbolFrom = 19, WildcardPattern.toRegexp = 20, sumOfPrimes = 6 after the label-jump the Python form cannot express), the only external check on a metric with no reference suite. SLOC excludes blanks, comments and docstrings; the public-symbol count ignores underscored names. The baseline round-trips LF-only under a debt-statement header, preserves the reason column across a re-stamp, and the census does not list the checker's own module above the threshold. The threshold boundary is pinned EXCLUSIVE (`>`, the one reading SR-183, LLR-206 and the baseline share): a function scoring exactly the threshold is under it and is not baselined, one below is. A module-level def wrapped in any control-flow container (`for`/`while`/`match`, not only `if`/`try`/`with`) is collected as a census row without descending into a function body.
