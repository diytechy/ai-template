SR-209Every commit the loop makes carries a checked provenance trailerre-attest owed

Requirement

When a commit is made from a process the unattended loop started, or is merged in a lane the loop owns from the point the loop took that lane over, the delivered commit floor shall refuse it unless it carries a valid provenance trailer naming the loop and its session.

Rationale

A status change on a human-held rung can be told apart from a human's only if every loop-made commit says it is one. Without a floor that holds every loop commit to it, a trailer could appear on only some of the loop's commits and a missing one would prove nothing. Where a commit is made, the condition is who made it, not when: a person committing in another checkout while the loop runs is not the loop. Where a lane merges, the floor sees commits, not processes, so it reads whose lane it is from the commits and judges every commit of a loop lane, a person's included: there an unmarked commit the loop made cannot be told from a person's, and a person's commit belongs in the person's own lane. The commits made before the loop took a lane over are exempt, since nothing then could have marked them. Refusing the unmarked commit at the floor makes the mark total, which is what lets a later check treat its absence as meaningful. The floor where a commit is made is local and a determined bypass defeats it, which is why the merge re-checks a loop lane and the history check stands behind both.
