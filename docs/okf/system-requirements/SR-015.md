# SR-015 — Performance-budget back-links

**Requirement.** The performance-budgets registry (PB-###) shall keep every row's Refs resolvable to a real SR/LLR/Module.

**Acceptance criteria.** A PB row with an unresolvable or empty Refs is a finding; a resolvable one passes.

**Rationale.** Realizes SN-002 — the off-spine budget rows stay traceable to the spine.
