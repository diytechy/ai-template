# SR-028 — Coordinator typed outcomes

**Requirement.** agent_loop.py shall end each session in a typed outcome code, guard a zero-commit HEAD, and report an all-ERROR stall as an unavailable agent rather than a work stall.

**Acceptance criteria.** A repo with no commits does not crash the loop; an agent-CLI error is logged ERROR; an all-ERROR region is reported as an unavailable agent.

**Rationale.** Realizes SN-006, SN-019 and SN-020 — a coordinator ending in an untyped code forces its caller to parse prose, and an all-ERROR run reported as a work stall sends a human looking for a blocked work item that does not exist. Treating an agent error as a stall was rejected for that reason: the two need different responses, so they need different outcomes.
