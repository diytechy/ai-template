# SR-124 — Contradiction-safe dual-plan dispatcher class

**Requirement.** schedule.py shall derive a contradiction-safe single-WI scheduling class from PlanMode.

**Acceptance criteria.** PlanMode derives a single-WI class, and a contradictory SafetyClass quarantines the row.

**Rationale.** Realizes SN-024 — a row whose PlanMode and SafetyClass disagree has no correct lane, and guessing one dispatches contradictory work rather than surfacing the contradiction. Defaulting to the safer class was rejected: it hides a registry error that only a human can resolve.
