# SR-018 — Privacy gate two-axis

**Requirement.** check_privacy.py shall add PII/identity classes when docs/privacy-check is on, exempting configured author identities.

**Acceptance criteria.** With privacy-check on, an identity/PII class is flagged unless the author is in EXEMPT_EMAILS; with it off, only the secrets floor runs.

**Rationale.** Realizes SN-009 — identity and PII classes are a policy choice a repo makes about its own contributors, unlike a leaked credential, so they layer above the always-on floor rather than replacing it. Making them always-on was rejected: it would flag every legitimate authorship line and train the reader to ignore the scanner.
