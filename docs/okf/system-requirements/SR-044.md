# SR-044 — Declared-interface connectivity

**Requirement.** trace.py shall integrity-check the IF-### interface-seam registry (id shape/uniqueness, SR-Refs resolution, and a best-effort ThisProject-vs-LLR-Module advisory); check_trajectory.py shall emit warn-first architecture-connectivity coverage (every arch-map module is a declared IF endpoint or an explicit source/sink, each Active seam is TC-cited, a Contracts: IF-### docstring matches the registry), opt-out and default-on so a multi-module arch-map with no declared seams reads connectivity-undeclared; and gen_trajectory.py / gen_arch_map.py shall render the declared seams as a graph in PROJECT_STATE.html and the arch-map dependency diagram.

**Acceptance criteria.** trace.py --strict flags a malformed/duplicate IF id or an IF row whose SR-Refs is empty or unresolvable; a multi-module arch-map with an empty or absent interfaces.csv warns connectivity-undeclared while docs/interfaces-check: off or a <=1-module inventory stays vacuous; a covered module missing a direction warns unless a source/sink Notes marker suppresses it; a docstring-declared Contracts IF id absent from the registry warns; the How-SW panel renders module/file/external nodes with IF-labeled edges when seams exist and stays a bare module table otherwise; every connectivity warn leaves the exit code and every gate and hook unchanged.

**Rationale.** Realizes SN-023 (progress AND relationships from one dashboard) and SN-002 (the seam tier joins the mechanically-verified spine — WI-056 closed the SR-002-era gap where trace.py never read the IF-### catalog; the AXES ratification sanctioned it: a cross-component edge without a declared interface is a finding). Coverage is warn-first so it never blocks a gate or hook; docs/interfaces-check: off silences it.
