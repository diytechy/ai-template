# SR-040 — Per-phase routing and review dial

**Requirement.** The unattended coordinator shall select the agent command template per in-process session phase (PLAN/BUILD/REVIEW-A/REVIEW-B/DESIGN-CHECK/CRITIQUE - the coordinator's own activity; the retired docs/run-phase file, deleted by SR-059, is not an input) via AGENT_CMD_MAP/--cmd-map, falling back to the single AGENT_CMD; surface the declared reviewer dial (docs/review-policy, default 1) at run start without enforcing it; and warn (never block) when a lane resume surface exceeds the declared size threshold.

**Acceptance criteria.** A mapped session phase invokes its own command template and the default template does not fire; a broken map entry fails preflight before iteration 1; the banner surfaces docs/review-policy; an oversized status.md warns on stderr while the run proceeds; AGENT_STATUS_WARN_BYTES=0 silences.

**Rationale.** Realizes SN-006 and SN-016 — the AGENT_ROLES R1/R3/R6 build calls: cross-family review routing is first-class (two samples of one model share blind spots; cross-family is the recommended review-policy 2 pairing), review dispatch stays the zero-code in-process-phase convention (rekeyed off the SR-059-deleted docs/run-phase by WI-207, audit-108 finding 1), and the resume surface has a warn-only growth tripwire.
