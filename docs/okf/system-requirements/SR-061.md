# SR-061 — Parallel-by-default dispatcher

**Requirement.** agent-resume shall launch a dispatcher/integrator with bounded parallelism (--jobs, default 2; --jobs 1 serial; auto adaptive to a ceiling; AGENT_JOBS env) running the reconcile->gate->build-out launch sequence: reconcile owned trains to a clean baseline, clear the gated spine serially whole-project (exiting for ratification per gate-policy), then pack the unblocked frontier into traincars and dispatch any dependency-clear traincar to a free worker.

**Acceptance criteria.** A launch with independent ready WIs runs up to the ceiling concurrently in separate worktrees and refills a free lane while others stay busy; spine/gate work stays serial; --jobs 1 produces the same integrated result set as a serial run.

**Rationale.** Realizes SN-025 and SN-016 — one worker at a time leaves the frontier's independent work serialized behind whatever happens to be first, and a static wave stalls every lane until the slowest finishes. Fixed-size waves were rejected for that reason: the engine has to refill a free lane while the others stay busy, which a wave cannot do.
