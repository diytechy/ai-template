# SR-061 — Parallel-by-default dispatcher

**Requirement.** agent-resume shall launch a dispatcher/integrator with bounded parallelism (--jobs, default 2; --jobs 1 serial; auto adaptive to a ceiling; AGENT_JOBS env) running the reconcile->gate->build-out launch sequence: reconcile owned trains to a clean baseline, clear the gated spine serially whole-project (exiting for ratification per gate-policy), then pack the unblocked frontier into traincars and dispatch any dependency-clear traincar to a free worker; it shall reserve a selected traincar's constituent WIs atomically via refs/llm/reservations/WI-### (an off-history commit-tree metadata commit plus one update-ref --stdin zero-old-value transaction), lease a linked worktree per train, rescan on every release/completion/block/verdict/integration for dynamic refill, and honor pause/blackout/model-capacity limits.

**Acceptance criteria.** A launch with independent ready WIs reserves and runs up to the ceiling concurrently in separate worktrees and refills a free lane while others stay busy; the atomic reservation transaction claims all constituents or none; spine/gate work stays serial; pause stops new reservations at the next boundary; --jobs 1 produces the same integrated result set as a serial run.

**Rationale.** Realizes SN-025 and SN-016 - the central fan-out engine: optimistic bounded parallelism over the derived frontier with durable Git reservations, never a static wave, never wedged by a prompt (docs/specs/parallel-wi-dispatch.md 4/6).
