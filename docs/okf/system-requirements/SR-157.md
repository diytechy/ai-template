# SR-157 — Prompt and route provenance in every session record

**Requirement.** Every session, outcome and verdict record shall carry the template identity and hash, the rendered-prompt hash, the route identity, the model and the source-artifact hashes used.

**Acceptance criteria.** Each launched session records the template identity and hash, the rendered-prompt hash, the route identity and the model; two renders of one template with one input produce one hash; a template edit changes the recorded template hash.

**Rationale.** Without provenance a recorded verdict cannot be reproduced or challenged: nobody can tell which prose produced it or which model read it. Recording the hashes rather than the prompts keeps the record small and keeps prompt content out of the tracked history.
