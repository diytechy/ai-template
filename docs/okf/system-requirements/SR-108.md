# SR-108 — Dual-plan round disposition

**Requirement.** The --dual-plan round shall commit SELECT as a docs-only disposition (children filed as queued specs, validated atomically with their generated views) and surface PAGE per gate policy, never silently.

**Acceptance criteria.** SELECT files children that pass the registry validator; a PAGE preserves the round's evidence on disk.

**Rationale.** Realizes SN-024 and SN-016 — a disposition split across commits can land half-applied, and halting every lane for one round's outcome throws away the parallelism for work the outcome does not touch. Applying the disposition per-lane was rejected: the registries are shared, so concurrent writers conflict on every one.
