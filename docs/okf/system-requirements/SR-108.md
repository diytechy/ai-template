# SR-108 — Serialized dual-plan disposition

**Requirement.** The dispatcher shall commit SELECT or PAGE as one serialized docs-only disposition without pausing disjoint work under autonomous policy; both it and the --dual-plan single-shot round shall map a PAGE through gate policy: hard-gate a human only under attended and otherwise reach the pause-free attention (STALL) end state.

**Acceptance criteria.** SELECT files children and closes the parent only after regenerated validation; a PAGE preserves evidence and follows attended/autonomous policy at both the dispatcher disposition and the --dual-plan single-shot round (attended -> NEEDS-HUMAN; autonomous/single-ratify -> RUNNING + EXIT_STALL; never a human gate); disjoint autonomous work continues.

**Rationale.** Realizes SN-024;SN-006 by isolating one independently reviewable obligation formerly carried by SR-066.
