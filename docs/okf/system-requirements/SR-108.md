# SR-108 — Serialized dual-plan disposition

**Requirement.** The dispatcher shall commit SELECT or PAGE as one serialized docs-only disposition without pausing disjoint work under autonomous policy.

**Acceptance criteria.** SELECT files children and closes the parent only after regenerated validation, and disjoint autonomous work continues.

**Rationale.** Realizes SN-024 and SN-016 — a disposition split across commits can land half-applied, and halting every lane for one round's outcome throws away the parallelism for work the outcome does not touch. Applying the disposition per-lane was rejected: the registries are shared, so concurrent writers conflict on every one.
