# SR-116 — Generated status surface

**Requirement.** The trunk lane shall maintain docs/status.md's generated snapshot as a freshness-gated reference surface never written on a worker branch (trunk_step --regen; concurrency-restructure SS5.2). (The docs/run-state half of this row retired with the dispatcher at Phase 5.)

**Acceptance criteria.** The status snapshot regenerates on the trunk after a merge and fails its freshness gate when stale; work branches skip the gate and never commit the artifact.

**Rationale.** Realizes SN-010 — an agent-authored status surface drifts from the state it reports and is trusted anyway, and a worker branch writing it makes the snapshot describe one lane instead of the project. Letting each worker append its own status was rejected: it produces a file that conflicts on every integration and reports no coherent whole.
