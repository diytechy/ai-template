# SR-053 — Dashboard UI uniformity (rubric-adjudicated)

**Requirement.** PROJECT_STATE.html shall read as one system across its tabs and views: one type scale and spacing rhythm; one status/phase/type color vocabulary applied consistently wherever the same concept renders; uniform node, edge, legend, and detail-panel styling across the SVG emitters; the same interaction idiom (expand, hover, detail) wherever the same structure appears.

**Acceptance criteria.** A fresh family-heterogeneous CRITIQUE session judging the generated dashboard against docs/rubrics/dashboard-uniformity.md (authored at [v3]-[g2]) returns APPROVE citing numbered anchors; type scale, color vocabulary, per-emitter node/edge/legend styling, and interaction-idiom consistency are each a rubric anchor.

**Rationale.** Realizes SN-024 and SN-023 — how alike is alike enough is subjective at the margins, so cross-view coherence cannot be pinned to a threshold without pinning the wrong thing. It is adjudicated against a written rubric by an independent session rather than by the authoring build, because the build and its author share the assumptions that produced the output: a self-judged view is checked against the intent that made it, not against a reader meeting it cold.
