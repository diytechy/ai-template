# SR-169 — The state view shows how the parts connect

**Requirement.** The delivered generator set shall render the adopted repository's declared structural units and the seams between them as a navigable graph — containment shown at more than one level with seams terminating at the containing boundary — degrading to a stated fallback rather than an empty view when the repository carries the source registries but declares no seams in them, the absent-registry case being the artifact contract's omission rule and not this row's.

**Acceptance criteria.** Declared structural units render with their containment preserved at each visible level; declared seams terminate at the correct ports and aggregate at a container boundary without duplicating an edge; descending a level and returning restores the reader's prior place; a repository whose source registries are present but declare no seams in them renders the stated fallback rather than an empty view.
