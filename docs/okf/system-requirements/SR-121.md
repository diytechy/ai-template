# SR-121 — Gated downstream migration to the parallel default

**Requirement.** A repo shall run --jobs 1 until both its soft-edge audit (correctness edges promoted to hard) and its SafetyClass audit (every open WI reviewed-classified) pass, then flip to the two-worker default as a recorded promotion, reconciling legacy active rows and docs/tracks/* within one compatibility window.

**Acceptance criteria.** Migration keeps a repo at --jobs 1 until both audits pass and records the two-worker promotion; legacy active rows and tracks reconcile with a logged finding; a non-adopting repo is unaffected.

**Rationale.** Realizes SN-012 — optimistic parallelism is sound only where the DAG's correctness edges are actually hard and every open WI is classified, so flipping the default before those audits dispatches conflicting work concurrently. Flipping on adoption and fixing the audits afterwards was rejected: the first concurrent conflict is what teaches the lesson.
