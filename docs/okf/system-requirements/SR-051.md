# SR-051 — Tiered drill-down views

**Requirement.** gen_trajectory.py shall render the When (roadmap DAG) and How-SW (module map) views as count-thresholded, click-to-explode hierarchies: the When view tiers phase -> workstream -> work item (a tier renders as collapsed blocks when its member count exceeds 3 and flat at or below), surfaces each work item delivery Phase, and draws parent-to-parent edges aggregated from the deduped union of child edges (the WI-074 idiom); the How-SW view starts at component blocks when top-level components exceed 3 and explodes into modules (the WI-073 containment generalized); the views render interface-wired - IF-### seams attach to their endpoints' block input/output ports at every tier, a cross-container seam aggregated to the container boundary (Simulink-style); double-click (with a keyboard alternative) on a container block descends one layer into it and a breadcrumb path returns; the interaction stays self-contained (no external fetches), byte-deterministic, with --check freshness unchanged.

**Acceptance criteria.** With more than 3 phases the When view starts at phase blocks exploding to workstreams then work items, flat at or below each threshold; the phase encoding is visible; each aggregated parent edge equals the deduped union of its children crossing edges; with more than 3 components the How-SW view starts at component blocks; each rendered seam attaches to its endpoints' block ports at the visible tier and aggregates to the container boundary when it crosses one; double-click (or its keyboard alternative) on a container descends one layer and the breadcrumb restores the prior view; a bundle-/data-less repo renders byte-identically; deterministic; --check trips on stale output.

**Rationale.** Realizes SN-010/SN-021 per the owner stated intent 2026-07-12 (docs/specs/WI-087.md): a large project must read top-down - Simulink-style blocks a viewer clicks into - instead of one dense graph; generalizes the shipped campaign-binning (WI-074) and component-containment (WI-073) idioms into uniform tiering. REV 2026-07-14 ([v3]-[g1]/WI-134, the owner-sanctioned amendment - the 2026-07-13 ratification note recorded amendments arrive as future WIs, not blockers): descend-a-layer navigation supersedes the Q3 in-place-expand/no-zoom provisional ruling, and seams wire to block ports (owner intake item 1C); the data-side graph extensions (typed-IF contracts, cyclic render) stay WI-064 (soft edge).
