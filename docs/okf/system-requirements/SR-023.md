# SR-023 — Arch-map generation

**Requirement.** gen_arch_map.py shall regenerate the symbol map inside its marker block and, under --check, fail when the committed map has drifted from source.

**Acceptance criteria.** --check fails when the map is stale and passes when current; regeneration rewrites only the marker block.

**Rationale.** Realizes SN-010 and SN-021 — a generated view cannot silently rot; --check makes drift a red.
