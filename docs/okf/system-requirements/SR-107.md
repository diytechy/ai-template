# SR-107 — Dual-plan direct-path isolation

**Requirement.** The worker shall refuse a dual row on the direct path.

**Acceptance criteria.** Direct workers reject dual rows and --dual-plan rejects non-dual rows.

**Rationale.** Realizes SN-024 and SN-006 — a dual-plan row built by the direct worker skips the competing-plan round that is the whole reason it was marked dual, and the skip is silent. Letting the worker fall back to a single plan was rejected: it produces a plausible result that nobody knows was never contested.
