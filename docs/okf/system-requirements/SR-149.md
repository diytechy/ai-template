# SR-149 — One immutable outcome event per attempt

**Requirement.** Every attempted branch shall write one immutable outcome event recording its worker outcome, its claim-base and tip commits, its scope digest and its evidence, outside the work-item registry.

**Acceptance criteria.** Each terminal branch writes exactly one event; a second write for the same attempt is refused; the event carries the outcome enum, both commits, the scope digest and the checks run with their results; no field of the event is read as an instruction.

**Rationale.** The recurring return-handling defects share one cause: the return had no identity of its own, so every consumer derived one from an observer and no two derivations agreed. An event with its own identity removes the derivation entirely, and keeping it out of the work-item folder keeps the registry loader's file pattern honest.
