# SR-026 — Coordinator resumes headless

**Requirement.** agent_loop.py shall resume headless with stdin closed, never blocking on a prompt. Resume authority per mode (audit-108 finding 4): the serial resume loop resumes from docs/status.md; the parallel dispatcher (SR-061) derives resume/recovery authority from the WI registry plus durable Git reservations (SR-057/SR-064), docs/status.md being its integrator-generated reference surface (SR-059).

**Acceptance criteria.** The serial loop reads its next action from docs/status.md; the dispatcher reconciles from the registry + reservations; every mode runs with stdin closed and a prompt cannot wedge it.

**Rationale.** Realizes SN-006 (resumable unattended run) and SN-016 (never wedged by a prompt) (IMPROVEMENT_PLAN.md Threads 33/45; the per-mode authority split recorded by WI-207).
