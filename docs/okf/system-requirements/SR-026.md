# SR-026 — Coordinator resumes headless

**Requirement.** agent_loop.py shall resume from docs/status.md and run headless with stdin closed, never blocking on a prompt.

**Acceptance criteria.** The loop reads its next action from docs/status.md and runs with stdin closed; a prompt cannot wedge it.

**Rationale.** Realizes SN-006 (resumable unattended run) and SN-016 (never wedged by a prompt) (IMPROVEMENT_PLAN.md Threads 33/45).
