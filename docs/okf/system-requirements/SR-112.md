# SR-112 — Checked per-agent skill fan-out

**Requirement.** The per-agent skill copies shall be a checked, generated fan-out of the one neutral skill source.

**Acceptance criteria.** A per-agent copy that diverges byte-for-byte from source is detectable and refreshed by one command. Read off the current carrier, as the current set: the .claude/.gemini/.agents copies generated from project-trajectory/skills/.

**Rationale.** Realizes the dissolved edge expectation that a generated artifact drifting from its source fails its --check — one skill maintained in three agent-specific copies rots into three different skills, and the copy an agent actually loads is the one nobody edited. Maintaining a single shared directory was rejected because each agent harness looks in its own path; the fan-out is forced, so the copies are generated and drift is a finding. Hat-derived (hat.MAINTAINER): the same lens, its other half — a generated copy that does not declare itself generated is the commonest way a reader loses work by editing it, and one skill fanned into three per-agent copies is that surface multiplied by the number of harnesses.
