# SR-025 — Skills index + checked per-agent fan-out

**Requirement.** gen_skills_index.py shall regenerate skills/INDEX.csv from each SKILL.md applicability frontmatter, and the per-agent skill copies (.claude/.gemini/.agents) shall be a checked, generated fan-out of the one neutral skills/ source — a copy that drifts from source is detectable and refreshed by one command.

**Acceptance criteria.** The regenerated INDEX.csv reflects the current SKILL.md frontmatter; a drifted index — or a per-agent copy that diverges byte-for-byte from source — is detectable.

**Rationale.** Realizes SN-012 (opt-in accelerators) and SN-021 (both the index and the per-agent fan-out are generated, not hand-maintained — gated like the arch map, so cross-agent copies cannot silently rot).
