# SR-025 — Skills index + checked per-agent fan-out

**Requirement.** gen_skills_index.py shall regenerate skills/INDEX.csv from each SKILL.md applicability frontmatter.

**Acceptance criteria.** The regenerated INDEX.csv reflects the current SKILL.md frontmatter, and a drifted index is detectable.

**Rationale.** Realizes SN-012 (opt-in accelerators) and SN-021 — a hand-maintained index drifts from the skills it indexes, and an index that disagrees with its sources is worse than none, because it is trusted. Requiring each author to update the index by hand was rejected for the same reason the traceability matrix is generated: the discipline fails silently.
