# SR-025 — Skills index generation

**Requirement.** gen_skills_index.py shall regenerate skills/INDEX.csv from each SKILL.md applicability frontmatter.

**Acceptance criteria.** The regenerated INDEX.csv reflects the current SKILL.md frontmatter; a drifted index is detectable.

**Rationale.** Realizes SN-012 (opt-in accelerators) and SN-021 (the index is generated, not hand-maintained).
