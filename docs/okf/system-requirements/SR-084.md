# SR-084 — Independent subjective-quality critique dispatch

**Requirement.** The coordinator shall trigger a fresh family-heterogeneous Critique session only for Critique-scoped builds and construct its brief from rubric, intent, and artifact recipe without self-assessment.

**Acceptance criteria.** Critique-scoped builds schedule the session; other builds do not; the prompt contains rubric/intent/recipe and excludes build transcript and self-assessment.

**Rationale.** Realizes SN-026;SN-024;SN-006 by isolating one independently reviewable obligation formerly carried by SR-047.
