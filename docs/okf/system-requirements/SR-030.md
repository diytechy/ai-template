# SR-030 — Second coordinator refused

**Requirement.** agent_loop.py shall refuse a second coordinator in the same checkout, preventing a two-writer race.

**Acceptance criteria.** A second coordinator on a held lock is refused; only one writer runs per checkout.

**Rationale.** Realizes SN-018 and SN-006 — mutual exclusion protects the working tree (IMPROVEMENT_PLAN.md Parallel tracks).
