# SR-030 — Second coordinator refused

**Requirement.** agent_loop.py shall refuse a second coordinator in the same checkout, preventing a two-writer race.

**Acceptance criteria.** A second coordinator on a held lock is refused; only one writer runs per checkout.

**Rationale.** Realizes SN-018 and SN-006 — two coordinators in one checkout write the same working tree, and the loser's commits interleave into the winner's diff where no review will separate them. Coordinating by convention was rejected: the failure is silent and shows up only as a garbled history.
