# SR-153 — Ready work derives from tracked state

**Requirement.** The delivered loop content shall derive the work it dispatches next from the repository's tracked registries and git history alone — the eligible set and its order deterministic, and an item whose declared safety, policy or plan-mode inputs are missing, undeclared or contradictory failing closed for that item only — never from prose or a hand-maintained pointer.

**Acceptance criteria.** Two resumes over the same tracked state select the same eligible set in the same order; an item with missing or contradictory declared inputs is excluded with a stated reason while disjoint classified work stays eligible; no prose surface participates in the derivation; the ordering and exclusion reasons are exposed for replay.

**Rationale.** Realizes SN-025 (self-direction from tracked state — its acceptance names exactly this contract), SN-027 (the DAG encodes what may proceed), SN-006 and SN-008 (a dishonest declaration cannot buy scheduling), with SN-024 via the plan-mode classification input.
