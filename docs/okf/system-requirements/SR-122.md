# SR-122 — Dashboard freshness check

**Requirement.** gen_trajectory.py --check shall fail on stale or missing output, the visible git-derived as-of stamp being excluded from stamp-only comparisons.

**Acceptance criteria.** Stale or missing output fails --check, and as-of behavior is stable in and outside Git.

**Rationale.** Realizes SN-021 — a committed dashboard that nobody re-checks becomes a confident picture of a project that has moved on, and the as-of stamp changes on every commit, so comparing it would make the check cry wolf and get disabled. Regenerating on read was rejected: the artifact is committed so it can be read without the toolchain.
