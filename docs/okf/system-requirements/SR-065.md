# SR-065 — Parallel-execution telemetry and downstream migration

**Requirement.** The dispatcher shall record reason-coded telemetry (frontier decisions, reservation, worker and reviewer start and finish, continuation, fork, join, overlap, conflict, re-review, integration, recovery, quarantine, cleanup) aggregated by (train, WI, session), surfacing a banner of active lanes, frontier, integration queue and cost ceiling.

**Acceptance criteria.** Telemetry emits the reason-coded events and required measurements aggregated per (train, WI, session) with no cross-session id collision, and the banner reports lanes, frontier, queue and ceiling.

**Rationale.** Realizes SN-025 and SN-012 — capacity tuned by intuition is tuned against whatever the last run felt like, and a parallel run with no per-lane record cannot be debugged after it ends because the lanes are gone. Logging free text was rejected: reason codes are what make the events countable.
