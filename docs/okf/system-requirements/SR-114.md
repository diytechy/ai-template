# SR-114 — Kit scripts run across the supported OSes

**Requirement.** The kit scripts shall run on Python 3.11+ across Linux, Windows and macOS.

**Acceptance criteria.** The CI matrix spans Linux, Windows and macOS on Python 3.11 and latest (3.x) and is green; the macOS+3.11 cell is excluded as a redundant-coverage call recorded in the rationale; the hosted matrix as an evidence surface is SR-152's contract.

**Rationale.** Realizes SN-011 — a script that works only where its author ran it turns portability into a defect the adopter finds, and the path, line-ending and locking differences that break it are invisible on a single platform. Testing one platform and reading the others by inspection was rejected: every one of those differences has been a real failure here. The macOS exclusion argument: the 3.11 floor is a platform-agnostic language/stdlib guarantee already exercised on Linux and Windows, while macOS's job is OS-specific behavior (fcntl.flock, paths, git worktrees) that does not vary by Python version — a redundant-coverage call, not a runner-availability workaround (3.11 has arm64 macOS builds).
