# SR-039 — Duplicate-code lint

**Requirement.** check_dupes.py shall report any window of at least a configurable minimum of consecutive significant source tokens appearing at more than one location, and exit nonzero unless the finding's file pair is recorded in the allowlist.

**Acceptance criteria.** A copy-pasted helper across two files exits 1 naming both file:line locations; clean source exits 0; raising --min-tokens above the block's length passes; a docs/dupes-allow recorded pair suppresses the finding.

**Rationale.** Realizes SN-008 — the working agreement's one-fact-one-home rule is mechanized for code too (Thread 53, adapted from the proven gilbert detector); an opt-in product-layer step wired via a stack-profile line, so a non-adopter pays nothing.
