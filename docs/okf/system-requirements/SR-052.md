# SR-052 — Dashboard accessibility (rubric-adjudicated)

**Requirement.** PROJECT_STATE.html shall be operable and readable without a pointer or full color perception: every interactive element (tabs, expandable blocks, SVG nodes with detail panels) is keyboard-reachable and carries an accessible name (title/aria/visible text); no information is encoded by color alone (status/phase/type encodings carry a text or shape cue); text keeps readable contrast against its fill.

**Rationale.** Realizes SN-024 and SN-023 — perceptual accessibility has no crisp measurable interface, so a row claiming a mechanized verification would assert a green that nothing actually checks.
