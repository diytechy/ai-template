# SR-032 — Onboarding and dev-setup scaffold

**Requirement.** The onboarding and dev-setup templates shall scaffold and run green, and dev-setup shall wire the pre-commit process floor (core.hooksPath) from its baseline.

**Acceptance criteria.** The scaffolded onboard/dev-setup scripts run to a green setup, and dev-setup wires the pre-commit floor (core.hooksPath) so it is active without a separate setup step.

**Rationale.** Realizes SN-001 — a new contributor is onboarded by the generated scripts, protected by the process floor from the rung they actually run.
