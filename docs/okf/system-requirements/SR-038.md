# SR-038 — Offline project-state view

**Requirement.** gen_trajectory.py shall generate a single self-contained offline HTML project-state view at the repository root (PROJECT_STATE.html) presenting definition completeness, execution completeness, the need hierarchy (SN->SR->LLR->TC), the prospective roadmap DAG, the software module-map view when a symbol inventory exists, the component table when CMP rows exist, and a git-derived as-of stamp visible on open, usable on desktop and mobile viewports, byte-deterministic, with --check failing the gate when the artifact is stale or missing (the as-of line alone excluded from the compare).

**Acceptance criteria.** The output is one root HTML file with no external fetches; the completeness tiles, the SN->SR->LLR->TC icicle and the roadmap DAG render from the registries; the module-map view renders from a committed symbol inventory and is omitted without one; the as-of line appears in a git repo, is absent outside one, and a stamp-only difference does not trip --check; the responsive shell is present; generation is byte-deterministic; --check trips on stale or missing output.

**Rationale.** Realizes SN-010 and SN-021 — project state is inspected from one generated, freshness-gated artifact that cannot silently rot (THREAD_52_REVIEW.md F1; WI-039 landed 2026-07-10 per the ratified AXES artifact spec: the HOW views, the root artifact and the git-derived stamp are now claimed - the stamp derives from the last source-touching commit, never now(), keeping generation deterministic).
