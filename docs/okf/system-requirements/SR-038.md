# SR-038 — Offline project-state view

**Requirement.** gen_trajectory.py shall generate a single self-contained offline HTML project-state view presenting definition completeness, execution completeness, the need hierarchy (SN->SR->LLR->TC) and the prospective roadmap DAG, usable on desktop and mobile viewports, byte-deterministic, with --check failing the gate when the artifact is stale or missing.

**Acceptance criteria.** The output is one HTML file with no external fetches; the definition and execution completeness tiles, the SN->SR->LLR->TC icicle and the roadmap DAG all render from the registries; the responsive shell is present (viewport meta, narrow-viewport single-column collapse, scrolling panels); generation is byte-deterministic; --check trips on stale or missing output.

**Rationale.** Realizes SN-010 and SN-021 — project state is inspected from one generated, freshness-gated artifact that cannot silently rot (THREAD_52_REVIEW.md F1; owner scope ruling 2026-07-09: the HOW view and the root PROJECT_STATE.html evolution are roadmapped as WI-039, not claimed here).
