# SR-125 — PAGE maps through the declared ratification level

**Requirement.** The --dual-plan single-shot round shall map a PAGE through the declared ratification level, hard-gating a human only while the tier in process is still HUMAN-HELD and otherwise reaching the pause-free attention (STALL) end state.

**Acceptance criteria.** A PAGE preserves evidence and follows the declared level (a human-held tier -> NEEDS-HUMAN exit; a loop-held tier -> STALL exit, no human gate); an unreadable level or stage resolves to human-held, so the failure direction is the gate, never past it.

**Rationale.** Realizes the dissolved edge expectation that an unattended run never blocks on a prompt, at launch or mid-run — a PAGE that always stops for a human makes the unattended loop attended in practice, while one that never stops discards the judgement the round asked for. Two separate mappings for the dispatcher and the single-shot round were rejected: they drift, and the drift shows up as a loop that hangs on one path only.
