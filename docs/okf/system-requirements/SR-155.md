# SR-155 — Strict rendering of every operational prompt

**Requirement.** Every operational prompt shall render from a declared versioned template through one renderer that refuses an unknown slot, a missing required slot or an unrendered placeholder before launch.

**Acceptance criteria.** A template with every required slot supplied renders and launches on standard input; an unknown slot, a missing required slot and a surviving placeholder each refuse before launch; a golden fixture render is byte-stable.

**Rationale.** Prompt prose embedded in code is reviewable only by reading the code, so the clauses that carry redaction and adversarial discipline are invisible to the people who most need to review them. One strict renderer over declared templates makes the prose reviewable and makes a malformed brief a refusal instead of a launched session.
