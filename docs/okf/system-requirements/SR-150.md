# SR-150 — Partial attempts classify every change group

**Requirement.** A partial attempt shall classify every branch commit or coherent change group as keep, discard or quarantine before the integrator accepts the branch.

**Acceptance criteria.** A partial branch with an unclassified change group is refused by name; a fully classified branch is accepted; a quarantined group is reverted to a bar-inert artifact and a discarded group leaves no code behind.

**Rationale.** A returned branch that merged green once landed rejected code as-is, because nothing forced anyone to say which of its changes were wanted. Making the split an admission precondition moves the revert decision to the adjudicator, in the open, instead of leaving it implicit in a merge.
