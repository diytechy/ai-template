# SR-138 — Legacy config converts automatically and totally

**Requirement.** bootstrap.py --migrate-config — run by both bootstrap and the documented re-sync — shall fold every legacy one-word policy file into docs/process.toml and delete it, never deleting a file whose value it did not manage to write.

**Acceptance criteria.** A repo carrying legacy files converts in one pass and reports what moved; a second pass is a no-op; a legacy file whose value cannot be written is LEFT IN PLACE with its value intact and named in the report; the retired gate-authority word expands to all three dials it meant rather than to a single key.

**Rationale.** The hard mixed-config refusal in SR-137 is only safe to ship if a downstream adopter never meets it un-aided. And the converter's own failure mode is the sharp one: an earlier cut deleted a legacy file on the strength of a write that never happened and reported success, destroying a declared `privacy_check = true` under a green `migrated:` line.
