# SR-138 — Mixed-source refusal without silent precedence

**Requirement.** The configuration preflight shall refuse when a canonical configuration key and its retired declared-policy source are both live, listing every conflicting pair.

**Acceptance criteria.** A tree carrying both a canonical key and its retired source refuses at preflight and lists each conflicting pair; a tree carrying only one source of each key passes.

**Rationale.** Two live sources for one behaviour is the failure mode the single-authority need exists to prevent, and a precedence rule hides it rather than fixing it: the adopter reads one file and the loop obeys the other. Refusing converts a silent divergence into a one-time migration step.
