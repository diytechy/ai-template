# SR-160 — Front-door launchers for the two universal contributor actions

**Requirement.** The delivered scaffold shall place both universal contributor actions — preparing the development environment, and resuming the automated development loop — as launchers at the repository root for each supported platform, each starting its action as a single step, or documenting the one platform-required step where a single click is impossible.

**Acceptance criteria.** A fresh scaffold and this repository each carry both launcher sets (dev-setup and agent-resume) at the root for Windows, macOS and Linux; each launches its action as a single step on that platform, or documents the single platform-required step (the Linux execute-bit case); the adopter-facing guide names the capability and invites reuse.
