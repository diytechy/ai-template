# SR-160 — Front-door launchers for the two universal contributor actions

**Requirement.** The delivered scaffold shall place both universal contributor actions — preparing the development environment, and resuming the automated development loop — as launchers at the repository root for each supported platform, each starting its action as a single step — locating a working interpreter by RUNNING a candidate and reporting clearly rather than crashing cryptically when none resolves or a Store alias exits nonzero — or documenting the one platform-required step where a single click is impossible.

**Acceptance criteria.** A fresh scaffold and this repository each carry both launcher sets (environment preparation and loop resume) at the root for Windows, macOS and Linux; each launches its action as a single step on that platform, or documents the single platform-required step (the Linux execute-bit case); with no working interpreter each root launcher reports clearly and does not crash cryptically, and with one it runs its action; the adopter-facing guide names the capability and invites reuse.
