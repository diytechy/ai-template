# SR-049 — Derived gate from artifact states

**Requirement.** The active gate shall be COMPUTED from the spine artifact states (SN section-state + SR/LLR/TC Status maturity) and cached to docs/gate, rather than hand-set, so a gate advances only when the mechanical states do.

**Acceptance criteria.** derive_gate.py --print on the meta computes G3 from the current states; --check exits nonzero when a state change is not reflected in the cached docs/gate basis.

**Rationale.** SSOT applied to the gate itself (docs/specs/derived-gate-model.md): a hand-set marker can be bumped without the work; deriving it makes gate advancement mechanical (SN-004) and un-gameable (SN-008). The hybrid cache keeps the value readable on checkout; --check guards rot.
