# SR-134 — Trunk step regenerates the declared artifacts in dependency order

**Requirement.** The serial trunk step shall regenerate the declared generated artifacts in dependency order - the derived gate before its consumers - failing loudly at the first error and never committing.

**Acceptance criteria.** --regen skips absent artifact families with a notice and stops loudly at the first failing generator; derive_gate runs before the dashboard/status/open-items regens.

**Rationale.** Stale-artifact merge conflicts become unrepresentable when only the serial trunk actor regenerates (§5.2/§5.5); dependency order because docs/gate is an input to the dashboard and status views, not an output. Decomposed from SR-130 so each row states one obligation.
