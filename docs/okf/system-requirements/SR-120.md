# SR-120 — Blocked-constituent disposition

**Requirement.** The integrator shall deliver the durable disposition for a blocked constituent while independent completed constituents still proceed.

**Acceptance criteria.** A blocked constituent receives a durable disposition through the integrator, and independent completed constituents still integrate.

**Rationale.** Realizes SN-025 — a block recorded only in a worker's log dies with the lane, so the next scan re-dispatches the same WI into the same wall. Failing the whole train on one blocked constituent was rejected: it discards completed, independent work.
