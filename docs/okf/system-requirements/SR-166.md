# SR-166 — The delivered package is complete and consumable at its declared manifest

**Requirement.** The delivered package shall be complete and consumable against its own declared shipped-file manifest — every file the manifest names present in the package and materialized at its declared destination in a fresh scaffold, every file the package ships named by the manifest, and this repository's own instance carrying the structure of the template it ships — a named source that is absent, a declared destination a fresh scaffold does not carry, a shipped file the manifest does not name, and a structural divergence between the shipped template and this repository's instance each failing rather than degrading the delivered package silently.

**Acceptance criteria.** A manifest entry whose source the package does not carry fails naming the file; a manifest entry whose destination a fresh scaffold does not contain fails naming the destination; a file the package ships that the manifest does not name fails naming the file; and a structural divergence between the shipped template and this repository's own instance fails naming the surface. Evidence: tests/test_bootstrap.py (manifest against the fresh-scaffold file lists) and tests/test_dogfood_sync.py (shipped template against this repository's instance).
