# SR-072 — Deterministic responsive dashboard freshness

**Requirement.** gen_trajectory.py shall produce byte-deterministic responsive output.

**Acceptance criteria.** Repeated generation is byte-identical, and mobile CSS is present.

**Rationale.** Realizes SN-010 and SN-021 — a generated dashboard that differs between runs cannot be freshness-checked, because every check reports a diff and the real staleness hides among them. Comparing rendered screenshots was rejected: it is expensive and still non-deterministic.
