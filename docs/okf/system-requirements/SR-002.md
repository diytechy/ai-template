# SR-002 — Integrity floor for ids and CSV structure

**Requirement.** trace.py shall fail --strict-integrity on a duplicated or malformed registry id, a data row whose column count differs from its header, or a TC that pairs an LLR with an SR it does not decompose.

**Acceptance criteria.** --strict-integrity exits 1 on a duplicate/malformed SR/LLR/TC/PB/MOD/PART/ASSET id, a mis-columned row, or an incoherent SR/LLR pairing in one TC, and 0 otherwise; orphans do not affect it.

**Rationale.** Realizes SN-002 — a misaligned or duplicated id corrupts the join before the orphan rules would notice, and an incoherent SR/LLR citation contradicts the LLR's own parent link; wrong at any stage, not just at a gate (the citation-coherence rule is IMPROVEMENT_PLAN.md Thread 50).
