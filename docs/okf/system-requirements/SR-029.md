# SR-029 — Coordinator lock auto-release

**Requirement.** The per-worktree coordinator lock shall be a kernel advisory lock the OS releases on process death, leaving no stale-pid wedge.

**Acceptance criteria.** After the lock holder dies, the next run acquires the lock; no stale-pid file blocks it.

**Rationale.** Realizes SN-017 — a lock recorded as a pid in a file outlives the process that died holding it, and the next run wedges on an entry nobody can safely clear. A pid file plus a liveness check was rejected: the check races, and on a reused pid it clears a live lock. A kernel advisory lock releases on process death by construction.
