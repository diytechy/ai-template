# SR-029 — Coordinator lock auto-release

**Requirement.** The per-worktree coordinator lock shall be a kernel advisory lock the OS releases on process death, leaving no stale-pid wedge.

**Acceptance criteria.** After the lock holder dies, the next run acquires the lock; no stale-pid file blocks it.

**Rationale.** Realizes SN-017 — a killed coordinator does not wedge the next run (IMPROVEMENT_PLAN.md Parallel tracks; re-scoped: the lock outlives the retired track lanes — the dispatcher, each worker, and an interactive sitting take it).
