# SR-021 — Hook python probe

**Requirement.** The git hooks and the root launchers (dev-setup / agent-resume, the coordinator's entry) shall locate a working python3 by running a candidate and skip-or-report clearly when none resolves or a Store-alias exits nonzero.

**Acceptance criteria.** With no working python3 the hook and each root launcher report clearly and do not crash cryptically; with one, they run their action.

**Rationale.** Realizes the dissolved edge expectation that the interpreter is probed by running a candidate — no cryptic crash when the interpreter is absent or a Windows Store alias. (The launcher half joined the hooks' at the 2026-08-13 SN dissolution.)
