# SR-021 — Hook python probe

**Requirement.** The git hooks shall locate a working python3 by running a candidate and skip-or-report clearly when none resolves or a Store-alias exits nonzero.

**Acceptance criteria.** With no working python3 the hook reports clearly and does not crash; with one, it runs the checks.

**Rationale.** Realizes SN-013 — no cryptic crash when the interpreter is absent or a Windows Store alias.
