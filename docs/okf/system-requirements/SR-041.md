# SR-041 — Doc reference validation

**Requirement.** check_doc_refs.py shall flag a documentation reference to a repository path that does not exist and an asserted sym:<module>.<name> reference missing from the generated module-map inventory, warn-first (exit 0) with --strict gating; absent inventory skips the symbol tier cleanly.

**Acceptance criteria.** A backticked repo path that does not exist warns and gates only under --strict; URLs, globs, placeholders, generated blocks and path-ok lines are ignored; a dangling sym: reference is flagged against the module map; with no inventory the symbol tier skips and the path tier still runs.

**Rationale.** Realizes SN-004 and SN-008 — the two rot classes link resolution cannot see (Thread 49): prose naming a renamed/deleted file, and an asserted code symbol that no longer exists. False-positive control is the design boundary: only path-shaped tokens and the explicit sym: convention are validated, never every backticked word; generated marker blocks and path-ok lines are exempt.
