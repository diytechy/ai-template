**Requirement.** check_stubs.py shall detect stub/placeholder markers in source at its declared gate and fail when one is present.

**Acceptance criteria.** A stub/NotImplemented/pass-only public function at the declared gate fails; clean source passes.

**Rationale.** Realizes SN-008 — a green never hides a stub.
