# SR-154 — Independent review routed across families

**Requirement.** Before unattended work integrates, the delivered loop content shall obtain each review or critique verdict the declared policy requires from a session that did not author the work — drawn from a different model family wherever one is configured, degrading only to the documented same-family mode — with every selection logged before launch and a non-converging rework loop escalated through the declared ratification level.

**Acceptance criteria.** A declared review policy of N schedules N independent reviewer sessions; a configured cross-family draw is preferred and its unavailability degrades to the documented mode, never a silent skip; every selection is logged before launch; rework iterates within the declared budget and pages per the declared ratification level on exhaustion; review substance scoring never rewards length.

**Rationale.** Realizes SN-026 (cross-family second opinions — this row is SN-026's only surviving SR-level carrier, so the sn_refs join forces the mint), SN-024 (an author cannot judge its own output) and SN-006. One row because routing, scheduling, scoring and escalation are one delivered contract — that the second opinion happens, independently, or its absence is documented — whose mechanics are the component details below it.
