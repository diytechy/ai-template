# SR-158 — Documentation drift reds or warns per its declared tier

**Requirement.** The delivered harness shall report a documentation surface that has drifted from what it claims — a broken intra-repo link, a missing vision declaration, a reference to an absent path or symbol, a stale generated doc, or a declared figure without its provenance — at the declared warn-or-gate severity for each class.

**Acceptance criteria.** A dead intra-repo link, an absent PROJECT-VISION tag, a stale generated doc under --stale, a dangling backticked path or sym: reference, and a declared fig: marker missing cmd/rev each produce a finding at their declared tier; the declared carve-outs (generated blocks, path-ok and fig-ok lines, unmarked figures, URLs and placeholders) stay silent. The tier for each class is read off its declaration site, as the current set: check.py's built-in `doc-navigability` step, which runs check_docs.py from DevBar-Reqs on -- a broken intra-repo link and a missing or repeated PROJECT-VISION tag exit nonzero, orphans warn unless --strict-orphans, and --stale is warn-only; docs/stack.ini's `[step:doc-refs]` and `[step:figures]` rows, which declare `gates = DevBar-Release` for check_doc_refs.py --strict (gating on dangling alone, with untraced counted and never gating) and check_figures.py --strict; and the carve-out surfaces those checkers read -- `docs/orphans-allow`, `docs/declared-absences`, and the path-ok / fig-ok line markers. A class whose severity is stated at none of those sites is undeclared, and this row is unsatisfied until it is declared there.

**Rationale.** Realizes SN-010 (navigable, honest documentation) and SN-008 (a green never hides a stale claim). One row because the delivered contract is one honesty verdict over the documentation surfaces; the individual checkers and their carve-outs are component details.
