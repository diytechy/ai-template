# SR-158 — Documentation drift reds or warns per its declared tier

**Requirement.** The delivered harness shall report a documentation surface that has drifted from what it claims — a broken intra-repo link, a missing vision declaration, a reference to an absent path or symbol, a stale generated doc, or a declared figure without its provenance — at the declared warn-or-gate severity for each class.

**Acceptance criteria.** A dead intra-repo link, an absent or repeated vision declaration, a stale generated doc under the staleness check, a dangling backticked path or symbol reference, and a declared figure marker missing its command or revision each produce a finding at their declared tier; the declared carve-outs (generated blocks, per-line and per-file allow markers, unmarked figures, URLs and placeholders) stay silent. The declared tiering, read off each class's declaration site rather than restated: link and vision findings gate from the first requirements bar on; orphans and staleness warn by default, orphans gating only under their declared strict flag; the reference and figure checks gate at the release bar, gating on dangling references alone, with untraced ones counted and never gating. A class whose severity is stated at no declaration site is undeclared, and this row is unsatisfied until it is declared there.

**Rationale.** Realizes SN-010 (navigable, honest documentation) and SN-008 (a green never hides a stale claim). One row because the delivered contract is one honesty verdict over the documentation surfaces; the individual checkers and their carve-outs are component details.
