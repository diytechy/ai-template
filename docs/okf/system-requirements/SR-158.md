# SR-158 — Stale admission verdicts are refused

**Requirement.** The strict trajectory check shall refuse a queued item whose recorded conflict verdict is absent, or whose recorded scope or spine digest differs from the current one.

**Acceptance criteria.** A queued item carrying a current verdict passes; an item with no verdict, an item whose scope digest has moved and an item whose spine digest has moved are each refused by name.

**Rationale.** A verdict that outlives the state it judged is worse than no verdict, because it reads as a current ruling. Comparing the digests the verdict itself names is what turns expiry into a mechanical property rather than a habit someone has to remember.
