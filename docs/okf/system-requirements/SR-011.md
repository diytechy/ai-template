# SR-011 — Idempotent re-runnable scaffold

**Requirement.** bootstrap.py shall be idempotent — a re-run never overwrites an existing file unless --force is passed — and shall stamp docs/kit-version (marked -dirty on an uncommitted kit tree) so a re-sync is a diffable operation.

**Acceptance criteria.** A re-run leaves every existing file (kit- or project-owned) byte-unchanged without --force; --force overwrites; docs/kit-version records the kit SHA + date.

**Rationale.** Realizes SN-001 (safe drop-in onto an existing repo) and SN-007 (a re-run to pick up kit updates never regresses the adopter's content). The deliberate kit-vs-project merge is the ADOPTING.md section 6 process — see SR-036.
