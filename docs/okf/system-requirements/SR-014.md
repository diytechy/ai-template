# SR-014 — Perf comparator and budgets

**Requirement.** check_perf.py shall compare a run against declared budgets and fail when a metric regresses beyond its tolerance.

**Acceptance criteria.** A metric within tolerance passes; one beyond its budget's tolerance fails at the declared block/warn level.

**Rationale.** Realizes SN-004 (a measurable gate bar) and SN-012 (perf is an opt-in layer).
