# SR-042 — OKF knowledge-bundle export

**Requirement.** gen_okf.py shall export the spine registries as a generated Open Knowledge Format bundle under docs/okf — one typed markdown concept per real row with the graph as resolvable markdown links and per-tier indexes — deterministic (no clocks), with --check failing on any stale, missing or extra bundle file; docs/okf-export off silences and placeholder-only registries are vacuous.

**Acceptance criteria.** One frontmatter-typed file per real SN/SR/LLR/TC row whose graph links resolve; regeneration is byte-identical; --check trips on a registry edit, a missing bundle and a hand-added file; the write mode prunes extras; off and placeholder-only registries pass silently.

**Rationale.** Realizes SN-004 and SN-010 — the traceability knowledge becomes portable into any OKF consumer with no new source of truth and no runtime dependency (Thread 48, owner-ruled on-by-default/opt-out + commit-the-bundle); emit-only stdlib (JSON string scalars are valid YAML), never a parser.
