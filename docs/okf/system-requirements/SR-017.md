# SR-017 — Always-on secrets floor

**Requirement.** check_privacy.py shall scan every commit's staged diff, message, and outgoing range for secret patterns regardless of the privacy toggle, unless docs/secrets-scan is explicitly set to off.

**Acceptance criteria.** A staged PEM header, token, or key pattern is flagged and blocks; a clean diff passes; the floor runs with privacy-check off, and is disabled only by an explicit docs/secrets-scan: off.

**Rationale.** Realizes SN-009 — a committed secret is caught in every repo without extra setup; the sole opt-out is the explicit docs/secrets-scan off declaration, not the privacy toggle (IMPROVEMENT_PLAN.md Threads 38/39/44/46).
