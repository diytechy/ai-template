# SR-145 — Deterministic resume precedence

**Requirement.** The resume planner shall order each cycle as unadjudicated outcomes, then changed normative digests, then draft-queue vetting, then human checkpoints, then current-stage spine work, then other ready work, then red-bar remediation.

**Acceptance criteria.** Two planner runs over one tree return the same decision; each precedence rung is selected in turn by a fixture that satisfies only that rung; a lower rung is never selected while a higher rung has work.

**Rationale.** A loop that decides what to do next from ambient state reaches different answers on identical trees, which is the property that makes an unattended run untrustworthy. Fixing the precedence in one pure function makes the next action a function of the tree alone and therefore reviewable and testable without a live station.
