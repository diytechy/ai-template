# SR-100 — Ownership-state reconstruction

**Requirement.** Recovery shall reconstruct one owner and state per WI and train, quarantine ambiguity or duplicate reservations, and fail closed on unprovable ownership.

**Acceptance criteria.** Every recoverable state yields one owner; ambiguity and duplicate claims quarantine only the affected train; no WI is double-assigned or falsely completed.

**Rationale.** Realizes SN-025;SN-017 by isolating one independently reviewable obligation formerly carried by SR-064.
