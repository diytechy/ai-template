# SR-034 — Scripts are stdlib-only

**Requirement.** Every kit script shall run on a clean Python 3.8+ with no pip installs (standard library only).

**Acceptance criteria.** No kit script imports a third-party package; confirmed by inspecting imports.

**Rationale.** Realizes SN-011 — the kit imposes no dependency stack on a downstream repo to run its checks.
