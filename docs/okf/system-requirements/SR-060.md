# SR-060 — Explicit worker assignment mode

**Requirement.** The coordinator shall replace internal --track assumptions with explicit per-worker --wi/--train/worktree assignment: a worker prompt is assembled from AGENTS.md, the WI row, its SpecRef, predecessor context, the current train diff, and any rework finding (never docs/status.md or docs/next-wi); worker branches never edit root status/run-state/next-wi, integrated WI statuses, the root log, or generated root artifacts; and WI-scoped review evidence uses collision-safe paths/ids naming the exact reviewed code commit. The --track lane machinery is retired outright: the explicit assignment is the only lane concept.

**Acceptance criteria.** A worker runs from an explicit WI/train/worktree assignment with no lane-local status/next/run-state file; two concurrent workers write non-colliding logs/review evidence; a worker branch never mutates root coordination truth; --track is refused as an unknown flag (retired outright) and no code path reaches the old lane plumbing.

**Rationale.** Realizes SN-025 and SN-006 - dynamic lanes/traincars replace long-lived tracks as the assignment unit, and collision-safe per-assignment state lets many workers run without a shared blackboard (docs/specs/parallel-wi-dispatch.md 2/6/8).
