# SR-143 — Meaning-changing amendment regresses the derived spine stage

**Requirement.** The attestation adjudication shall derive a spine stage equal to the tier of the artifact a meaning verdict names, while a clarity verdict advances the accepted anchor to the new digest and leaves the stage where it stands.

**Acceptance criteria.** A meaning verdict at each of the four tiers derives the matching stage; a clarity verdict writes a new accepted anchor at the new digest and leaves the stage unchanged; a canonicalisation-only edit produces no candidate at all.

**Rationale.** Today only a system requirement carries a post-attestation amendment state, so a changed need has no honest baseline at all. Deriving the stage from the tier of the changed artifact gives need prose the same standing as requirement prose, and separating clarity from meaning stops a re-wrap from costing a re-attestation.
