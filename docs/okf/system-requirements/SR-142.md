# SR-142 — Cumulative numeric human ratification boundary

**Requirement.** The ratification boundary value shall decide, for each spine tier at or below it, that a ratification requires a recorded human decision, and permit an adjudicator to enact ratification above it.

**Acceptance criteria.** Each boundary value from zero to three routes the four spine tiers to the human or the adjudicator exactly as the inclusive table declares; a boundary outside the range refuses; an adjudicator decision above the boundary is enacted and recorded.

**Rationale.** The retired gate-authority enum expressed who ratifies but not which tiers, so a repo wanting human sign-off on needs and requirements while automating test-case ratification had no way to say so. A cumulative ordinal says exactly that in one number and orders the four tiers unambiguously.
