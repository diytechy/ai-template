# SR-146 — Component-partitioned exclusive spine batch

**Requirement.** A spine batch shall admit as one exclusive unit whose scope is a connected component of the declared trace and interface graph, collapsing to one project-wide batch when ownership is missing or an edge crosses the proposed partition.

**Acceptance criteria.** Independent components admit as separate batches; a trace or interface edge crossing a proposed partition collapses the batch to one project-wide unit; a row with no declared owning component collapses it likewise.

**Rationale.** Splitting requirement work by anything other than graph connectivity lets two batches amend rows that reference each other, which is how a reviewed spine acquires an unreviewed composition. Connectivity is the only criterion that makes the independence claim true rather than plausible.
