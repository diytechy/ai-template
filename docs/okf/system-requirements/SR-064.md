# SR-064 — Crash safety and git-as-authority recovery

**Requirement.** out/dispatch/ shall be a rebuildable journal/cache, never the sole record: every startup shall acquire the dispatcher lock and reconstruct one ownership/state record per WI and train from Git alone - the authoritative integrated disposition from refs/heads/llm/integration (the development branch is its published projection, not the recovery authority), plus llm/train/*, llm/integrate/*, refs/llm/reservations/*, the refs/llm/publish-intent ref, worktrees, reservation commits, and exact-head review records - enumerating that evidence BEFORE deciding authority (an absent integration ref initializes from the development branch only when no owned train/integrate/reservation/intent ref or integration trailer exists, else reconstructs-if-uniquely-provable or fails closed, never silently blessing the development branch), quarantining ambiguity/duplicate reservations and failing closed on unprovable ownership before deriving new work; recovery shall handle a crash at every lifecycle boundary (including the reservation transaction, both CAS points, and the worktree sync) without double-assignment, lost commits, false completion, or half-integrated authoritative state or unclassifiable publication state, and shall reconstruct even with all of out/dispatch/ deleted.

**Acceptance criteria.** Injecting termination at each lifecycle boundary reconstructs exactly one owner, double-runs/falsely-completes nothing, deletes no unintegrated commit/dirty tree, and leaves llm/integration atomically before or after integration with the development ref/worktree in one of three recoverable states - fully unpublished, fully synchronized, or recoverably in-between with a valid publication-intent ref proving the expected-old and target hashes; an absent integration ref initializes from the development branch only with no dispatcher evidence, else reconstructs-if-provable or fails closed; every constituent reservation reconstructs from refs/llm/reservations/* including before its first commit; deleting all of out/dispatch/ still reconstructs from Git; stale PIDs and released OS locks never block recovery.

**Rationale.** Realizes SN-025 and SN-017 - a walk-away parallel run must survive process/host death with the disk intact, reconstructing every reservation and disposition from durable Git refs so nothing is double-run or falsely done (docs/specs/parallel-wi-dispatch.md 11).
