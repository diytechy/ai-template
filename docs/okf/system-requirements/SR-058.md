# SR-058 — Deterministic safety classification

**Requirement.** schedule.py shall own one pure safety classifier - shared by validation, dashboard, traincar packing, and dispatch - mapping a WI's declared SafetyClass (ordinary|spine|gate|attestation|protected|high-risk), gate/phase, hard edges, Exclusive keys, and review/critique policy to a scheduling class plus reason codes: spine/gate/attestation serialize whole-project and pack only with each other - ready spine-serial WIs (plus queued spine-serial successors unlocked aboard) cluster into ONE spine-only traincar in hard-edge order, cap-bounded, never sharing a traincar with any other class (WI-204 owner ruling 2026-07-17: drafted together, reviewed together, attested together); protected serializes whole-project; high-risk, a critique requirement, or an integration-checkpoint policy force a single-WI traincar; only classified ordinary work packs optimistically; and missing/invalid/contradictory input returns unclassified, fails closed for that WI, and never stops disjoint classified work. The validator shall cross-check a declared class against structurally visible spine/gate/attestation/review evidence and fail closed on a mismatch, never silently upgrading.

**Acceptance criteria.** Every SafetyClass and review-policy input produces the same scheduling class and reason codes across CLI, validator, dashboard, and dispatcher; missing/contradictory input yields unclassified and fails closed only for the affected WI; an ordinary declaration with structurally visible spine/gate/attestation/critique/review-boundary evidence fails validation rather than upgrading silently; ready spine-serial WIs pack into one spine-only traincar (hard-edge order, cap-bounded) that never carries another class, the homogeneous spine-only train passes the worker continuation re-check while a heterogeneous grouping still refuses, and under gate-policy autonomous the built batch continues on the recorded verdict with no ratification pause.

**Rationale.** Realizes SN-025 and SN-008 - scheduling safety depends on classifications that must be deterministically derivable and fail-closed so two conformant implementations cannot fan out different work (docs/specs/parallel-wi-dispatch.md 4 Deterministic safety classification); a declared-but-unverified class is caught by the validator plus the 14 audit. The spine-only batch is the WI-204 amendment (docs/specs/WI-204.md): one drafted-together body of spine work is one train, one review scope, one ratification scope.
