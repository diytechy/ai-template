# SR-128 — Paraphrase advisory

**Requirement.** trace.py shall warn (never fail) when a child cell mostly re-words its parent.

**Acceptance criteria.** An SR Rationale overlapping its own Requirement, or an LLR Detail overlapping its parent SR Requirement, past the declared threshold emits a stdout WARNING and a report line; the exit code is unchanged.

**Rationale.** Realizes SN-002 — a child that restates its parent adds a second home for one fact and no decomposition, so the trace grows a level without gaining information. It warns rather than fails because the detector is lexical overlap: a short, correct Detail legitimately shares vocabulary with the requirement it decomposes, and gating on a heuristic with a large legitimate majority produces a check that gets scrolled past.
