# SR-131 — Tracked pause drains claiming to a merged stop

**Requirement.** A tracked docs/work/pause file (TOML: reason, since) shall pause claiming - everything in flight finishes and integrates - with either pause home (the legacy untracked docs/pause or the tracked file) sufficient to pause the coordinator, failing closed on malformation, and the generated pending surface shall render the declared since and reason verbatim.

**Acceptance criteria.** A tracked pause file pauses the coordinator via pause_reason under the unchanged None/''/reason contract; a malformed file pauses with the pinned loud placeholder; the pending block renders Paused since <date> - <reason> with the declared date verbatim (no clock) and clears when the file is deleted.

**Rationale.** §5.6: pause means stop claiming and drain to a merged stop - never a strand. The tracked form survives clones, its reason is diffable history, and unpausing is an auditable deletion commit; a broken pause file must still pause, loudly, and an open pause must stay a visible accruing cost (the stale-reason lesson).
