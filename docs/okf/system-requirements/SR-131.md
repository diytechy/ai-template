# SR-131 — Tracked pause drains claiming to a merged stop

**Requirement.** A tracked docs/work/pause file (TOML: reason, since) shall pause claiming —
everything in flight finishes and integrates.
It shall be read via pause_reason as the ONE pause home (the legacy untracked
docs/pause half retired with the dispatcher at Phase 5), failing closed on
malformation.

**Acceptance criteria.** A tracked pause file pauses the coordinator via pause_reason under the unchanged None/''/reason contract; a malformed file pauses with the pinned loud placeholder; a stray legacy docs/pause file is inert.

**Rationale.** §5.6: pause means stop claiming and drain to a merged stop - never a strand. The tracked form survives clones, its reason is diffable history, and unpausing is an auditable deletion commit; a broken pause file must still pause, loudly. The pending-surface render is SR-135's obligation (one row, one obligation).
