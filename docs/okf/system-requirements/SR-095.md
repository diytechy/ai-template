# SR-095 — Safety-aware traincar packing

**Requirement.** The dispatcher shall optimistically pack only ordinary work, serialize protected work, isolate forced single-WI work, and cluster ready spine, gate, and attestation work into homogeneous cap-bounded trains.

**Acceptance criteria.** Ordinary chains may pack; protected work serializes; forced-single work stands alone; spine-serial work batches only with its class in hard-edge order and respects the cap and gate policy.

**Rationale.** Realizes SN-025;SN-008 by isolating one independently reviewable obligation formerly carried by SR-058.
