# SR-035 — Stack-agnostic across OSes

**Requirement.** The process and ID scheme shall be stack-agnostic and the scripts shall run on Python 3.8+ across Linux, Windows and macOS.

**Acceptance criteria.** The CI matrix spans Linux, Windows and macOS on Python 3.8 and latest and is green; macOS+3.8 is excluded because macos-latest is an arm64 runner with no CPython 3.8 build (3.8 predates Apple Silicon; official arm64 macOS binaries start at 3.9.1), and that cell adds no coverage — the 3.8 floor is a platform-agnostic language/stdlib guarantee already exercised on Linux and Windows, while macOS's job is OS-specific behavior (advisory locks, paths, git worktrees) that does not vary by Python version; the ID scheme is language-neutral.

**Rationale.** Realizes SN-003 and SN-011 — portability is analyzed via the CI matrix, not a single unit test.
