# SR-035 — Stack-agnostic across OSes

**Requirement.** The process and ID scheme shall be stack-agnostic and the scripts shall run on Python 3.11+ across Linux, Windows and macOS.

**Acceptance criteria.** The CI matrix spans Linux, Windows and macOS on Python 3.11 and latest (3.x) and is green; macOS runs on current Python (3.x) only — the 3.11 floor is a platform-agnostic language/stdlib guarantee already exercised on Linux and Windows, while macOS's job is OS-specific behavior (fcntl.flock, paths, git worktrees) that does not vary by Python version, so the macOS+3.11 cell is excluded as a redundant-coverage call (M-27), not a runner-availability workaround (3.11 has arm64 macOS builds); the ID scheme is language-neutral.

**Rationale.** Realizes SN-003 and SN-011 — portability is analyzed via the CI matrix, not a single unit test.
