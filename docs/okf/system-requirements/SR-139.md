# SR-139 — Fail-closed configuration query for the shell hooks

**Requirement.** The configuration query entry point shall answer one requested policy key per invocation and exit non-zero with a named refusal when the declared interpreter floor is unmet.

**Acceptance criteria.** A declared key is printed on stdout with exit 0; an undeclared key exits non-zero; an interpreter below the declared floor exits non-zero with a message naming the floor; the pre-commit, commit-msg and pre-push hooks each block when the query refuses.

**Rationale.** The git hooks defend privacy and review policy before any Python tooling runs, so they need a reader that cannot answer wrongly. A refusal on a missing or below-floor interpreter is stronger than the first-line grep it replaces: the grep answers 'absent' and the hook proceeds, whereas a refusal stops the commit.
