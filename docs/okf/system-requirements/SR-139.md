# SR-139 — Ratification as an ordinal over a derived spine stage

**Requirement.** The kit shall express human ratification authority as a cumulative integer 0-4 naming the highest spine tier a human still ratifies, compared against a separately derived SPINE STAGE (0=SN..4=nothing in process) with a declared, auditable mapping to the harness gate. Every unreadable or out-of-range input shall resolve toward MORE human involvement.

**Acceptance criteria.** Level N holds exactly the tiers the shipped template documents (cumulative, strictly-less-than the stage); stage 4 is held by no level, the end-of-run hold being its own dial; an unreadable stage, an absent dial, and a wrong-typed dial all read as human-held; an out-of-range level falls back to the conservative end AND is refused loudly; a legacy gate-policy word reads as all three dials it meant.

**Rationale.** The retired three-value enum could not express "TCs are human-held but LLRs are not", and four tables each re-interpreted the same word with its own fail-safe direction. The failure that matters is a machine ratifying something a human meant to hold, so every degrade has to point the same way — including the ones that look like kindness: clamping an out-of-range level toward 0 reads as "nothing is human-held" and disarms every hold in the repo.
