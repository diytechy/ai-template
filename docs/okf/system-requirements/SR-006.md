# SR-006 — Gate/tier harness enforces required steps

**Requirement.** check.py shall run the required steps of the gate that must next be passed (the strictness selector cached in docs/gate) and fail that gate when a required tool is missing, reporting SKIP(missing) rather than silently passing.

**Acceptance criteria.** check.py --gate <bar> runs that bar's steps; a required-but-absent tool fails the gate with guidance (never a silent pass), and --lenient degrades it to SKIP; --tier selects the declared step subset.

**Rationale.** Realizes SN-004 (gates enforce their bar), SN-008 (no false green) and the dissolved edge expectation that a missing tool fails, never skips. The work-branch lane skip is SR-133's obligation (one row, one obligation).
