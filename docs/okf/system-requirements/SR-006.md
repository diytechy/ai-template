# SR-006 — Gate/tier harness enforces required steps

**Requirement.** check.py shall run the active gate's required steps and fail the gate when a required tool is missing, reporting SKIP(missing) rather than silently passing.

**Acceptance criteria.** check.py --gate GN runs that gate's steps; a required-but-absent tool fails the gate with guidance (never a silent pass), and --lenient degrades it to SKIP; --tier selects the declared step subset.

**Rationale.** Realizes SN-004 (gates enforce their bar), SN-008 (no false green) and SN-014 (a missing tool fails, never skips). The work-branch lane skip is SR-133's obligation (one row, one obligation).
