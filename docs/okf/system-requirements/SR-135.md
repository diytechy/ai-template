# SR-135 — Pending surface renders the declared pause verbatim

**Requirement.** The generated pending surface shall render a declared pause's since and reason verbatim - no clock - clearing when the pause file is deleted.

**Acceptance criteria.** the pending block renders Paused since <date> - <reason> with the declared date verbatim (no clock), omits the stamp when since is empty, renders the pinned fail-closed placeholder on malformation, and clears when the file is deleted.

**Rationale.** An open pause is a visible accruing cost, never a forgotten one (the stale-reason lesson). Decomposed from SR-131 so each row states one obligation.
