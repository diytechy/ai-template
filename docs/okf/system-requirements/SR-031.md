# SR-031 — Declared-policy readers agree

**Requirement.** The policy readers shall share one parse so the hooks, agent_loop and check_privacy agree on every declared value. Since SN-028 that parse is docs/process.toml, read by two grammars — tomllib and the hooks' pure sh — whose agreement over the file's checked line shape is itself driven; the legacy one-word files stay readable through the migration window, and a dial declared in both homes is REFUSED rather than resolved by precedence.

**Acceptance criteria.** Every enforcer reads the same value for the same dial; the hooks' sh and tomllib return the same answer over the adversarial file-shape table (including a trailing-comment decoy, which once made the privacy gate fail OPEN); a legacy file present alongside its key is a refusal naming both.

**Rationale.** Realizes SN-004 (policies drive the gate) and SN-005 (one source, every enforcer reads it the same way).
