# SR-031 — Declared-policy readers agree

**Requirement.** The gate-policy, push-policy, and privacy-check readers shall share one declared-value parse so the hooks, agent_loop, and check_privacy agree on the value.

**Acceptance criteria.** The gate-policy and push-policy readers return the first declared line; every enforcer reads the same value.

**Rationale.** Realizes SN-004 (policies drive the gate) and SN-005 (one source, every enforcer reads it the same way).
