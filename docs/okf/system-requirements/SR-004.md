# SR-004 — Acceptance-criteria advisory

**Requirement.** trace.py shall warn (never fail) when an SR AcceptanceCriteria uses a comparative term with no pinning predicate in the cell.

**Acceptance criteria.** A comparative claim with no pinning predicate marker emits a stdout WARNING and a report line; the exit code is unchanged.

**Rationale.** Realizes SN-002 by keeping acceptance criteria testable, while leaving the call to the G1 review — a heuristic lint must not gate.
