# SR-156 — A judge's brief excludes the judged party's self-assessment

**Requirement.** A prompt rendered for a judging role shall exclude every source class declared prohibited for that role, including the assessment written by the party under judgement.

**Acceptance criteria.** A rendered judging brief contains no content from a prohibited source class; supplying prohibited content refuses the render; the check runs over the prompt as launched rather than over the template alone.

**Rationale.** A brief that opens with the defendant's own verdict anchors the judge before the evidence, and this was observed in a live adjudication brief clipped mid-word. Declaring prohibited source classes per role generalises the reviewer redaction rule instead of correcting each incident after it happens.
