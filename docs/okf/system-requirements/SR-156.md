# SR-156 — Bounded lanes narrowing to one gated landing

**Requirement.** The delivered loop content shall run ready work on bounded, mutually isolated lanes and narrow every lane back to the integration branch through one serial, fail-closed seam that runs the declared bar on the composed tree — parking a red candidate and stopping the queue loudly, draining claiming to a clean merged stop under a declared pause, closing a lane that cannot finish into a terminal state, and reconstructing claim and queue state from version-control history alone at any crash boundary, never a half-integrated authoritative state.

**Acceptance criteria.** A launch with independent ready work runs up to the configured lane ceiling concurrently in isolated working trees, and a single-lane setting preserves the serial semantic; a finished branch reaches the integration branch only through the serial seam with the declared bar green on the composed tree — a red parks the candidate and stops the queue loudly; a declared pause stops claiming and drains in-flight lanes to a merged stop; a lane that cannot finish closes into a terminal state that merges like any other branch; a crash at any lifecycle boundary recovers from version-control history without double-assignment. Read off the current carrier, as the current set: integrate.py, lane.py, handback.py, agent_common.py's tracked pause reader.

**Rationale.** Realizes SN-027 WHOLE — ready work fans out across bounded parallel lanes and that fan-out narrows to one serialized gated seam before anything lands, in the need's own words — with SN-008 (the seam is fail-closed) and SN-025 (recovery from version-control history alone). SPLIT 2026-08-16 (re-tier v2 S4, ruling R1): the row's former "one row because serial integration is one delivered contract" argument was sound for the SEAM, but three children were not the seam — lane execution, claim authority, and the trunk-side mint of work-item identity had ridden in under it. The measured corroboration: no SR in the corpus stated SN-027's FIRST half at all (a grep of every requirement cell for bounded lanes, isolated working trees or a worker ceiling returned nothing), so the merge was hiding a coverage hole rather than expressing one contract — exactly what the fan-out detector exists to surface. This row therefore widens to the honest lane LIFECYCLE (claim, run isolated, close, land) and closes that hole in the same act; the trunk-only authority contract sheds to SR-170. The two fail independently: a perfectly serialized landing that lets a lane commit a regenerated artifact satisfies this row and not that one.
