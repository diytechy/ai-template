# SR-156 — Serialized, gated integration of parallel lanes

**Requirement.** The delivered loop content shall land every lane's finished work through one serial, fail-closed integration seam that runs the declared bar on the composed tree and regenerates the shared authority surfaces only at that seam — draining claiming to a clean merged stop under a declared pause, and recovering from git history alone at any crash boundary — never a half-integrated authoritative state.

**Acceptance criteria.** A finished branch reaches the trunk only through the serial integrator with the declared bar green on the composed tree — a red parks the candidate and stops the queue loudly; log fragments and generated artifacts are compiled and regenerated only by the serial trunk actor and never committed on a work branch; a declared pause stops claiming and drains in-flight lanes to a merged stop; a crash at any lifecycle boundary recovers from git history without double-assignment.

**Rationale.** Realizes SN-027 — fan-out narrows to one serialized gated seam before anything lands, in the need's own words — with SN-008 (the seam is fail-closed), SN-025 (recovery from git alone) and SN-010 (the status surface a human reads regenerates at the seam, never on a lane). One row because serial integration is one delivered contract; the trunk step, pause drain, fragment compilation and verdict-freshness mechanics are its component details.
