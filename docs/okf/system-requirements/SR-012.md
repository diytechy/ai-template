# SR-012 — Doc navigability

**Requirement.** check_docs.py shall fail on a broken intra-repo link or a missing PROJECT-VISION tag, and check generated-doc freshness under --stale.

**Acceptance criteria.** check_docs.py --stale fails on a dead intra-repo link or absent PROJECT-VISION tag and passes a clean doc set.

**Rationale.** Realizes SN-010 — documentation stays navigable and honest; a broken link or undeclared vision is a red.
