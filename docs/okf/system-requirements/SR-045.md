# SR-045 — Heterogeneous implementer/reviewer scheduling

**Requirement.** When docs/agents-enabled opts in, the unattended coordinator shall schedule fresh reviewer sessions after a committing build per docs/review-policy (0|1|2, loop-enforced), route each session's model from the docs/agents.csv registry by the phase tier + reviewer heterogeneity (two providers, at least one differing from the implementer's - preferred not required, degraded same-provider legal) + per-model cooldown, walk a tier UP but never down, and log every selection before launch (no silent swap); a stdlib substance scorer shall score each verdict block (confirmed-finding rate, cross-reviewer corroboration, anchored precision, actionability - severity hygiene and anti-gaming tripwires as gates never scores, length never positive) into an advisory decayed scoreboard; and a fixed win-stay/lose-shift escalation policy shall swap the implementer provider after two consecutive failed review gates, raise the tier only after the swap fails, and page the human per the docs/gate-policy failure semantics on the shared-failure regime, contradictory verdicts, or any tripwire. Absent the enable-list, the loop keeps today's single AGENT_CMD/AGENT_MODEL behavior.

**Acceptance criteria.** With docs/agents-enabled present, review-policy 1 schedules REVIEW-A (2 also REVIEW-B) before the next build and 0 schedules none; a --prompt-map file slots the reviewer prompt and a missing one fails preflight; selection honors enable-list order, tier, the heterogeneity preference, the degraded same-provider fallback, cooldown, and tier-up-never-down; a verdict file machine line parses; the scorer components and each tripwire fire as documented; the win-stay/lose-shift streak/margin logic and the gate-policy paging path hold; and an absent enable-list reproduces today's behavior.

**Rationale.** Realizes SN-006 and SN-016 - the S8 heterogeneous-scheduling build (AGENT_ROLES R1/R6; docs/specs/working-surface-and-architecture-restructure.md#s8): separately scheduled implementer/reviewer sessions across tiers and providers with next-round routing a declared, legible policy informed by mechanically scored review substance (no learned router at per-project sample sizes), staying stdlib, consent-explicit (no silent model swap), and never-breaking. Rides the pending G3 re-attestation.
