# SR-140 — The attestation anchor lives on the artifact's own row

**Requirement.** The kit shall record each acceptance ON THE ACCEPTED ARTIFACT'S OWN ROW - the commit whose tree carries the text that was accepted, and a digest of that row's NORMATIVE cells - never in a second registry keyed on the same artifact; shall report text that has moved away from its recorded anchor regardless of any Status movement; and shall treat an anchor written in the same commit as the text it anchors as an error.

**Acceptance criteria.** An artifact whose normative text has moved since its recorded anchor is reported whether or not its Status moved; an anchor that cannot be recomputed, or that names an artifact which is not a current row, is a finding rather than silence; a commit that writes an anchor cell while also changing that row's normative cells is refused, because a re-stamp in the same breath as an amendment hides the amendment; and the same rules hold for a stakeholder need, which has no Status cell for the amendment machinery to watch.

**Rationale.** Attestation STATE is already the row's own Status - derive_gate computes the gate from those cells and reads no other source - so a separate ledger was a second home for a fact the row already carried, and three of its seven columns duplicated cells outright (Decision=ratified|meaning IS Status; superseded IS SupersededBy). What the ledger got right is the ANCHOR ITSELF: 'has this been ratified' was answered by walking git for the newest commit where a row read Verified, which is sound only while every amendment flips its row in the same commit - precisely the sanctioned path the staged-amendment guard deliberately ignores. Two cells are kept rather than one because they fail in DIFFERENT directions: the commit is what a human can review and what the before/after brief diffs against, while the digest is what survives a squash-merge, a rebase or a shallow clone, any of which makes a recorded sha unresolvable and would otherwise silence drift detection repo-wide at once.
