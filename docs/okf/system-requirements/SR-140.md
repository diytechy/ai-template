# SR-140 — Legacy configuration conversion with unmapped-value reporting

**Requirement.** The configuration converter shall translate every retired declared-policy source into docs/config.toml and report each value it cannot map rather than guessing one.

**Acceptance criteria.** Each retired source converts to its canonical key; a value with no lossless target is reported by name with its candidate targets and left unwritten; the report is produced without modifying the tree when the read-only flag is given.

**Rationale.** The retired gate-authority values do not map one-for-one onto the numeric ratification boundary: one of them also encoded cadence and another permitted no early human checkpoint. A converter that guessed would move a repo to a policy nobody chose, which is worse than an explicit question.
