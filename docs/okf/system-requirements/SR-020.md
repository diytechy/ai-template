# SR-020 — Pre-push hook outgoing scan

**Requirement.** The pre-push hook shall scan the outgoing commit range and block a push that publishes a secret or (under privacy-check) a private identity.

**Acceptance criteria.** The hook scans the push range and blocks when a secret (always) or an identity/PII class (privacy-check on) appears.

**Rationale.** Realizes SN-005 and SN-009 — the last gate before content leaves the machine.
