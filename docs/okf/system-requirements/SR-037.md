# SR-037 — Work-item registry validation

**Requirement.** check_trajectory.py shall validate the work-item registry — well-formed WI ids, resolvable predecessors and an acyclic dependency DAG — and exit nonzero on a violation; a placeholder-only or absent registry passes vacuously and docs/trajectory-check: off silences the step.

**Acceptance criteria.** A valid registry exits 0; a malformed WI id, an unresolvable predecessor and a dependency cycle each exit nonzero naming the offender; a placeholder-only registry and docs/trajectory-check: off both pass.

**Rationale.** Realizes SN-002 and SN-012 — the prospective roadmap is validated mechanically like the rest of the spine (THREAD_52_REVIEW.md F1 traced this layer's own code), and the opt-out keeps the layer free for a repo that does not use it.
