# SR-137 — Validated single configuration file

**Requirement.** The configuration loader shall parse docs/config.toml into a typed model and refuse an unknown key, a wrong-typed value, or an unsupported schema version, naming the offending key.

**Acceptance criteria.** A well-formed file loads to a typed model; an unknown key, a wrong type and an unsupported schema version each produce a refusal naming the key and a non-zero exit; an absent file yields the declared defaults.

**Rationale.** One authority is only an authority if it rejects what it does not understand: a lenient loader silently ignores a mistyped dial and the adopter believes a policy is live when it is not. Typing the model at the boundary also gives every caller one shape to read instead of six parse conventions.
