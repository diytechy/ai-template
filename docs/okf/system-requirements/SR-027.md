# SR-027 — Coordinator preflight

**Requirement.** agent_loop.py shall refuse a broken footing in preflight — not a git repo, no agent CLI, or a private author under privacy-check — exiting a typed nonzero code rather than hanging.

**Acceptance criteria.** Outside a git repo, with no agent CLI, or with a private author under privacy-check, preflight exits a typed nonzero code.

**Rationale.** Realizes SN-006 and SN-015 — a run that starts on a broken footing fails later and further from the cause, and an unattended loop cannot be asked what went wrong. Continuing with a warning was rejected: each of these conditions makes every subsequent step meaningless, so a typed nonzero exit is what lets the caller act on it.
