# SR-136 — Declared-figure provenance

**Requirement.** check_figures.py shall flag a declared driven figure - a line opting in under the fig: marker convention - that does not carry both the command that produced it and the revision it was driven at, or a derivation naming the declared figures it is computed from, warn-first (exit 0) with --strict gating; presence only, never truth, and an unmarked figure is out of scope by design.

**Acceptance criteria.** A fig: marker missing cmd= or rev= (or carrying only empty or wordless values) warns naming the missing half and gates only under --strict, each marker on a line judged on its own attributes; cmd= plus rev= (bare or quoted), or a non-empty derived=, passes; unmarked figure prose, placeholder-grammar examples, fig-ok lines, GENERATED blocks and docs/reviews/ records are ignored; docs/stack.ini is scanned beside the root and docs markdown surfaces.

**Rationale.** Realizes SN-008 and SN-010 - a driven figure is evidence only at the revision it was driven on, and three false figures in one session (2026-08-01) each cost a review round because no record named the producing command or revision, so a stale figure read exactly like a live one. Digit detection was rejected (ids, dates, section numbers and byte budgets drown it, and one false figure had no digits at all), so the marker is opt-in - declare, don't infer - making the honest claim 'declared figures carry provenance', never 'all figures do'. Re-derivation is rung 2, deliberately not built: recorded commands are an execution surface, most figures are legitimately historical, and some commands are expensive or non-deterministic.
