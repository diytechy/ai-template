# SR-005 — Off-spine registries stay traceable

**Requirement.** trace.py shall integrity-check the optional off-spine registries (PB/REPO/PART/ASSET, plus legacy MOD compatibility) and validate their back-links without blocking a project that does not use them.

**Acceptance criteria.** A PB row whose Refs name no real SR/LLR/Module, or a REPO row (including a legacy MOD row) delegating an unknown SR, is a finding; a -000 example row in any of them is ignored.

**Rationale.** Realizes SN-002 (off-spine rows stay linked to the spine) and SN-012 (an unused optional registry costs nothing — its -000 row is ignored).
