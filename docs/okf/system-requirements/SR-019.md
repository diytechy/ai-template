# SR-019 — Pre-commit hook floor

**Requirement.** The pre-commit hook shall run the integrity + secrets floor on every commit, agent-neutrally.

**Acceptance criteria.** The hook runs trace --strict-integrity and the secrets scan on staged content and blocks a commit that fails either.

**Rationale.** Realizes SN-005 and SN-009 — a floor only CI enforces is one the local tree crosses freely, and a secret caught after the commit is already in history. Trusting the agent to run the checks was rejected: a floor exists for the times the agent forgets, so it is git-enforced and agent-neutral.
