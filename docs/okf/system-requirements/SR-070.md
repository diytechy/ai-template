# SR-070 — Offline project-state core

**Requirement.** The delivered generator set shall produce the adopted repository's self-contained, offline, deterministic and freshness-checkable project-state views from the tracked registries alone.

**Acceptance criteria.** The root state view renders its registry-derived views (completeness tiles, the SN-to-SR-to-LLR-to-TC hierarchy, the WI roadmap DAG) without external fetches and remains usable offline; regeneration from unchanged registries is stable; each generated view carries a --check freshness contract.

**Rationale.** Realizes SN-010 and the dissolved edge expectation that a generated artifact drifting from its source fails its --check, by isolating one independently reviewable obligation formerly carried by SR-038.
