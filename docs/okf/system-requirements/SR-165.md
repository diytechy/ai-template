# SR-165 — The component partition carries a reproducible derivation record

**Requirement.** A decomposition run that partitions the system shall keep, with the tracked architecture record, a reproducible comparison — the candidate partitions considered, the declared objective and constraints they were scored against, and the selected partition — with the human's naming of the components and ruling of the final choice recorded as the deciding act.

**Acceptance criteria.** The partition record lives in tracked architecture surfaces, never session prose alone; a reviewer can re-run the stated comparison against the declared objective and reproduce the recorded scores; the record names the candidate partitions, the constraints, the selected partition and the human ruling that adopted it.

**Rationale.** Realizes SN-040 — a free-form partition leaves no record of the alternatives weighed, so the next reviser cannot tell load-bearing boundaries from accidents; the record is what lets the choice be re-examined. SN-040 had no citing SR, even as the P5 partition work performed exactly this record. Cites B-02 beside B-05 because the human ruling is the authority input that adopts the partition.
