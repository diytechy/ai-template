# SR-082 — Fixed review escalation

**Requirement.** The coordinator shall apply fixed win-stay/lose-shift escalation and page for shared failure, contradictions and tripwires per the declared ratification level, keyed on whether the tier in process is still the human's to ratify and on the separate drain dial the retired three-value enum bundled into the same word.

**Acceptance criteria.** Two failed gates swap family, a failed swap raises tier, and shared top-tier failure, contradictions, or tripwires page according to gate policy.

**Rationale.** Realizes SN-006;SN-016 by isolating one independently reviewable obligation formerly carried by SR-045.
