# SR-118 — Traincar build and review shape

**Requirement.** A traincar shall be one Build pass (one commit per WI) followed by one review cycle over the combined diff carrying the policy-required number of independent verdicts, with no constituent done until the whole train integrates.

**Acceptance criteria.** A multi-WI traincar takes one review cycle with the policy-required verdict count and no early done.

**Rationale.** Realizes SN-025 — the clustering only pays if the review cost is paid once, and marking a constituent done before the train integrates publishes a WI whose code is still on an unmerged branch. Reviewing each constituent separately was rejected: it restores the per-link cost the train exists to avoid.
