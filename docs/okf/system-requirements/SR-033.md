# SR-033 — Release checklist generation

**Requirement.** The delivered release-checklist generator shall emit the release-gate checklist, including the warn-tier performance budgets that never fail a gate.

**Acceptance criteria.** Running the generator emits the checklist content: the perf-budget section lists each warn-tier PB with its id and allocation. Read off the current carrier, as the current set: gen_release_checklist.py.

**Rationale.** Realizes SN-004 — the release gate has a generated checklist surfacing the budgets a human must tick off. Hat-derived (hat.PERFORMANCE): a warn-tier budget that never fails a gate is read by nobody unless something surfaces it for a human to tick off, so the generated checklist is where an un-gated budget still gets met — derivable only through the switched-off PERFORMANCE charter, recorded so the dependency is visible.
