# TC-117 — verifies SR-052;LLR-112

**Method.** Over the shipped dashboard plus seven fixture renders: derive every querySelectorAll selector from the document's own scripts and assert each is classified control-or-not; for every control selector, match its elements in the script-stripped markup (quote-aware tag scan; the tiny selector grammar is matched exactly and anything richer fails loudly) and assert each match is focusable (tabindex=0, a button, or a link with href); assert every classified selector is seen somewhere and every control selector matches at least one element (non-vacuous both ways). Separately assert the only emitted tabindex values are 0 and -1, with -1 confined to roving tablist buttons.

**Expected.** Every wired control is keyboard-focusable; no unclassified, stale, or non-literal selector; no positive tabindex; every control wiring loop that attaches click/dblclick attaches focus or keydown beside it. Verified to fail against a control losing its tabindex, a newly wired selector (single- AND double-quoted), a positive tabindex, and a wiring loop stripped of its focus path.
