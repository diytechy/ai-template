# IF-112 — Interface

**Contract.** reads the requirement spine through the CARRIER (IF-102): the stakeholder-need rows behind the README Must/Should coverage floor. Replaces a markdown table walk that discovered its `Priority` column by header text and tracked draft-ness by heading — both shapes the markdown carrier forced. The heading arm is the one that mattered: over a TOML file it finds no headings, so NO need reads as draft, and every draft need would be ADDED to a floor that gates the README.
