# IF-077 — Interface

**Contract.** check_trajectory resolves the ANCHOR half of an open WI's `doc#anchor` SpecRef THROUGH check_docs' markdown parser (parse_doc -> the doc's anchor set, which applies check_docs' slugifier), so ONE slugifier defines what an anchor is in both homes and the same reference can never pass as a SpecRef while failing as a link — the split that let WI-326 cite a truncated heading for two days. Lazy import that degrades to path-only when check_docs is absent, because this module runs in the SHIPPED pre-commit hook and a hard requirement there would block an adopter's every commit; the two scripts always ship + re-sync together (bootstrap MAPPING), which is the same ground IF-056 stands on. Declared at WI-354 when the cross-CMP rule surfaced the new CMP-001 -> CMP-003 edge.
