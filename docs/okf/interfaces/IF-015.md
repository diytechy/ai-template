# IF-015 — Interface

**Contract.** agent_loop.py CLI: --wi runs one claimed worker assignment (--train is the optional session tag, defaulting to the branch name), --interactive launches one attached session, --dual-plan runs one decomposition round; a PLAIN launch (no role flag) runs the DRIVE mode (WI-374/WI-381, sibling dispatch.py + lane.py): claim the next ready WI in build order (schedule.py frontier -> integrate.py claim), run a worker session on the claimed branch's worktree, drain the serial merge queue (integrate.py integrate), repeat - re-deriving the frontier every cycle, resuming a parked claim on relaunch, stopping loudly on any composed refusal, never pushing. Preflight refuses broken footing and the per-checkout lock refuses a second coordinator.
