# IF-106 — Interface

**Contract.** reads the requirement spine through the CARRIER (IF-102) instead of csv.DictReader, so the SR/LLR/TC rows the OKF knowledge bundle exports answers whichever of TOML/CSV is live and the rows arrive under today's column names either way. Consumes spine_carrier.load. The bundle is generated and --check-gated, so a cell this seam failed to hand over would surface as bundle drift rather than silently - which is why the export reads through the carrier rather than keeping a private CSV reader.
