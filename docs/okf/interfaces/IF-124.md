# IF-124 — Interface

**Contract.** reads the approval baseline through IF-123: consumes baseline_snapshot.exists, SNAPSHOT_DIR and stamp, so the re-attestation brief measures an amendment against an anchor that is not the text under judgement. The half the CONSUMER owes is the refusal: with no snapshot the brief HOLDS and names a FIRST-APPROVAL question, never fabricating an anchor and never rendering a before/after with an empty before. The stamp is advisory - off git, the baseline line omits the date.
