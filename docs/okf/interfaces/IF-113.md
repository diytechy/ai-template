# IF-113 — Interface

**Contract.** The adjudicator side of the prompt loader (the IF-097 seam consumed): `adjudicate_brief.compose` resolves the brief its row's declared `Brief` cell names through `prompts.load` (an operator `--prompt-map` override under the same key wins) and fills it with `prompts.fill`, whose both-ways strictness is load-bearing HERE rather than merely tidy - an unknown slot or a declared slot left unfilled is a `PromptError`, which this module turns into a REFUSAL to dispatch, not into a brief with a hole where the evidence belongs. A judge's brief whose evidence section is thin reads as an investigation that was run and found nothing, so there is deliberately no partially-filled path across this seam.
