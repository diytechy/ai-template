# IF-101 — Interface

**Contract.** reads the id watermark so a mint counts from the RECORD, not from the live tree - read_watermark(root) -> {space: int}, raising on an absent or malformed mark rather than degrading to zero, and bump_watermark(root) to raise the marks in the same commit that files the specs. next_wi_id mints max(watermark, live filenames) + 1. Shared rather than duplicated because the mint and the checker must agree on what an id is: a second copy of that rule is the defect the check exists to catch.
