# IF-117 — Interface

**Contract.** the SYMBOL-BINDING seam behind the LLR `CodeSymbol` anchor rule (WI-429, the discharge test repo-lock D-9 leaves open for the LLR tier). Consumes gen_arch_map.module_bindings(tree) -> the set of names a module binds at module scope plus its class-level def names; the caller owns the parse, so the seam is pure and a module that will not parse costs that module's rule rather than the run. Deliberately NOT the rendered arch-map: the committed module map is a PUBLIC-API view that drops every _-prefixed name and every module constant, and 41 of this repo's 149 live LLR rows name exactly those, so reading the artifact would report real code as missing. The sym: tier keeps reading the artifact (load_symbol_oracle) - two oracles for two questions, and this row is the reason they are different.
