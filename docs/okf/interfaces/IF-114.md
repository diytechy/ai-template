# IF-114 — Interface

**Contract.** reads the requirement spine through the CARRIER (IF-102): the TC rows a red-TC brief lists (Verifies/Status/Method/Expected/Evidence) and the SR `Requirement` / LLR `Detail` text naming the obligation each case covers. Read through the carrier rather than a path with a suffix because the brief must assemble identically either side of the carrier cutover. Every cell it lists is REQUIRED: a row missing one refuses rather than rendering a dash, since a dash in an evidence listing reads as "checked, not applicable" when the truth is "the registry never said".
