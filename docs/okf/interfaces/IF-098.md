# IF-098 — Interface

**Contract.** The generated catalogue reads `catalog_rows()` — `(key, file, slots, digest)` per shipped prompt — and nothing else, so the catalogue cannot disagree with the loader about what ships. `render()` is pure, which is what lets `--check` and the write path share one answer to 'what is current'.
