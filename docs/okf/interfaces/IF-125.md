# IF-125 — Interface

**Contract.** reads the approval baseline through IF-123 so the generated status and dashboard surface reports pending amendments against what was blessed, not against HEAD. Consumes the READ half only - load_all, rows_for, is_drifted and the SNAPSHOT_DIR constant - and never copy_live. Vacuous by absence: with no snapshot the surface reports nothing approved, never everything drifted.
