# IF-100 — Interface

**Contract.** The dual-plan hats' side of the prompt loader (SN-032, the IF-097 seam consumed): `plan_briefs` loads the planner, critic and arbiter templates through `prompts.load`/`fill` with the same strict slot rules the session prompts take — an unknown slot and a declared slot left unfilled are both refusals, never a silently empty instruction to a planner.
