# IF-108 — Interface

**Contract.** reads the requirement spine through the CARRIER (IF-102) instead of csv.DictReader, so the SR surface handed verbatim to an LLM planning brief answers whichever of TOML/CSV is live and the rows arrive under today's column names either way. Consumes spine_carrier.load. This seam feeds a MODEL, not a check: a cell the reader failed to map would not fail loudly, it would quietly narrow what the planner was told. That asymmetry is the reason the vocabulary has one home (repo-lock D-6) rather than a copy here.
