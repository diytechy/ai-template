# IF-115 — Interface

**Contract.** The adjudicator-brief seam the session engine composes from: `compose(root, row, verdict_path, prompt_templates) -> (text, None) | (None, reason)`, selected by the row's DECLARED `Brief` cell rather than inferred from `SpecRef` (that inference is ambiguous - an amended test-case row and a red-TC census row carry the same one). The seam is ALL-OR-NOTHING and that is its whole contract: every assembler fills its template's slots from a real derivation or returns a reason, so the caller never receives a partially-filled judge's brief. What the caller owes in return is the fail-closed half - a row that DECLARES a brief this seam cannot compose must be held for a human, never dispatched with the worker assignment, because a judge briefed as a builder ends its session DONE like any other and the miss is silent.
