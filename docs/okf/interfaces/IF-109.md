# IF-109 — Interface

**Contract.** reads the requirement spine through the CARRIER (IF-102) instead of csv.DictReader, so the SR rows behind the critique gate and the artifact recipe answers whichever of TOML/CSV is live and the rows arrive under today's column names either way. This seam feeds an LLM brief and a GATE at once: agent_loop reads SR Verification to decide whether a critique round is owed, and lifts SR/TC prose verbatim into the brief. A cell lost in translation would either skip a required round or narrow what the model was told - neither of which fails loudly.
