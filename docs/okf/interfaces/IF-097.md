# IF-097 — Interface

**Contract.** The prompt LOADER seam (SN-032): `load(key, override)` returns one shipped template's text or raises a named `PromptError`; `fill(key, text, values)` refuses an unknown slot and a declared-but-unfilled slot rather than launching a silently empty instruction; `preflight(keys, overrides)` turns a missing template into a launch-time refusal instead of a first-session crash; `digest(text)` fingerprints a template over NORMALIZED line endings, so a CRLF checkout is not a change. `KIT_PROMPTS` is the declared key->file map and the only vocabulary a caller may use.
