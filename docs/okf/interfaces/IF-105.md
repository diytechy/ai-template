# IF-105 — Interface

**Contract.** reads the requirement spine through the CARRIER (IF-102) instead of csv.DictReader, so the known-id sets the runtime-flow citation check validates against answers whichever of TOML/CSV is live and the rows arrive under today's column names either way. Consumes spine_carrier.load. The one consumer that needs no column vocabulary at all: under TOML an id is the TABLE KEY, so this seam reads keys and nothing else.
