# IF-127 — Interface

**Contract.** reads the re-attestation MODEL through trace: consumes trace.load_registries and trace.reattest_model, so the adjudication brief is composed from the same rows, the same snapshot baseline and the same ratified/traced split that `trace.py --ratify` renders. Imported LAZILY. An EMPTY model is a refusal, not an empty brief: no spine row differing from its snapshot copy and none awaiting a first approval means there is nothing to judge, and the caller is told so by name.
