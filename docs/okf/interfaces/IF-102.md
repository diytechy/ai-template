# IF-102 — Interface

**Contract.** spine_carrier.py module: the requirement spine's registry CARRIER (OI-12 / repo-lock D-5). SPINE_TABLE maps an id column to its TOML tier table (SR-ID->requirement, LLR-ID->design, TC-ID->test); SPINE_COLUMN maps a carrier key to today's COLUMN NAME and is the exact inverse of migrate_carrier.KEY. rows_from_text(text, id_col, carrier) -> {id: row} under today's column names, or None when a TOML text does not parse (absent, never empty); rows_from_toml / rows_from_csv are the two arms. carriers(rel) -> both suffixed paths, for an applicability test that must span the cutover. resolve(path) -> the live carrier file, RAISING when both exist rather than resolving by precedence; load(path, id_col) -> rows in file order, the shape csv.DictReader returns, raising on a carrier that exists and will not parse. The `-000` example filter is NOT applied here - that is trace_text's rule.
