# IF-103 — Interface

**Contract.** migrate_carrier.py: the ONE-SHOT converter that moves the spine's four tiers from their two legacy carriers (stakeholder-needs.md prose tables, SR/LLR/TC CSV) to the TOML carrier spine_carrier reads. convert(root, write) -> (findings, written_paths): findings is EMPTY only when every cell survived a re-read of what was emitted, so the caller decides whether a lossy conversion is allowed to write. CLI: --check converts in memory and verifies the round-trip, writing nothing, exit 1 with a finding naming the registry, row id and field for each cell that did not survive; without --check it writes each .toml beside its source and STILL refuses on a lossy result. KEY is the column -> carrier-key map and the definition of record; spine_carrier.SPINE_COLUMN is its inverse, pinned by test_rule_sync.
