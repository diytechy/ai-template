# IF-119 — Interface

**Contract.** reads the MODEL REGISTRY through the CARRIER (IF-102), so `docs/agents` answers whichever of TOML/CSV is live and a pair row arrives under today's column names either way. Consumes spine_carrier.resolve + spine_carrier.rows_seq_from_text; the CSV branch keeps its own header check, because a declared-header schema is a property of that carrier and TOML's analogue is a decode failure. An unparseable registry is an ERROR, never an empty pool - {} under managed routing reads as a consent decision rather than a broken file, so the human is never paged.
