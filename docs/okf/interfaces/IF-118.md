# IF-118 — Interface

**Contract.** reads the OWNER DECISION REGISTRY through the CARRIER (IF-102) instead of csv.DictReader, so `docs/requirements/open-items` answers whichever of TOML/CSV is live and the rows arrive under today's column names either way. Consumes spine_carrier.load + spine_carrier.resolve. The fail-closed half is what this seam is FOR: read directly, a registry that exists and will not parse came back as no rows, and this view then published "0 pending decisions" - which on a decision queue reads as "nothing is waiting on you". load raises there and returns [] only when the registry is genuinely absent.
