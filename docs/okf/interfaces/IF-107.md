# IF-107 — Interface

**Contract.** reads the requirement spine through the CARRIER (IF-102) instead of csv.DictReader, so the SR/TC/LLR rows the release checklist groups by phase answers whichever of TOML/CSV is live and the rows arrive under today's column names either way. Consumes spine_carrier.load. Phase arrives as an INT from the TOML carrier and as a string from CSV; the carrier renders both to the same cell text, which is what keeps the checklist's grouping stable across the migration.
