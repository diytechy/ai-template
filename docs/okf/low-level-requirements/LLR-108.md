# LLR-108 — Accessible-name quality, not merely presence (A2 residue)

**Detail.** The QUALITY half of accessibility anchor A2, mechanizing what LLR-101 had left perceptual. Three rules over every focusable element and role=img graphic: it HAS an accessible name; that name is never a bare registry id (IF-001 tells a screen-reader user nothing about what the control is); and navigation LANDMARKS are distinct, because a reader listing them hears a flat list and two called 'Breadcrumb' are indistinguishable - which is exactly what three drills produced. SCOPE, and it is narrower than the first measurement assumed: A2 governs INTERACTIVE elements and meaningful graphics. A <title> on a decorative edge path is a tooltip, not an accessible name, and asserting over those would manufacture findings WCAG does not make. Uniqueness is asserted for landmarks ONLY: a descend control for the same container legitimately recurs across drill layers, one visible at a time, so those repeats are one control reached by different paths. Whether a well-formed, unique, descriptive name is the RIGHT description stays a judgement, and belongs to SR-054's reading-task critique rather than to A2's structure.
