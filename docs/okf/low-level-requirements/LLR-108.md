# LLR-108 — Accessible-name quality, not merely presence (A2 residue)

**Detail.** The QUALITY half of accessibility anchor A2, mechanizing what LLR-101 leaves perceptual. Three rules over every focusable element and role=img graphic: it HAS an accessible name; that name is never a bare registry id; and navigation LANDMARKS are distinct. SCOPE, narrower than a first measurement suggests: A2 governs INTERACTIVE elements and meaningful graphics — a <title> on a decorative edge path is a tooltip, not an accessible name. Uniqueness is asserted for landmarks ONLY: a descend control for the same container legitimately recurs across drill layers, one visible at a time, so those repeats are one control reached by different paths. Whether a well-formed, unique, descriptive name is the RIGHT description belongs to SR-054's reading-task critique.

**Rationale.** A bare registry id tells a screen-reader user nothing about what the control is, and a reader listing landmarks hears a flat list in which two called 'Breadcrumb' are indistinguishable — which is what three drills produce unless the names are made distinct. Asserting over decorative graphics too was rejected: it would manufacture findings the accessibility standard does not make, and a check that cries wolf is one a reader stops reading.
