# LLR-036 — Duplicate-block detector

**Detail.** Tokenizes each source file (stdlib tokenize; comments/NL/indent excluded, NEWLINE kept so windows cannot stitch unrelated statements), slides a --min-tokens window (default 30), merges overlapping hits by line offset into one finding per block, POSIX-normalizes the file pair, and fingerprints each block (first-window signature + token extent, line-number-free). A finding is suppressed only when its fingerprint+pair is recorded in docs/dupes-allow (count-aware: N lines sanction N identical copies) or a legacy bare pair matches; --emit-census prints the lines.
