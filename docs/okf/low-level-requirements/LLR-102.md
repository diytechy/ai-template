# LLR-102 — One-concept-per-colour de-collision (U5 core)

**Detail.** The mechanized core of uniformity anchor U5 (docs/rubrics/dashboard-uniformity.md): no hex value is reused across STATUS_FILL/TIER_FILL/OKF_TYPE_FILL/SW_NODE_FILL/PHASE_ACCENTS for an unrelated concept (the intentional TIER_FILL<->OKF_TYPE_FILL SN/SR/LLR/TC mirror is the one exception, asserted as a bijection rather than a set match), no PHASE_ACCENTS entry equals the CSS --accent token, and PHASE_ACCENTS clears a PAIRWISE (not merely adjacent) deltaE floor of 15. SCOPE: hex-identity and deltaE across these five declared palettes; the near-duplicate residue across vocabularies belongs to LLR-109/TC-114.

**Rationale.** One hex carrying two concepts makes the legend a lie in both directions, and a phase sharing the --accent token makes that phase's focus and hover ring invisible — a control the reader cannot see they have reached. Comparing only ADJACENT entries was rejected: a palette is read as a whole, so two members that collide are a collision wherever they sit in the list.
