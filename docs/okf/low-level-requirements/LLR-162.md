# LLR-162 — Prompts as loaded files, catalogued and fingerprinted

**Detail.** `load` reads a shipped template (or an operator override) and raises a named `PromptError`; `fill` refuses an unknown slot and an unfilled declared slot; `digest` normalizes line endings before hashing; `preflight` turns a missing template into a launch-time refusal. `gen_prompt_catalog.py` renders the catalogue with a `--check` freshness gate, and `agent_common.prompt_fingerprint` records the rendered result per session beside the template's own name.

**Rationale.** Normalizing before hashing is not cosmetic: the same template checked out CRLF on Windows and LF on POSIX is the same prompt, and a telemetry field that said otherwise would report a model change on every clone.
