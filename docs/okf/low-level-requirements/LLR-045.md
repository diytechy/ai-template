# LLR-045 — Loop-side reviewer dispatch + managed routing

**Detail.** When docs/agents-enabled is present (managed mode; absent = today's behavior byte-for-byte) a committing non-review session schedules REVIEW-A (and REVIEW-B under review-policy 2) before the next build; each session's model is routed via agent_route.select at the phase tier (phase_tier / --tier-map), reviewers excluding the implementer's (and REVIEW-A's) provider; the redacted reviewer_prompt (embedded default, or a --prompt-map/AGENT_PROMPT_MAP template FILE, {verdict} slotted) never carries the implementer self-assessment; verdicts are read from docs/reviews/NNN-<phase>.md, merged mechanically, scored, recorded, and fed to escalate; a page-human decision enacts failure_action (attended stops NEEDS-HUMAN); every selection/cooldown is logged before launch and preflighted up front.
