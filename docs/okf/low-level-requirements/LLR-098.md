# LLR-098 — Per-module coverage-floor comparator

**Detail.** Reads the docs/coverage-floors census (module + min percent; blank and # lines ignored) and coverage.py's JSON report (per-file percent_covered, path-normalized), fails on any module below its floor or absent from the report, SKIPs when the report is absent, is a no-op with an empty census, and fails loudly on a malformed floor line. A failure names the offending module, and all floors holding exits 0 — the per-module floor is what keeps the global aggregate from hiding a thin high-risk module.
