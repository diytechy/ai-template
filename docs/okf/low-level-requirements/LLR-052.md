# LLR-052 — Tiered When/How-SW drill-down (interface-wired, descend-a-layer)

**Detail.** Revised for the SR-051 amendment (WI-134 [v3]-[g1], owner-sanctioned): the tiered When/How-SW views render Simulink-style - IF-### seams attach to their endpoints' block input/output ports at every visible tier and a cross-container seam aggregates to the container boundary; double-click on a container block (with a keyboard alternative - Enter/Space on a focused block) descends one layer into it and a breadcrumb path restores the parent view, superseding the shipped in-place-<details>-expand/no-zoom render (the Q3 ruling the rev supersedes). Retains the count-thresholded tiering (phase->workstream->work item when a tier's member count exceeds 3, flat at or below; the How-SW view containerizing components into modules per the WI-073 idiom, bounded above at TOP_VIEW_MAX) and the deduped parent-to-parent edge aggregation. Self-contained (no external fetches), byte-deterministic; --check unchanged. Data-side graph extensions (typed-IF contracts, cyclic render) stay WI-064. Rebuilt at the WI-141 dev slice (a shared drill renderer: block input/output ports, IF-/dependency-edge wires, double-click / Enter-Space descend-a-layer, breadcrumb) across both the When and How-SW views; re-Verified.
