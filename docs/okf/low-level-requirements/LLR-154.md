# LLR-154 — The merge slot's post-merge intake arm

**Detail.** integrate_one's post-merge arm is the intake's one honest hook point: the merge has landed, the slot is still held, trunk is serial - intake.intake_after_merge(root, pre-merge head, head, outcomes, branch) mints there as one bookkeeping commit (RULING-6: docs/work/ + the declared generated set), and a mint refusal stops the run loudly while the merge stands (recovery: fix trunk-side, then python intake.py sweep). The refresh's bar directives (_lane_bar_directives, read off the same trunk claim the slot reads) carry the adjudication no-bar arm and the bar strictness pin to _run_bar's --gate.

**Rationale.** Minting anywhere else re-opens the two-lanes-one-id collision the trunk-only ruling ended; the slot is the only place trunk moves under a held lock.
