# LLR-144 — Terminal lane outcomes (handback + quarantine)

**Detail.** hand_back: commits the lane's work as-is, returns each claimed spec to queued/ with a `## Handback` section naming what remains and the commit range that holds it, and sets blockref to the spec's own path so the returned WI leaves the ready frontier (schedule reads queued+blockref as blocked) and the driver cannot claim and return it forever. quarantine: the ruled red arm - reverts the product paths to the merge base and keeps the failing diff as a bar-inert .patch under docs/work/handback/, reading `git diff --name-status -z` as three-field RECORDS so a rename cannot revert the wrong path, checking every git return code, and restoring rather than reporting when a revert step fails. Both leave the branch finished, so integrate.branch_outcomes reads the outcome off the spec's DIRECTORY - complete/=merged, cancelled/=cancelled, any open folder=handback - and every lane ends in a merge.

**Rationale.** Making the outcome the directory leaves no fourth answer and no state file that could hold one; partial work lands in trunk where a future WI can find it instead of on a branch nobody will look at.
