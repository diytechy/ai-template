# LLR-136 — Registry converter (CSV <-> spec folder)

**Detail.** Converts between the spec folder (the live docs/work/ home) and the retired CSV form (docs/requirements/work-items.csv) per the Phase 2a grammar (TOML +++ frontmatter, Deliverable in the body, status from the directory, order key only as a CSV-order migration artifact). --verify round-trips CSV->specs->CSV in a temp dir, exits nonzero on any cell mismatch, and reports byte identity with a reason. write_spec_file is the single spec writer (to_specs and plan_artifacts filing both go through it). Refuses unknown statuses by row, non-empty targets without --force, and any in-flight active/<branch>/ claim by name (status is the FIRST path component, the loaders' rule; conversion is a drained-stop operation per §3.2 - the Phase 4 claim protocol made the state reachable).

**Rationale.** One writer keeps migration and filing byte-compatible; refusal over catch-all keeps a malformed registry loud rather than silently reclassified.
