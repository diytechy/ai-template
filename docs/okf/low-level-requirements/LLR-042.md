# LLR-042 — Architecture-connectivity views and coverage warns

**Detail.** check_trajectory.interface_findings emits warn-first coverage keyed on the arch-map inventory (arch_inventory parses architecture.md generated block for module names + Contracts citations): default-on connectivity-undeclared when interfaces.csv is empty or absent for a multi-module map, per-module missing-endpoint and missing-direction warns with a source/sink Notes honesty valve, Active-seam-TC and Contracts-vs-registry citation warns; docs/interfaces-check off or a <=1-module inventory is vacuous. gen_trajectory.sw_graph renders the seams as a module/file/external graph reusing the WI-DAG layouter (byte-deterministic; table fallback when no seams), and gen_arch_map merges module-to-module IF edges plus harvests Contracts docstrings. No path changes an exit code.
