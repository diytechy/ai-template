# LLR-113 — No information by colour alone (A3 core)

**Detail.** The MECHANIZED core of accessibility anchor A3, split out of LLR-053 under the (f) decomposition ruling: for every declared colour vocabulary (enumerated from the module constants - the U5/U2 closure, so a new vocabulary enters by existing), every member that actually PAINTS in a rendered document resolves to a legend swatch labelled in words in that same document, with CSS tokens resolved (the status legend paints via var(--done); a raw hex scan under-reports it 1 of 4). Status members additionally pair a per-status glyph (the earlier A3 tests, still owning). Delivered with two defect fixes found on first measurement: the What-tab tier legend HARDCODED its swatches and its TC swatch kept an older hex that had since become STATUS_FILL[done] - a legend labelling the done-green TC while the cells painted TIER_FILL[tc] - and is now derived from TIER_FILL and pinned as a bijection; and the flat How-SW seam graph encoded node KIND by fill with no legend at all (the containment drill earned one in the 048/U3 round; the fallback never did). REWORKED same day after adversarial review found the SAME stale hex shipping in a THIRD place the first pass missed: the emitted JS detail-badge maps (const tierColor/statusColor) were hand-copied literals whose tc entry was still the done-green. The maps are now SUBSTITUTED from TIER_FILL/STATUS_FILL (their in-script fallbacks derived from the maps), and three drift guards hold every copy equal to the constants: the emitted JS maps byte-match the Python palettes; the CSS --done/--active/--queued/--retired tokens match STATUS_FILL and are asserted theme-invariant; and the tier-legend bijection derives its expectation from the TIER_FILL DICT, so a member dropped from the legend also fails (emitter and test previously shared one literal tuple - the growth-direction blind spot). SCOPE and its narrowing: the worded cue must exist in the same document - that it sits within eyeshot of the painted element is layout this does not re-assert (the adversarial review measured the shipped artifact per tab-panel and found every painted member cued in its own panel today, so the narrowing currently costs a reader nothing - re-attestation should bless it knowingly). The JS detail-panel badge stays out of the LEGEND rule because its background carries its concept as the badge's own visible text; its colours are now derived, not copied.
