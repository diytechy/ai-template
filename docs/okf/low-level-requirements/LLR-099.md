# LLR-099 — Default-density start-collapse (T2 core)

**Detail.** The mechanized core of usability anchor T2 (docs/rubrics/dashboard-usability.md): a view whose scale EARNS tiering — a bundle spanning more than 3 OKF types, a module set above the component threshold (the SR-089 '>3' rule) — renders START-COLLAPSED as the shared type-tiered drill, one block per type or container, rather than a flat wall of nodes; at or below the threshold it stays flat. Covers the Knowledge, How-SW and landing What views; the What icicle start-collapses to one block per SN with descend-on-click, reusing _drill_layer_svg/_render_drill so the interaction idiom is single-sourced. SCOPE: T2's remaining 'reads legibly at default density' judgement stays perceptual under LLR-055/TC-055.

**Rationale.** Tiering imposed on a small project costs a click to reach what already fitted on one screen, so it is earned by scale rather than switched on globally. Capping DEPTH instead of collapsing was rejected and the emitter records why: height is leaf-proportional, so stopping at the SR lane still stacks one unit per SR and the wall returns. The What icicle is the case that forced the widening — it rendered the whole spine at LEAF scale, one unit per test case.
