# LLR-110 — Declared weight/alpha/corner tokens (U3 residue)

**Detail.** Mechanizes what LLR-103 left perceptual. 'Spacing and exact visual weight' was undecidable because the weights were never declared: 8 distinct stroke-widths, 7 opacities, 5 corner radii and 6 SVG rx values, of which FIVE stroke widths were doing the single job 'draw a connector' and FOUR rx values 'round a node box'. Fourteen CSS tokens plus SVG_RX now name one step per role, near-duplicates merged into the role's step, and every emitted value must resolve to a declared token. stroke-opacity is checked under the opacity scale deliberately - it is the same scale applied to a stroke. SVG_RX is a declaration the test enforces against both the source literals and every render, because the rx presentation attribute cannot read a CSS custom property portably. SCOPE: token membership, asserted over paint surfaces (style blocks and style/fill/stroke attributes), never over prose that quotes CSS.
