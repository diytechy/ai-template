# LLR-110 — Declared weight/alpha/corner tokens (U3 residue)

**Detail.** Mechanizes what LLR-103 leaves perceptual. Fourteen CSS tokens plus SVG_RX name one step per role for stroke-width, opacity and corner radius, near-duplicates merged into the role's step, and every emitted value must resolve to a declared token. stroke-opacity is checked under the opacity scale deliberately — it is the same scale applied to a stroke. SVG_RX is enforced against both the source literals and every render, because the rx presentation attribute cannot read a CSS custom property portably. SCOPE: token membership, asserted over paint surfaces (style blocks and style/fill/stroke attributes), never over prose that quotes CSS.

**Rationale.** 'Spacing and exact visual weight' was undecidable because the weights were never declared: the shipped page carried 8 stroke-widths, 7 opacities, 5 corner radii and 6 SVG rx values, of which five stroke widths were doing the single job 'draw a connector' and four rx values 'round a node box'. Nothing can be uniform against an undeclared scale, so declaring the roles is what turns the judgement into a check; leaving it to review was rejected because a near-duplicate weight is exactly what an eye does not catch.

**Code.** `project-trajectory/scripts/gen_trajectory.py` — `--w-*/--o-*/--r-* tokens; SVG_RX`
