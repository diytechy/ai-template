# LLR-104 — Process-tab node-label type scale (U1 core)

**Detail.** The mechanized core of uniformity anchor U1 (docs/rubrics/dashboard-uniformity.md): the Process tab's working-loops SVG no longer hardcodes 12px/9.5px/13px/13px on .stgt/.stgn/.hooplab/.hubname. .stgt/.stgn are the same per-node-label role as the shared --nlabel/--nsub tokens the icicle, dag and knowledge views already share, and reuse them directly; .hooplab/.hubname are a once-per-diagram headline label, a genuinely different role, so they take the one documented --nhead scale step. SCOPE: these four selectors resolve to a declared token, asserted structurally against the emitted CSS. Whether the sizes read as uniform belongs to LLR-111/TC-116.

**Rationale.** A magic number is invisible to every later change: two independently-drifting literals doing one job diverge the first time somebody adjusts one of them. Collapsing all four selectors onto the node-label tokens was rejected because a once-per-diagram headline is a different role, and forcing one token onto two roles is the same defect in the other direction.
