# LLR-163 — Argv arrays, and the adjudicator as a routed phase

**Detail.** `split_cmd` recognises a JSON array ONLY when the value parses as a list, so no existing template can change meaning; a non-string token raises rather than being stringified. The prompt-transport decision reads the resulting TOKENS, so it is identical for both forms. Alongside it, `ADJUDICATE` joins `agent_route.WEIGHT_PHASES` and `agent_loop.DEFAULT_PHASE_TIER` with its own `route_intent` arm: cross-family like the reviewers, tier pinned by the row's measured estimate, and deliberately deaf to the implementer's escalation overrides.

**Rationale.** A silent coercion in a registry is a launch that does not match its declaration. And an adjudicator inheriting the implementer's escalation would silently re-tier a judgement because a different row's build went badly.
