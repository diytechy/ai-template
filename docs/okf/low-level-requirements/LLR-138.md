# LLR-138 — Tracked pause reader (dual-home)

**Detail.** tracked_pause parses docs/work/pause as TOML ({reason, since}; absent -> None) and fails closed on malformation with the pinned loud placeholder reason; pause_reason checks the legacy untracked docs/pause first, then the tracked home, preserving the None/''/reason contract so the retired-in-place dispatcher can never resume on a home swap. The legacy half retires with the dispatcher at Phase 5.

**Rationale.** A broken pause file must still pause; two homes during the migration window, one meaning.
