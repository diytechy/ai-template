# LLR-123 — Deterministic traincar ordering

**Detail.** Orders eligible traincars by (gate, Priority desc, downstream-dependent count desc, hard-path desc, first WI id). The downstream-dependent count is transitive and the path length is the remaining hard-path length; the order is identical across ready --explain, ready --format json and simulate --jobs 1's serial schedule.

**Rationale.** Split from the frontier row: deriving WHICH traincars are eligible and deciding WHICH runs first fail independently, and only the second one makes a run replayable.
