# LLR-134 — Requirement form rules

**Detail.** form_findings applies six rules — one obligation per requirement, no non-obligation modal, no actorless passive, no unfalsifiable term, no open-ended clause, no obligation keyword in an LLR Detail — skipping Draft rows, and joins the --strict failure set via exit_code.

**Rationale.** Draft is skipped because a pre-ratification row is exempt from the decomposition rules by definition, and an unfinished acceptance criterion is what Draft MEANS; flagging it would make the state unusable for drafting. This cell says "obligation keyword" rather than quoting the keyword itself: the rule cannot distinguish a mention from a use, and an exemption a checker cannot see is one an author can reach for.
