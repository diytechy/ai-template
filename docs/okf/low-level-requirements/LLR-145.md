# LLR-145 — Link-aware spec-move ritual (move + relink indivisible)

**Detail.** move_spec moves a registry/spec file and keeps every markdown link in the repo true as ONE indivisible operation: the moved file's own relative targets are re-relativised against its new directory, every inbound link whose target resolves to the vacated path is redirected (link text untouched, #fragments carried, external/protocol-relative/bare-anchor targets left alone, root-relative targets excused only in the rebase half, line endings preserved via newline=''), and every rewritten file is staged with the move so the ritual lands as one changeset. integrate.claim and handback.close_partial call it for the claim and close moves; the CLI performs the worker's terminal close move and the dated docs/archive/specs/ archival. expected_relink is the pure oracle integrate._abandoned_claim compares byte-for-byte to excuse a crashed claim's own relink writes without widening its conviction to any .md edit.

**Rationale.** A bare move strands both link directions and the break surfaces late, on the composed tree (measured: one probe archival took the broken-link count from 4 to 8 - 3 outbound, 1 inbound). Making move+relink one indivisible operation is a constraint that leaves the two-thirds state unrepresentable, rather than a check that detects it after the parallel work is done.
