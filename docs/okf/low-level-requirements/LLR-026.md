# LLR-026 — Headless session launch

**Detail.** Runs the agent CLI headless: build_argv substitutes {model} into argv and, when a CmdTemplate carries no {prompt} placeholder (the default for both claude and codex - WI-217), routes the prompt to the child's STDIN (run_session writes it from a daemon thread then closes) so a large prompt survives the OS command-line cap (Windows codex.CMD 8191-char cmd.exe / 32767-char CreateProcess - the round's ~70k briefs exceed even argv), while the no-wedge invariant holds (a fixed prompt + EOF, never an interactive read; WI-216). A codex session additionally captures codex's own --output-last-message file as the result (_codex_lastmsg_setup/_codex_lastmsg_read), since codex echoes its banner + the whole prompt into stdout (WI-217). stdin is otherwise closed so no prompt wedges the loop (WI-210: the scope is the dispatcher + worker sessions; the status.md-resume read is retired).
