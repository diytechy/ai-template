# LLR-026 — Headless session launch

**Detail.** Runs the agent CLI headless: build_argv substitutes {model} into argv and, when a CmdTemplate carries no {prompt} placeholder (the default for both provider CLIs), routes the prompt to the child's STDIN (run_session writes it from a daemon thread then closes), while the no-wedge invariant holds — a fixed prompt plus EOF, never an interactive read. A codex session additionally captures that CLI's own --output-last-message file as the result (_codex_lastmsg_setup/_codex_lastmsg_read). stdin is otherwise closed so no prompt wedges the loop; the scope is the dispatcher and worker sessions, and the former status.md-resume read is retired rather than coexisting with them.

**Rationale.** A large prompt passed as argv dies at the OS command-line cap (8191 characters through a Windows .CMD shim, 32767 via CreateProcess) and a round's briefs run to roughly 70k, so stdin is the only delivery that survives — both limits verified live rather than assumed. The last-message capture exists because that CLI echoes its banner and the whole prompt into stdout, so stdout is not the result.

**Code.** `project-trajectory/scripts/agent_session.py` — `build_argv/run_session/_codex_lastmsg_setup`
