# LLR-106 — Single-sourced concept colour vocabulary (U2 core)

**Detail.** The mechanized core of uniformity anchor U2 (docs/rubrics/dashboard-uniformity.md). Every concept's fill is LOOKED UP from a declared module-level palette, so the same concept cannot render two hexes — there is only one place a hex can come from. Concretely: every #rrggbb appearing in a rendered dashboard is either a member of a declared palette collection or a `--token:#hex` theme definition (surfaces, text and borders, which encode no concept). SCOPE: this proves single-sourcing of the VOCABULARY, not that a concept was assigned a well-chosen hue — collision and perceptual separation belong to LLR-102.

**Rationale.** A vocabulary is one vocabulary only if every member is in it: a bare hex literal outside the declared collection is invisible to the collision sweep and to the ring-ink enumeration alike, so it evades both the checks that would catch it. That is not hypothetical — a four-kind vocabulary declared only three because one badge fill sat inline in its emitter. Auditing hues by review was rejected: review cannot see a member that was never declared.
