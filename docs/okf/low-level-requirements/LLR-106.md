# LLR-106 — Single-sourced concept colour vocabulary (U2 core)

**Detail.** The MECHANIZED core of uniformity anchor U2 (docs/rubrics/dashboard-uniformity.md), split out of LLR-054 under the WI-300 (f) ruling. Every concept's fill is LOOKED UP from a declared module-level palette, so the same concept cannot render two hexes - there is only one place a hex can come from. Concretely: every #rrggbb appearing in a rendered dashboard is either a member of a declared palette collection or a `--token:#hex` theme definition (surfaces/text/borders, which encode no concept). SCOPE: this proves single-sourcing of the VOCABULARY, not that a given concept was assigned a well-chosen hue - U5 (LLR-102) owns collision and perceptual separation. Delivered with its own defect fix: the How-SW `component` badge was a bare #475569 literal inside cmp_block, so that four-kind vocabulary declared only three and the undeclared member was invisible to U5's collision sweep and to _ring_ink's enumeration alike - a vocabulary is one vocabulary only if every member is in it.
