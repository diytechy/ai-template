# SN-006 — An agent can run unattended and resume from repository text alone. Such a run ne

**Need.** An agent can run unattended and resume from repository text alone. Such a run never waits for interactive input, and reports its failures clearly. It also stays safe: declared limits bound the workers it may set running and the actions it takes that cannot be undone, and only an override a human provides — never one the model can set — may relax those limits.

**Why it matters.** Agents develop here, and a walk-away run is only worth having if it can be both left alone and trusted while unwatched.
