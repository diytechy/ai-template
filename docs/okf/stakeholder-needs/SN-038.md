# SN-038 — Scope: template (adopters + this repo). An adopter can determine why every file 

**Need.** Scope: template (adopters + this repo). An adopter can determine why every file supplied by the kit exists and which stakeholder outcome it supports.

**Why it matters.** A supplied file with no recorded purpose becomes inherited scope creep: adopters carry, maintain and trust it even though nobody can explain what failure its removal would cause. The absence must appear as a named coverage finding rather than remain hidden in the tree.

**Acceptance intent.** A declared shipped-file inventory defines the coverage universe and its exclusions. Every inventoried file maps to at least one system requirement whose references resolve to a stakeholder need; generated outputs may map through their generator. A mechanical check reports missing files, stale inventory entries, unresolved references and files with no mapping, and applies the declared warning-to-gating policy.
