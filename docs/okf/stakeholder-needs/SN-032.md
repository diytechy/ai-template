# SN-032 — A prompt is a reviewable file with an audit trail, and a route is declared as ar

**Need.** A prompt is a reviewable file with an audit trail, and a route is declared as argv rather than as a shell string.

**Why it matters.** Prose is what steers the sessions this loop launches, and the three highest-traffic prompts were Python string constants — reviewable only by reading source. That is not a style complaint: prose has already changed outcomes here. One judge's brief opened with the defendant's own verdict, and a magic substring inside a free-text reason silently selected review tier. Two rules generalize out of those incidents: prose that carries control flow must be a typed field, and a judge's brief must not contain the claim under judgement. Separately, a shell-string command template has to guess where a Windows path ends and a quote begins.

**Acceptance intent.** Every shipped prompt is a file under prompts/ with strictly filled {slot}s (an unknown or unfilled slot is a refusal, never a silently empty instruction), a generated catalogue listing each template by digest with a gated freshness check, and a per-session record of which template was used plus the fingerprint of what it rendered to — so "which instruction did this session see" is a lookup rather than an inference; a CmdTemplate may be a JSON argv array, with every existing shell-string template reading byte-identically.
