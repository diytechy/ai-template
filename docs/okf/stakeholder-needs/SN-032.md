# SN-032 — Nothing enters the work queue without a recorded, current ruling that it does no

**Need.** Nothing enters the work queue without a recorded, current ruling that it does not conflict with the requirement tree or with work already in flight.

**Why it matters.** Several producers writing straight into the queue means the preconditions are re-implemented per producer and drift apart, which is how an unclassified or stale row reaches a worker. Mechanical overlap is not itself a conflict — two rows touching one file may be perfectly compatible in a declared order — so the judgement has to be recorded rather than inferred, and it has to expire when the thing it judged moves.

**Acceptance intent.** One trunk-side transaction performs every move into the queue and validates identity, scope digest, predecessor acyclicity, reference currency and declared classification; it records a conflict verdict of no-conflict, compatible-overlap or conflict against the spine and every queued or active item; and the strict trajectory check refuses a queued item whose verdict is absent or computed against a superseded scope or spine digest.
