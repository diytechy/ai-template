# SN-031 — A work item's scope is fixed when it is claimed, the attempt records its own ver

**Need.** A work item's scope is fixed when it is claimed, the attempt records its own verdict immutably, and the attempt is never revived.

**Why it matters.** A branch that can edit its own scope can narrow it to whatever it finished, which makes every completion claim unfalsifiable; and a return that mutates the row it returns overwrites the record of what was tried. A returned branch that merged green once landed rejected code as-is, because nothing forced anyone to say which of its changes were wanted.

**Acceptance intent.** A terminal move whose scope differs from the claim is refused with the differing region named; every attempted branch writes exactly one immutable outcome event carrying its outcome, both commits, its scope digest and its evidence; a partial attempt classifies every change group as keep, discard or quarantine before the integrator accepts it; and remaining scope enters the queue only as a successor carrying explicit lineage.
