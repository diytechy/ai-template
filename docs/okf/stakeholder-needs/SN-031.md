# SN-031 — A lane that cannot finish CLOSES rather than hanging, its claimed outcome is a c

**Need.** A lane that cannot finish CLOSES rather than hanging, its claimed outcome is a claim an adjudicator may overrule, and the close event has its own immutable document.

**Why it matters.** Five successive mechanisms tried to answer "is a judgement still owed for THIS return?" and every one leaked, because every one reconstructed the event from a MUTABLE proxy: a merge sha in a title, the spec's last-touch commit, a digest of a note, a title token, a relationship field. Each failure was starvation-class — an owed judgement silently not happening. A document that never moves dissolves the class instead of mitigating it. Separately, a green handback once merged code a lane had rejected, because nothing had asked which commits should survive.

**Acceptance intent.** A lane closes into a TERMINAL partial/ (nothing re-claims it, so nothing strands), writes one immutable per-close report naming the outcome, the reason, the commit range and the keep/discard split, and merges like any other branch; the report path is the disposition's event identity, so a re-sweep dedupes exactly and a genuinely second close is a second document; a report declaring NEITHER a keep/discard split nor an explicit deferral to the adjudicator is refused, because silence about the split is how the incident happened; continuing partial work means DRAFTING A SUCCESSOR carrying explicit lineage — a closed row is never revived and its scope never changes to mean something else.
