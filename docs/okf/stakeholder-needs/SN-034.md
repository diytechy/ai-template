# SN-034 — Scope: template (adopters + this repo). A person setting up to work on the repos

**Need.** Scope: template (adopters + this repo). A person setting up to work on the repository can start each of the two universal contributor actions — preparing their development environment, and resuming the automated development loop — with a single action from the repository's front door, on Windows, macOS and Linux alike (one click where the platform allows it; one obvious command where it does not).

**Why it matters.** Setup friction is where a new contributor or fresh machine silently diverges from the declared toolchain, and a resume path that needs remembered commands is a resume path that rots. A single visible entry point per platform makes the sanctioned path the easy path. On Linux desktops a bare double-click is unpromisable (the platform requires marking a file executable first), so the promise there is one action, not one click.

**Acceptance intent.** Both entry points exist at the repository root for each supported platform in a fresh scaffold and in this repository; each launches its action as a single step on that platform, or documents the one platform-required step where a single click is impossible; the adopter-facing guide names the capability and invites reuse. This row is the ONE home for launcher-class obligations — root visibility, one action per platform, both universal contributor actions; SN-025 (self-direction) no longer names a launcher.
