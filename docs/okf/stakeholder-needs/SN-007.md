# SN-007 — The kit's own changes stay traceable and tested — a change to a script is covere

**Need.** The kit's own changes stay traceable and tested — a change to a script is covered by a test exercised end-to-end against a real scaffold.

**Why it matters.** The kit is a foundation many repos inherit; a regression here propagates downstream. (This need is what Thread 47 makes first-class.)

**Acceptance intent.** The suite bootstraps a temp scaffold and runs every script; pytest -q green is required before each change lands.
