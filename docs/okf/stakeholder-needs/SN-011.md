# SN-011 — The kit's scripts run on a clean Python 3.8+ with no pip installs, on Windows an

**Need.** The kit's scripts run on a clean Python 3.8+ with no pip installs, on Windows and POSIX (and macOS).

**Why it matters.** Portability — the kit must not impose its own dependency stack on a downstream repo to run its checks.

**Acceptance intent.** Every kit script is stdlib-only; the CI matrix is green on Linux + Windows + macOS.
