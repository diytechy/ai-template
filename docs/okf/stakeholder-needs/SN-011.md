# SN-011 — The kit's scripts run on a clean Python 3.11+ with minimal, argued dependencies 

**Need.** The kit's scripts run on a clean Python 3.11+ with minimal, argued dependencies — stdlib by default, a non-stdlib dependency admitted only through a reviewed ledger row — on Windows and POSIX (and macOS).

**Why it matters.** Portability — the kit must not impose an *unargued* dependency stack on a downstream repo to run its checks. But a blanket "no dependencies" rule is itself a design constraint: it can force a worse hand-rolled alternative than a well-chosen tool, so the bar is argument, not abstinence (owner RULING-3, 2026-07-28).

**Acceptance intent.** Every non-stdlib import in the kit's scripts is declared as a row in docs/dependencies.md naming what it replaces, why hand-rolling is worse, and the ruling that admitted it — tests/test_dependency_ledger.py fails the suite on an undeclared import; checks an adopter runs (shipped tier) stay stdlib-*preferred*, since a dependency there forces every adopter to install it; the CI matrix is green on Linux + Windows + macOS.
