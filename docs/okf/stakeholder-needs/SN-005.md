# SN-005 — AI agents and humans work from the same playbook, with the process enforced agen

**Need.** AI agents and humans work from the same playbook, with the process enforced agent-neutrally (git hooks + CI), not by trusting any one agent.

**Why it matters.** *AI agents and humans working from the same playbook*; enforcement can't depend on which agent showed up.

**Acceptance intent.** The enforcement floor is git + CI running the *same* harness a human runs; per-agent configs only mirror it, never replace it.
