# SN-029 — A single number says which parts of the requirement tree a human must sign off, 

**Need.** A single number says which parts of the requirement tree a human must sign off, and a change that alters meaning honestly reopens that tier.

**Why it matters.** Gate authority today says *who* ratifies but not *which tiers*, so a team wanting to sign off needs and requirements while automating test-case ratification cannot express that. And only a system requirement currently carries a post-attestation amendment state, so edited need prose has no honest baseline at all — the loop reads a stale approval as a current one.

**Acceptance intent.** A cumulative 0–3 boundary routes each spine tier to a human decision or to an adjudicator; a meaning-changing amendment at any tier regresses the derived stage to that tier while a clarity-only verdict advances the accepted text without regressing it; and a request for a full-spine human review persists across relaunches and closes only on a recorded human decision.
