# SN-012 — The process is right-sized, not ceremony for its own sake — small changes stay c

**Need.** The process is right-sized, not ceremony for its own sake — small changes stay cheap, and heavy layers are opt-in.

**Why it matters.** An over-heavy process is abandoned; adoption depends on proportionality.

**Acceptance intent.** Opt-in layers (perf, guardrails, unattended, parallel tracks, OKF export) cost a repo that doesn't use them nothing; the proportionality doctrine governs LLR/TC granularity.
