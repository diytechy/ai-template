# `docs/` — this repo's documentation tree

The hand-written half of the record. The **requirement spine** and its
registries live in [`requirements/`](requirements/README.md) and
[`test/`](test/README.md); the
authored architecture narrative is [`runtime-flows.md`](runtime-flows.md); the
forward-only working surface is [`status.md`](status.md) and the account of what
happened is [`log.md`](log.md), compiled from the per-session fragments in
[`log.d/`](log.d/README.md). Declared policy dials sit in
[`process.toml`](process.toml) and the product toolchain in
[`stack.ini`](stack.ini). Frozen design history is under
[`archive/`](archive/README.md), and generated documents (the dashboard, the CLI
and interface references, the open-items view) are regenerated by their own
tools rather than hand-edited.

To resume the redesign, start with the [September 6 handoff](handoff-2026-09-06.md).
It links the committed implementation, verification, remaining work and control
launch conditions. The [execution record](ai-template-redesign-2026-09-05-codex/EXECUTION-RECORD.md)
records actual outcomes; the [September 5 plan](ai-template-redesign-2026-09-05-codex/README.md)
preserves the architecture, package boundaries, objective mapping and review
history. The live registries and policy remain authoritative.

For local validation during kit development,
[`scripts/check_changed.py`](../scripts/check_changed.py) previews selection
against an explicit proposal base; its [P9R record](ai-template-redesign-2026-09-05-codex/P9R-EXECUTION.md)
explains the conservative fallback and evidence limits. It is a meta-repo tool;
the commit bar in the `session-protocol` skill and CI/phase-close Full checks
still apply.
