# WI-159 — Knowledge (OKF) tab: start-collapsed density (the T2 fix)

**Branch:** dualplan-routing-fix · **Un-deferred:** 2026-07-20 (owner directive,
on the 075-CRITIQUE re-affirmation) · **BuildTier:** medium ·
**SafetyClass:** ordinary (dashboard rendering + a TC; no control flow).

## Why

The [075-CRITIQUE](../reviews/075-CRITIQUE.md) rendered-pixel critique
(CHANGES-REQUESTED) confirmed the owner's "hard to read" complaint: the
**Knowledge (OKF) tab opens fully exploded** — every SN/SR/LLR/TC/IF concept node
(100s) at once under a dense mesh of crossing edges (a T2 *default-density*
failure, the rubric's exact *Bad* example), with the rightmost TC-column labels
**clipped** at the container edge (T4). Shots: `1280px-{light,dark}-know-full.png`.

This was already known — filed as WI-159 off the 052-CRITIQUE / OI-12 and then
**deferred**. The When (roadmap DAG) and How (SW architecture) tabs already solve
this: they **start-collapsed** and render a tier as wired blocks only when it
holds more than 3 members (SR-089, the `>3` rule), with double-click / Enter to
descend and a breadcrumb to return. The Knowledge graph is the one graph view
that never adopted that pattern.

## Scope

1. **Apply the start-collapsed `>3` density pattern to the Knowledge graph** in
   `gen_trajectory.py` (`know_graph` / `_know_panel`), reusing the DAG/How-SW
   collapse mechanism (`_dag_ranks` / `_reorder` / the tiering + descend/breadcrumb
   idiom) rather than inventing a new one — single-source the collapse behavior.
   The default view must read as a legible, collapsed summary (e.g. grouped by OKF
   `type` / tier), expandable to the full concept graph on demand; a **small**
   bundle (≤ the `>3` threshold) still renders flat.
2. **The clipping (T4) resolves** as a consequence (a collapsed default is not
   wider than its container); if any residual right-edge clip remains at the
   collapsed default, fix the layout so no node label is clipped.
3. **Keep it self-contained + deterministic**: the Knowledge panel stays a
   conditional, fully-offline block (its own style + inline script + embedded
   data); a bundle-less repo still renders byte-identically (the WI-070 round-trip
   property must hold); `gen_trajectory.py --check` stays deterministic.
4. **Verify against pixels**: re-run `scripts/dashboard-shots/shoot.mjs` and Read
   the new `1280px-{light,dark}-know-full.png` + `390px-light-know-full.png` to
   confirm the tab now opens legibly (no wall of nodes, no clipped labels) in both
   themes.
5. **Test**: extend `tests/test_gen_trajectory.py` — the Knowledge graph obeys the
   `>3` start-collapsed rule (a large bundle emits the collapsed shape; a small one
   stays flat), plus the existing renders-from-bundle / omitted-byte-identical /
   deterministic / `--check`-stable guards still pass.

## Non-goals

- **No redesign** beyond adopting the existing collapse pattern; not a new
  interaction idiom.
- **No spine change** (SR-054's T2 anchor is the target; no new SR/LLR).
- The 3 minor nits (WI-246 How-SW truncation, WI-247 DAG hue, WI-248 What-390) are
  **separate WIs** — not in scope here.

## Done-when

The Knowledge tab opens start-collapsed under the `>3` rule (a large bundle is not
a wall of nodes; a small one reads flat), with no clipped node labels, expandable
to the full graph; the WI-070 data-less byte-identity + determinism + `--check`
properties hold; a re-shot `know` render (both themes) visibly reads clean;
`tests/test_gen_trajectory.py` gains the density-rule assertion; full suite +
`check.py` at the derived gate green.
