- **The check would fire exactly once here**: `gen_trajectory` (CMP-002) →
  `check_trajectory` (CMP-001) is a real cross-component import with **no
  declared IF row** — the exact undeclared coupling the model says must
  surface. (The other 3 edges are CMP-004-internal wiring.)

**In scope (this WI):** the cross-CMP-edge check, the trace.py IF

## 2. Scope ruling — what stays gated (recorded, not built)

Each with its applies-when; none has a trigger in this repo today:

- **Typed `IF-###` contract check** (§8 "highest value") — applies when a
  repo's `Contract` cells carry machine-checkable formats (OpenAPI / JSON
  Schema / proto). All 55 of this repo's seams are prose CLI contracts;
  there is nothing to mechanize yet.
- **`consumes` / effort-duration schema** (§7) — applies when a physical /
  resource-timeline project adopts; vacuous for software repos.
- **Cyclic-graph renderer + the How-physical view** (§11, Cross-cutting) —
  applies when a project has a `connects-to` loop topology (a 4-bar linkage);
  the meta-repo's graphs are all DAGs.
- **Shared graph-engine extraction + unified edge vocabulary** (#8) — applies
  at the second in-kit *general* graph consumer. The Slice B check is
  deliberately **not** that consumer: it reuses the existing joins
  (`module_components`, `load_ifs`, the committed diagram block) rather than
  introducing an engine.
- **Routed CAD extractor** (iter 8) — solution-space; permanently routed out.

## 4. Ground rules

- **Never-breaking.** The check is vacuous when any input is absent: no CMP
  rows, no `Component` tags, no committed DEPENDENCY DIAGRAM block, or
  `docs/components-check: off` (the existing opt-out). A fresh scaffold and
  every current downstream stay byte-identical green.
- **Committed-artifact idiom.** check_trajectory reads the *committed*
  `docs/architecture.md` diagram block (like `arch_inventory` reads the module
  map) — never a live source rescan. Freshness is already gated by
  `gen_arch_map --check` (the splice covers the optional block).
- **Warn-first.** WARN plain / ERROR under `--strict` (G2+), matching
  `interface_findings` / `component_findings`.
- **Stdlib-only, Python 3.8+; commit bar per slice; full suite at WI close.**

## 5. Slices

- **A — Dogfood the dependency-diagram block.** Add the
  `BEGIN/END GENERATED DEPENDENCY DIAGRAM` markers to the meta-repo's
  `docs/architecture.md` (prose placement near the module map) and regenerate.
  No script change; the hook's arch-map `--check` now guards the block.
- **B — The cross-CMP-edge-without-IF check** in `check_trajectory.py`:
  1. Import edges come from the committed **MODULE MAP block's**
     `Imports (internal): \`a\`, \`b\`` lines — a required block every
     scaffold carries, parsed by extending the existing `arch_inventory`
     grammar (### headers + Contracts lines) rather than adding a mermaid
     parser. *(Build-time improvement over the plan's original
     diagram-block parse: simpler grammar, and the check works even where
     the optional diagram markers are absent. The diagram block from Slice A
     stays as the human-visible render of the same edges.)* Bare import
     stems resolve against the block's module names by stem match.
  2. Join each edge's endpoints to CMPs via `module_components()`. An edge
     with an unmapped endpoint is skipped (membership coverage is the
     containment rule's job, not this one's).
  3. A cross-CMP edge is a finding unless some real IF row's normalized
     `(ThisProject, Counterpart)` covers the module pair (either direction).
     Finding text names the edge, both CMPs, and the fix ("declare an IF-###
     row or retag membership").
  4. Wire into `component_findings` gating (`docs/components-check` opt-out)
     + `main()`. Unit tests (parser, join, either-direction seam match,
     vacuity matrix) + one e2e scaffold test.

## 6. Done-when

- A cross-CMP import edge with no covering IF row is a WARN (plain) / ERROR
  (`--strict`) finding; covered/intra-CMP/unmapped edges and every
  absent-input case are silent (the vacuity matrix is tested).
- trace.py validates IF `Component` tags like LLR/PART/ASSET ones.
- The meta-repo dogfoods clean: diagram block committed, the
  `gen_trajectory→check_trajectory` seam declared, zero findings at
  `check.py --gate G3` (all 15 steps).
- LLR-067 + TC-067 Verified; goldens byte-identical; PROCESS_OPTIONS carries
  the one-paragraph contract.

## 7. Risks / watch-fors

- **Grammar drift** between `build_dependency_diagram`'s emit and the new
  parser — pin both with the sync comment and a round-trip test.
- **Downstream surprise**: scaffolds already carry the diagram markers, so a
  downstream repo that tags CMPs *will* start seeing warns on undeclared
  cross-CMP imports — that is the feature; the PROCESS_OPTIONS paragraph must
  say so plainly (warn-first, opt-out named).
- **Scope creep**: no engine extraction, no edge-vocabulary unification, no
  IF-tag *coverage* rule (only resolution of tags that exist) — §2 items stay
  parked.
