# WI-192 — Trace golden masters are platform-sensitive (defect)

**Status: queued (filed 2026-07-16, found during the WI-189/190/191 filing
session on macOS).**

## Symptom

`tests/test_trace_golden.py` (the WI-081 golden-master net over `trace.py`'s
report + summary + exit) fails all three cases on macOS at clean HEAD —
verified with the working tree stashed, so it is **not** caused by any current
change:

```
FAILED tests/test_trace_golden.py::test_golden_offspine_rich_spine
FAILED tests/test_trace_golden.py::test_golden_orphaned_spine
FAILED tests/test_trace_golden.py::test_golden_clean_spine
3 failed, 732 passed, 2 skipped (smoke tier)
```

## Diagnosis

The checked-in goldens (`tests/golden/{clean,offspine,orphan}.txt`) were
generated on Windows and embed two platform artifacts:

1. **`os.sep` paths** — e.g. `Report -> docs\test\report.md` — where a POSIX
   run produces `docs/test/report.md`; `_normalize` covers the tmp root but
   not separator differences inside relative paths.
2. **Encoding mojibake** — the goldens carry `â€”` where the live output has a
   real em-dash (`—`): the capture path double-encoded UTF-8 through a legacy
   console codepage when the goldens were written.

CI (Linux + Windows + macOS) never flagged it because the branch is unpushed
(OI-3) — this is exactly the class the cross-OS matrix exists to catch.

## Fix shape

- Make the compared body platform-stable: normalize separators in
  `_normalize` (or emit POSIX separators in the report text itself — check the
  kit's other contracts, e.g. `dupes-allow` already speaks POSIX pairs) and
  force UTF-8 on the capture path.
- Regenerate the goldens **deliberately** (`UPDATE_TRACE_GOLDEN=1`) from the
  normalized output, and verify the suite green on both a POSIX and a Windows
  run before closing.

## Done-when

- [ ] The three golden cases pass on macOS/Linux **and** Windows from one set
      of checked-in goldens.
- [ ] The normalization is tested (a unit case covering separator + encoding
      stability), so the net cannot silently re-fork by platform.
