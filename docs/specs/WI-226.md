# WI-226 — Dispatcher decomposition: characterize, then separate decisions from effects (repo-review-2026-07-18 H-02, slice B)

"required next move", main slice; absorbs L-04 as its trailing test-split) ·
**BuildTier:** strong · **SafetyClass:** high-risk (the integrator/publish

## Why

`agent_dispatch.py` is 2,292 lines with `dispatch_run` at 698 lines /
complexity 84, and `integrate_train`, `publish_integration`,
`pack_traincars`, `_salvage_round_evidence` all over-limit. WI-218 moved code
verbatim behind seams — it deliberately did not decompose. The review's
verdict stands: the code is safe to change because the tests are excellent,
not because the control flow is legible. Correctness hardening keeps landing
here (WI-220/222/223/224), so illegibility compounds where the risk is
highest.

## Scope (staged; each stage lands green independently)

1. **Characterize.** A design doc (`docs/specs/` companion or §-section
   here) enumerating `dispatch_run`'s states, transitions, and effect points
   (git refs, worktrees, sessions, journal, run-state) — written from the
   code + tests, reviewed for honesty against both. No code change.
2. **Extract pure decisions.** Move decision logic (what to do next, how to
   rank, when to stop) into side-effect-free functions with table-driven
   tests; effects (git/session/filesystem) stay behind the existing seams.
   Measurable targets set per boundary at stage start — e.g. `dispatch_run`
   complexity 84 → a stated target, not "smaller" — with the WI-225 ratchet
   re-stamped *downward* each stage.
3. **Test split (the L-04 fold-in).** Re-home tests along the new behavior
   boundaries only after stages 1–2 stabilize them; no split before then.

Behavior-preserving throughout: public surface, exit codes, journal events,
and ref discipline unchanged; the full-suite + G3 bar after every stage.

**Non-goals:** no reconcile-policy or spec-§9 semantic changes; no
arbitrary file-count targets; no downstream migration burden (seams and
public names stay).

## Done-when

Each stage's target met and recorded in the log with before/after complexity
numbers; WI-225's baseline strictly smaller than at start; full suite + G3
gate green at every stage close.
