# WI-225 — No-new-complexity ratchet (repo-review-2026-07-18 H-02, slice A)

**Branch:** dualplan-routing-fix · **Filed:** 2026-07-18 (review H-02 "required
next move", first slice) · **BuildTier:** medium · **SafetyClass:** ordinary
(meta-repo test tooling; no kit-script behavior change).

## Why

The review measured a C901 census of 50 over-complexity functions and
documented the census growing *during remediation* because nothing fails on
it (§5 correction 3). It has since grown twice more the same way: 51 after
the review's own M-01 fix, **52** after WI-222/224 added
`_salvage_round_evidence` (complexity 16). Every growth was well-intentioned
and unnoticed — exactly the failure mode a ratchet exists for. The full
decomposition is WI-226; this slice stops the bleeding first.

## Scope

A meta-repo test (`tests/`, dev tooling — the stdlib-only rule governs kit
scripts, not their tests) that runs
`ruff check --select C901` over `project-trajectory/scripts` and compares
per-function complexity against a committed baseline mapping
`(file, function) → complexity` embedded in the test module (one home,
reviewed like any code change):

- **FAIL** when a function exceeds its baselined complexity or a new
  over-limit function appears — the message names the function and says the
  fix is simplification, not a baseline bump (a deliberate bump is a reviewed
  edit with a stated reason).
- **FAIL** when a baseline entry no longer matches an over-limit function
  (improved or renamed) — the baseline must be re-stamped downward in the
  same commit, so the ratchet only ever tightens by default.
- **Skip** when ruff is unavailable (mirrors the suite's needs-git skips);
  the threshold (10) is pinned explicitly in the invocation, not inherited.

**Non-goals:** no simplification of the 52 (that is WI-226's work); no C901
in the downstream-shipped check.py (a kit-policy question, not this slice).

## Done-when

The ratchet test is green at baseline 52; deliberately raising a function's
complexity (or adding an over-limit function) fails with an actionable
message, verified locally and reverted; smoke bar green; the baseline's
re-stamp discipline is stated in the test's docstring.
