# WI-1001 — An approved automated test case has a test behind it (spec of record)

**WI:** WI-1001 · **Status:** queued · **Delivers:** SR-157

Routed by OI-127's ruling of 2026-11-05. The row keeps its Context and
Done-when, which stay the one home of what closes it.

## Why

TC-165 and TC-166 stood Approved for eleven weeks with no test behind what
they state, and every bar stayed green. An automated TC need only cite a
non-empty evidence cell, and a whole-file part naming a real, passing test
file satisfies that without saying anything about the case. The owner's
reading of the failure: this should not have been possible.

The test-file tags (WI-994, seeded by WI-997) make it checkable for the first
time: a TC either has a test declaring it, or it does not.
