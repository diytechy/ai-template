## The defect

Found in headless leg 08 (2026-10-21) at WI-957's attestation step (wi-957
D-006). `integrate.py attest --branch wi-957 --bar review` in the lane
worktree `C:/Projects/ai-template.wt/wi-957` refused before its bar:
"the harness floor REFUSES this bar run: no runnable ./.venv interpreter
found under C:\Projects\ai-template.wt\wi-957". `agent_common.venv_python`
looks only under the checkout's own root, and `harness_floor_failures`
fails closed when it finds none (WI-286, WI-361: never the ambient
interpreter). In this repository every lane is a linked worktree of the
primary checkout and runs under the primary checkout's `.venv` (the
coordinator-cycle recipes, section 0), so no lane can take a review
attestation. WI-957 makes every review render refuse a tip without one,
so it cannot land until this row has: landed, it would stop every lane's
review.

This is a defect in a landed mechanism (WI-956's `attest`), fixed forward
in a lane with a regression test, never by a bypass flag or a fallback to
the ambient interpreter (the coordinator-cycle skill, section 4).

The anchor: the review gate's attestation requirements WI-956 approved
(its SR and LLR rows; the scope critique names them). The architectural
delta, for the critique to judge: whether the floor's interpreter lookup
for a linked worktree reads the repository's own pinned `.venv` at the
primary checkout (found through the git common directory), as the commit
hooks' interpreter probe may already do (one owner, if so), or whether
each lane worktree gets its own `.venv` from dev-setup.

## Trust

- **Producer:** dev-setup creates the primary checkout's `.venv`; a lane
  worktree carries none.
- **Consumers:** `agent_common.harness_floor_failures` and
  `harness_python`, through `integrate.py` (attest and the composed-tree
  bar); the commit hooks' interpreter probe (to be read by the critique).
- **Ruling (proposed):** a linked worktree's floor reads only the pinned
  `.venv` of the same repository's primary checkout; absent, unrunnable or
  below the floor there refuses exactly as today; the ambient interpreter
  is never used.
