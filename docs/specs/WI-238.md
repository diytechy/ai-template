# WI-238 — blocked_disposition must survive a registry without a BlockRef column

**Branch:** dualplan-routing-fix · **Filed:** 2026-07-19 (field finding — the
WI-229 blocked-exit dead-end) · **BuildTier:** medium · **SafetyClass:**
high-risk (disposition transaction).

## Why

`blocked_disposition` rewrites the blocked WI's row with `Status=blocked` +
`BlockRef` ([agent_dispatch.py:1539-1544](../../project-trajectory/scripts/agent_dispatch.py#L1539-L1544)),
but `_rewrite_wi_rows` silently drops a field whose column the registry does
not carry — and this repo's `work-items.csv` has no BlockRef column. The
result (field event, runs `20260719T112312/131512/132453`): the disposition
commit fails `check_trajectory`'s blocked-row validation ("status=blocked but
BlockRef is empty") on every launch, forever — an infinite parked-error loop
whose real cause was invisible (see WI-240). The disposition can never
succeed in any adopted repo whose registry predates the BlockRef column.

## Scope

Make the mismatch impossible: when the BlockRef column is absent,
`blocked_disposition` (or `_rewrite_wi_rows` on its behalf) **adds the
column** in the same surgical rewrite (header + empty cells + the blocked
row's value) — the same registry-extension pattern WI-229 used for
`SupersededBy`. If extending is deemed wrong for a given registry state, the
transaction must **fail loudly naming the missing column** instead of
committing a row that validation will reject. Scaffolded template: confirm
`work-items.template.csv` carries the column so fresh repos never hit this;
this repo's registry gains it with the fix.

**Non-goals:** no change to the blocked-classification lifecycle (WI-239);
no validation relaxation in `check_trajectory`.

## Done-when

Regressions prove: a blocked disposition against a registry WITHOUT the
column succeeds by extending it (row carries the BlockRef; `check_trajectory`
green); with the column present, behavior unchanged; the WI-229 field shape
(trailer evidence + column-less registry) drives end-to-end to a committed
disposition. Suite green.
