# WI-236 — Weighted reviewer draws declared in agents-enabled

**Branch:** dualplan-routing-fix · **Filed:** 2026-07-19 (owner-selected
config shape — annotations in `docs/agents-enabled`) · **BuildTier:** medium ·
**SafetyClass:** high-risk (model selection policy).

## Why

Preference today has exactly two degrees: the order of `docs/agents-enabled`
(tie-break within a tier) and `AGENT_PREFER_MAP=PHASE=ID` (a single pinned
draw per phase). The owner wants proportional distribution — e.g. three
reviewer families with OpenAI taking ~2 of every 3 reviews and Kimi reserved
for judging — which no current surface can express. The owner reviewed three
config homes (agents-enabled annotations · AGENT_PREFER_MAP grammar ·
an agents.csv Share column) and selected **agents-enabled annotations**: the
consent + preference file stays the single home for "who runs and how often,"
and the launcher env stays a simple override.

## Scope

**Grammar.** An enabled id may carry optional per-phase draw weights after
whitespace: `<ID>[ <PHASE>=<int>]...` — e.g.

```
ANTHROPIC-FABLE
OPENAI-TERRA        REVIEW=4
OPENCODE-KIMI       REVIEW=1  CRITIQUE=9
OPENCODE-GROK       REVIEW=1
```

Unannotated ids weigh 1 in every phase; `REVIEW` covers REVIEW-A/REVIEW-B; a
malformed annotation fails preflight loudly (never silently ignored — the
file is the consent surface). Line order keeps its current meaning as the
tie-break within equal weights.

**Selection.** Within the legal candidate set — after tier resolution,
heterogeneity rules, cooldowns, and `AGENT_PREFER_MAP` pins (a pin still
wins its phase outright; weights govern the unpinned remainder) — draws
follow **deterministic weighted rotation** keyed on the durable per-train
session counter, so a given history always reproduces the same draw and every
selection is journaled as today. Weights renormalize over available
candidates when a model cools; weights can never force a same-family review,
a weaker tier, or a disabled id (the invariant mirrors "a preference can
never change the requested tier").

**Non-goals:** no percentage syntax (integers only — ratios are exact and
diff-reviewable); no per-WI weights; no change to `agents.csv` (capabilities
stay separate from deployment policy); no random draws.

## Done-when

Regressions prove: a 4:1:1 REVIEW weighting yields exactly that rotation over
12 simulated draws with full availability; a cooling model's share
renormalizes and returns after cooldown; a `CRITIQUE=9` annotation
concentrates judge draws without starving heterogeneity; an unannotated file
behaves byte-identically to today (weights all 1); a malformed annotation
fails preflight naming the line; `AGENT_PREFER_MAP` pins still win their
phase. Scaffolded template + PROCESS_OPTIONS routing section document the
grammar in one place. Suite green.
