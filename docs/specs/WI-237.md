# WI-237 — Ownership claims scan: ignore integration-reachable commits

**Branch:** dualplan-routing-fix · **Filed:** 2026-07-19 (field finding — the
WI-229 pre-merge quarantine) · **BuildTier:** medium · **SafetyClass:**
high-risk (recovery/ownership reconstruction, SR-064 family).

## Why

Reconcile derives a train's claimed WIs by scanning its commits; a claim on a
WI the train has not reserved quarantines it fail-closed
(`claims-unreserved-wi`). Field event 2026-07-19 (run `20260719T105727`): the
owner merged the development branch INTO train `p0-g3-WI-229-3999` to preempt
known integration conflicts before stage 3 — a content-only sync — and the
scan read the imported `WI-226:`/`WI-227:`/… commit subjects as foreign
claims, quarantining the attested, stage-3-ready train at launch. Recovery
required manual state surgery (retire train + release reservation; safe only
because the train tip happened to be fully integration-contained). The scan's
suspicion is correct for genuinely ambiguous trains, but a commit **already
reachable from the integration ref** is integrated history, not a claim this
train is making — treating it as one makes any owner sync/merge into a
reserved train a quarantine trap.

## Scope

When deriving a train's claims, exclude commits reachable from the
integration ref (`git rev-list <tip> ^<integration-head>` bounds the scan, or
the equivalent merge-base filtering) so only the train's OWN novel commits
can claim WIs. A genuine foreign claim in novel commits still quarantines
exactly as today. Document the now-sanctioned owner resync ("merging the dev
branch into a reserved train is content-sync, not claiming") in the
PROCESS_OPTIONS unattended section (byte-budget guard applies) and the spec
of record for the dispatcher's reconcile.

**Non-goals:** no relaxation of duplicate-reservation or unreadable-metadata
quarantines; no auto-resync of trains; no change to reservation metadata.

## Done-when

Regressions prove: a train with the dev branch merged in (imported foreign-WI
commit subjects, all integration-reachable) reconciles and resumes instead of
quarantining; a train whose NOVEL commits claim an unreserved WI still
quarantines with the same reason; the WI-229 field shape (reservation base
predating the merge) is the driven scenario. Suite green.
