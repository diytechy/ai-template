# WI-282 — train build commits: enforce the `WI:` trailer at commit time

**WI:** WI-282 · **Status:** queued · **Delivers:** the train commit contract
(harness floor; no spine SR — meta harness layer, empty-`SR-Refs` precedent)

## Problem

Live failure, 2026-07-23, train `p0-g3-WI-281-9ae9`: session 006's build
commit `45637d2` was written with a malformed trailer block — `Train:`/`Base:`
present, **no parseable `WI: WI-281` trailer** (an interposed blank line breaks
git's trailer block). `reviewed_train_head()` resolves a train's reviewed head
as *the newest commit carrying a `WI:` trailer*, so the integrator's verdict
gate skipped `45637d2`, resolved the head to the older `d8d50e6`, read its
CHANGES-REQUESTED (005) instead of the tip's APPROVE (007 at `45637d2`), and
parked the train `rework` — **a one-line commit-message slip cost a full extra
build+review cycle.** The trailer rule is currently prose (worker prompt);
enforcement-audit doctrine: a rule the harness can check must not be left to
prose.

## Approach

- **Primary — a commit-time floor check.** A `commit-msg` hook (the floor is
  currently pre-commit only; the message is only checkable in commit-msg),
  shipped in `project-trajectory/hooks/` with the same thin meta-repo wrapper
  pattern as `.githooks/pre-commit`: on a branch matching `llm/train/*`, a
  commit that touches non-generated files must carry a parseable
  `WI: WI-<n>` trailer — refuse with a message naming the exact fix.
  Scope carefully: the dispatcher's own sanctioned shapes (`Blocked-WI:`
  dispositions, `integrate:`/`telemetry:`/`review:` commits) must stay legal —
  gate on "touches non-generated files" and/or exempt the sanctioned subject
  prefixes.
- **Secondary — a loud integration diagnostic.** When `reviewed_train_head()`
  resolves to a commit that is NOT the newest substantive commit on the train
  (i.e., trailered head ≠ tip-most non-telemetry commit), journal a warning
  naming both SHAs — so a slipped trailer is visible at integration instead of
  masquerading as honest dissent.
- Tests beside the existing hook tests (worktree case included — hooks run in
  train worktrees via the shared `core.hooksPath`); downstream: hooks ship in
  the kit, so note the migration in the close deliverable.

## Interfaces

No cross-module seam — intra-module (hooks + `agent_dispatch.reviewed_train_head`
diagnostic + tests).

## Done-when

- [ ] A train-branch build commit without a valid `WI:` trailer is refused at
      commit time with an actionable message; sanctioned dispatcher shapes
      unaffected (tests prove both).
- [ ] The reviewed-head mismatch diagnostic journals loudly (test).
- [ ] Commit bar green; row `done`, spec archived.
