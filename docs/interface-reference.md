# Interface reference — what each module promises for the seams it declares

The rows of record are in
[requirements/interfaces.toml](requirements/interfaces.toml): an `IF-###` row
states what **crosses** a seam, typed, and names its endpoints. This document is
the other half — what the **providing side** promises, stated in the module's own
docstring beside the code that must honour it, and harvested here so a registry
cell can point at it instead of restating it.

A module declares its seams on one `Contracts:` line and may state a contract
body for each. Both live in the module docstring; this file is generated from
them and must not be edited by hand.

## Stated contracts

### `hooks/pre-commit`
_Pre-commit hook — the agent-neutral *process floor*._

**IF-134** — git invokes this hook at commit time with no arguments; exit 0 admits the staged write into governed state, any nonzero exit refuses the commit, and the failing check is named on stderr. `git commit --no-verify` skips the invocation entirely, so this seam admits only the writes a session routes through git's own floor.

### `hooks/pre-push`
_Pre-push hook — the privacy-review backstop for privacy-checked repos._

**IF-135** — git invokes this hook before a push with the remote name and URL on argv and the outgoing ref pairs on stdin; exit 0 releases the push and any nonzero exit refuses it, naming the offending range on stderr. `git push --no-verify` skips the invocation, so the refusal binds only a session that routes through git's own floor.

### `scripts/check`
_The check harness — one command that runs every quality gate locally and in CI._

**IF-013** — SR-006's obligation delivered as a CLI here. Runs a gate's declared steps as subprocesses and exits nonzero on any required failure, degrading only to a reported SKIP — never to a silent pass.

**IF-144** — the reporting protocol every delivered checker honours, composed here into one verdict. A finding names its location — the at-fault row and cell, `file:line`, or the module — unless it is population-level and no single location exists; it carries a severity from the closed set OK / SKIP / WARN / FAIL; an advisory class never reaches the exit code; a declared strict flag is the only promotion from warning to failure; and an absent optional input exits zero and names the absence. Per-class severity stays each requirement's own declaration — this fixes the protocol, never the disposition.
