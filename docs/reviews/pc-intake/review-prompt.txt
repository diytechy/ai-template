def _decision_rows(payload, scope):
    decisions = payload.get("decision", [])
    rows = []
    for item in decisions:
        if not isinstance(item, dict):
            return None, "decision is not a table"
        need = {"registry", "row", "classification", "before", "after", "evidence"}
        if set(item) != need:
            return None, "decision {} has an unexpected key set".format(
                item.get("row", "?")
            )
        if (
            not isinstance(item["registry"], str)
            or not isinstance(item["row"], str)
            or not isinstance(item["classification"], str)
            or item["classification"] not in _CLASSES
        ):
            return None, "decision has an invalid registry, row or classification"
        if item["row"] not in scope:
            return None, "decision {} is outside the turn scope".format(item["row"])
        if (
            not isinstance(item["before"], dict)
            or not isinstance(item["after"], dict)
            or set(item["before"]) != set(item["after"])
        ):
            return (
                None,
                "decision {} must bind identical before/after cell sets".format(
                    item["row"]
                ),
            )
        if not item["before"] or not all(
            isinstance(c, str) and isinstance(v, str) and _HEX40.fullmatch(v)
            for m in (item["before"], item["after"])
            for c, v in m.items()
        ):
            return None, "decision {} has invalid cell blob identities".format(
                item["row"]
            )
        if (
            not isinstance(item["evidence"], list)
            or not item["evidence"]
            or not all(isinstance(x, str) for x in item["evidence"])
        ):
            return None, "decision {} has no evidence refs".format(item["row"])
        rows.append(item)
    if {item["row"] for item in rows} != set(scope) or len(rows) != len(scope):
        return None, "decisions must name every scoped row exactly once"
    return rows, None

*Referenced from PROCESS.md §4.* The dial above says **which rungs** a human
still accepts. It never said **who acts** on the rungs it releases, and for a
single-lane repo the question does not arise — the session that authors a row
is the only session there is. It arises the moment work runs in parallel lanes,
and the owner ruled it (2026-09-01):

> The approval act on a spine row — the `Status` flip `Drafted` → `Approved`
> (and on to `Founded`), and the `docs/archive/last_approved/` copy that anchors
> it — belongs to an **adjudicator**, performed on the **serial trunk side**,
> never to the worker lane that authored the row.

Two reasons, and both are properties of the lane rather than of the model
driving it:

- **Context.** Approving a row means reading its whole chain — the parent
  requirement, the sibling decomposition rows, the tests that claim to cover
  it — and deciding the row belongs where it sits. One work item does not hold
  that chain; it holds its own scope, which is the point of scoping it.
- **Concurrency.** Two lanes touching the spine conflict at merge, and the
  approval snapshot must not move across a workstream — a lane that re-anchors
  the record seals whatever text happened to be live in *its* tree. A
  trunk-side act, taken while nothing else claims, cannot do either.

**The division of labour, in full:**

| | A worker lane | An exclusive primary adjudication turn |
|---|---|---|
| Authors spine rows | Only exclusive spine-authoring work; new rows stay `Drafted`. | No. |
| Amends governing SN/SR/LLR text | Only exclusive spine-authoring work, within scope. Implementation returns a handback. | No; it returns findings to separate authoring work. |
| Flips spine `Status` | **Never** (SN/SR/LLR/TC). | Mechanical publication applies an accepted first approval, after required review and authority checks. |
| Writes `docs/archive/last_approved/` or its ledger | **Never**, including adjudication worktrees. | The mechanical publisher copies accepted content in the approval commit; the model does not invoke the copier. |
| Judges a post-approval amendment | No; it records its scoped proposal. | Compares meaning against the last approved snapshot under the rule below. |
| Concurrency | Ordinary implementation may run in parallel; spine authoring runs alone. | Runs in the coordinator's designated primary checkout on its integration branch, without a worktree; ownership excludes admission, merges and other writers through publication and restart. |

**An ID denotes stable meaning.** Changed bytes require semantic comparison,
not automatic invalidation of implementation judgments. Accepted equivalent
wording preserves those judgments and its existing approval; publish the
equivalence decision and mechanical snapshot update together. Uncertain
equivalence holds the prior baseline. Changed meaning requires impact review
of every use and reference, including downstream requirements, tests,
implementation and approval evidence, before acceptance. A `MEANING` verdict
alone never authorizes a copy. No new-ID policy or replacement status follows.
Rejection leaves the baseline intact. A whole-file copy must enumerate and
resolve every unapproved cell it would absorb outside the accepted scope.
