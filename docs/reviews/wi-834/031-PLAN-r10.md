  NAME only before `{`. Bash's grammar is `coproc [NAME] compound-command`.

  `until`, `if`, `for`, `select`, `case`, `[[`, `((` (as ruled; the reader
  splits at `(`, so `((` never reaches a segment and that entry is inert).

  `coproc WORK if codex exec -; then :; fi` denied;
