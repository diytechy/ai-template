**WI:** WI-000 · **Status:** queued · **Delivers:** SR-000

## Problem

One or two sentences: what is wrong or missing today, and why it matters now.
State it concretely enough that a fresh session understands the goal without the
conversation that produced it.

## Approach

The intended shape of the change — the files/modules it touches, the design
choices already made, and the trade-offs deliberately accepted. Reference
durable ids (`SR-###`, `LLR-###`, `TC-###`) and in-repo paths, never
session-local codenames.

## Interfaces

*Arms only where PROCESS.md §8 applies — the WI acts across a module boundary
(another module, a shared file, an external actor). A single-module change states
that here instead of inventing a seam.* Cite each seam the WI acts on as an
`IF-###` that resolves in [`docs/requirements/interfaces.csv`](../requirements/interfaces.csv):

- `IF-012`: what this WI does over that **existing** seam.
- `IF-045` (Proposed): the new seam's contract — nearest existing `IF-012`,
  insufficient because *&lt;why&gt;*. A genuinely new seam is filed as a
  `Status=Proposed` row **at this filing**, and the rationale naming the nearest
  IF is the forced anti-duplication search (`check_trajectory` verifies the
  citation resolves and a Proposed citation carries a rationale; whether it is
  *honest* is a reviewer/critique call).

Intra-module instead? Write one line and cite nothing: *no cross-module seam —
acts only within `<module>`.*

## Done-when

The frontier of a half-complete WI is its **first unticked box**. Tick each as it
lands (transient working state — this spec archives at close).

- [ ] The change is implemented and the harness is green
      (`check.py --gate <G>`).
- [ ] New behavior is covered by a test (`tests/…`), not just asserted in prose.
- [ ] The spine reflects it (the delivered `SR-###` and its `LLR/TC` chain).
- [ ] `status.md` names the next work; this WI's row is `done` with its
      `Deliverable` filled and `SpecRef` cleared.
- [ ] This spec is archived to `docs/archive/specs/` (close date appended, WI
      id noted).
