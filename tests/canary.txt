# The canary set: is every capability still basically alive?
#
# One end-to-end happy path per capability, run by the iterate checks beside the
# tests a change names (scripts/check_iterate.py). The set is FIXED-SIZE: its
# cap is tests/conftest.py CANARY_MAX, and a new entry past the cap replaces
# one already here. It is chosen for breadth, so a subprocess- or
# scaffold-driven test belongs here when it is the one that shows a capability
# working; cost is held by the cap, not by excluding a kind of test.
#
